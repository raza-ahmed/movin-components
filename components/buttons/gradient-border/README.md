# Gradient Border button

A silver highlight spins continuously around the button border; on hover it brightens to white and casts a soft blurred halo. CSS @property angle and colour, no dependencies.

Live preview: https://movin.design/components/buttons/gradient-border/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-gradient-border.json
```

Or copy [`button-gradient-border.tsx`](./button-gradient-border.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-gradient-border.html`](./button-gradient-border.html) where it goes and include [`button-gradient-border.css`](./button-gradient-border.css). It is pure CSS, so there is no script.
