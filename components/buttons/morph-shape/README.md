# Morph Shape button

On hover, the button morphs from a pill shape to a circle: the width collapses and border-radius transitions to 50%. The text label fades out and a decorative symbol fades in with a spring-bounce entrance. Both transitions are CSS-only.

Live preview: https://movin.design/components/buttons/morph-shape/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-morph-shape.json
```

Or copy [`button-morph-shape.tsx`](./button-morph-shape.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-morph-shape.html`](./button-morph-shape.html) where it goes and include [`button-morph-shape.css`](./button-morph-shape.css). It is pure CSS, so there is no script.
