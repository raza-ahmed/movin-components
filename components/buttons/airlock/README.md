# Airlock button

Two hazard-striped doors seal the button. Hover cracks them apart a few pixels; a click slides them open on an angled seam to show a lit ACCESS GRANTED inside, then they close again.

Live preview: https://movin.design/components/buttons/airlock/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-airlock
```

Or copy [`button-airlock.tsx`](./button-airlock.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-airlock.html`](./button-airlock.html) where it goes and include [`button-airlock.css`](./button-airlock.css). [`button-airlock.js`](./button-airlock.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
