# Pull Cord button

A lamp switch: a cord hangs from the button with a bead on the end. Drag the bead down past the trigger point and let go to turn it on; the cord springs back and swings like a pendulum. Clicking the button itself toggles it too and tugs the cord, so keyboards get the same switch.

Live preview: https://movin.design/components/buttons/pull-cord/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-pull-cord.json
```

Or copy [`button-pull-cord.tsx`](./button-pull-cord.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-pull-cord.html`](./button-pull-cord.html) where it goes and include [`button-pull-cord.css`](./button-pull-cord.css). [`button-pull-cord.js`](./button-pull-cord.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
