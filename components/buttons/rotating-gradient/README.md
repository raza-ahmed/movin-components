# Rotating Gradient button

On hover, a large conic-gradient layer (alternating dark and light grays) fades in behind the button text and spins continuously via a rotate(360deg) keyframe animation. A subtle dark overlay keeps the white text readable against the gradient. No dependencies.

Live preview: https://movin.design/components/buttons/rotating-gradient/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-rotating-gradient
```

Or copy [`button-rotating-gradient.tsx`](./button-rotating-gradient.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-rotating-gradient.html`](./button-rotating-gradient.html) where it goes and include [`button-rotating-gradient.css`](./button-rotating-gradient.css). It is pure CSS, so there is no script.
