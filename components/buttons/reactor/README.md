# Reactor button

A round reactor core as a toggle button: three segmented rings counter-rotate around a breathing core. Hover spins the rings up without a jump; a click ignites the core with a flash ring and keeps it running faster while it is on.

Live preview: https://movin.design/components/buttons/reactor/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-reactor
```

Or copy [`button-reactor.tsx`](./button-reactor.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-reactor.html`](./button-reactor.html) where it goes and include [`button-reactor.css`](./button-reactor.css). [`button-reactor.js`](./button-reactor.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
