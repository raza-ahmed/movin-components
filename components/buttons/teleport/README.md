# Teleport button

Click and the button is beamed out: it breaks into tiles that stretch up and vanish into a column of light, bottom row first, then rematerialises tile by tile from the top down.

Live preview: https://movin.design/components/buttons/teleport/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-teleport
```

Or copy [`button-teleport.tsx`](./button-teleport.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-teleport.html`](./button-teleport.html) where it goes and include [`button-teleport.css`](./button-teleport.css). [`button-teleport.js`](./button-teleport.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
