# Fold button

The button is a sheet of paper. A click folds the top half down over the bottom like a letter, its underside showing and the crease casting a shadow; it holds folded while the label changes underneath, then unfolds with the new label. Hover lifts the top flap a little to say it can fold.

Live preview: https://movin.design/components/buttons/fold/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-fold
```

Or copy [`button-fold.tsx`](./button-fold.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-fold.html`](./button-fold.html) where it goes and include [`button-fold.css`](./button-fold.css). [`button-fold.js`](./button-fold.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
