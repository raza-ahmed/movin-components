# Topple button

An explore button whose letters tip over like dominoes on hover, each knocking the next, hold a moment and then stand back up in a ripple.

Live preview: https://movin.design/components/buttons/topple/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-topple
```

Or copy [`button-topple.tsx`](./button-topple.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-topple.html`](./button-topple.html) where it goes and include [`button-topple.css`](./button-topple.css). It is pure CSS, so there is no script.
