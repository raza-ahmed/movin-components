# Morse button

Hover and the button transmits its label in Morse code: a paper tape of dots and dashes runs past a read head while a lamp blinks in time with every mark. Leave and the tape stops where it is.

Live preview: https://movin.design/components/buttons/morse/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-morse
```

Or copy [`button-morse.tsx`](./button-morse.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-morse.html`](./button-morse.html) where it goes and include [`button-morse.css`](./button-morse.css). [`button-morse.js`](./button-morse.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
