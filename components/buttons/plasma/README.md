# Plasma button

Live turbulent energy churns inside a pill button: bright filaments of plasma that never repeat. At rest they smoulder faintly; hover turns them up to a blaze behind the label, with a glow round the rim.

Live preview: https://movin.design/components/buttons/plasma/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-plasma
```

Or copy [`button-plasma.tsx`](./button-plasma.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-plasma.html`](./button-plasma.html) where it goes and include [`button-plasma.css`](./button-plasma.css). [`button-plasma.js`](./button-plasma.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
