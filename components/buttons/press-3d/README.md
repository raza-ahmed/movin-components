# Press 3D button

A chunky RPG-style button with a thick box-shadow that simulates physical depth. On mousedown it snaps down 5px while the shadow collapses, then springs back on release, replicating the feel of pressing a physical arcade or game controller button. No dependencies.

Live preview: https://movin.design/components/buttons/press-3d/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-press-3d
```

Or copy [`button-press-3d.tsx`](./button-press-3d.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-press-3d.html`](./button-press-3d.html) where it goes and include [`button-press-3d.css`](./button-press-3d.css). It is pure CSS, so there is no script.
