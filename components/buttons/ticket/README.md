# Ticket button

A ticket with a perforated stub. Hover tugs at the stub; a click tears it off along the perforation and it tumbles away while the ticket reads Admitted, then a fresh stub slides back into place. The notches are radial-gradient masks, the perforation a repeating gradient.

Live preview: https://movin.design/components/buttons/ticket/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-ticket
```

Or copy [`button-ticket.tsx`](./button-ticket.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-ticket.html`](./button-ticket.html) where it goes and include [`button-ticket.css`](./button-ticket.css). [`button-ticket.js`](./button-ticket.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
