# Data Rain button

Hover and columns of glyphs start pouring down behind the label, each column at its own speed with a fading trail. Leave and the columns finish their fall and trickle out one by one.

Live preview: https://movin.design/components/buttons/data-rain/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-data-rain
```

Or copy [`button-data-rain.tsx`](./button-data-rain.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-data-rain.html`](./button-data-rain.html) where it goes and include [`button-data-rain.css`](./button-data-rain.css). [`button-data-rain.js`](./button-data-rain.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
