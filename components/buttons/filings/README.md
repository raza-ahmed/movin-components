# Filings button

A field of 52 compass needles inside the button, every one turning to point at the cursor wherever it is on the page, brighter and longer the closer it gets, with a springy transition between headings. A click spins the whole field once in a staggered sweep.

Live preview: https://movin.design/components/buttons/filings/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-filings.json
```

Or copy [`button-filings.tsx`](./button-filings.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-filings.html`](./button-filings.html) where it goes and include [`button-filings.css`](./button-filings.css). [`button-filings.js`](./button-filings.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
