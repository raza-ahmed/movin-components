# Quantum button

The label sits in superposition: three faint copies of the button jitter between positions out of step. Hover or focus observes it, and they collapse instantly into one solid button with a ring of light.

Live preview: https://movin.design/components/buttons/quantum/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-quantum
```

Or copy [`button-quantum.tsx`](./button-quantum.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-quantum.html`](./button-quantum.html) where it goes and include [`button-quantum.css`](./button-quantum.css). It is pure CSS, so there is no script.
