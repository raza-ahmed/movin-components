# Dot Matrix button

An LED dot-matrix panel spells the label in lit dots. On hover or focus it scrolls the message like a station marquee, starting exactly where the resting word sits, and settles back when you leave.

Live preview: https://movin.design/components/buttons/dot-matrix/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-dot-matrix
```

Or copy [`button-dot-matrix.tsx`](./button-dot-matrix.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-dot-matrix.html`](./button-dot-matrix.html) where it goes and include [`button-dot-matrix.css`](./button-dot-matrix.css). [`button-dot-matrix.js`](./button-dot-matrix.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
