# Diamond button

A diamond-shaped button using a 45-degree rotated wrapper with counter-rotated text. On hover, the button scales up, the background gradient brightens, and a pulse box-shadow animation radiates outward. No clip-path — pure CSS rotate transform.

Live preview: https://movin.design/components/buttons/diamond/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-diamond.json
```

Or copy [`button-diamond.tsx`](./button-diamond.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-diamond.html`](./button-diamond.html) where it goes and include [`button-diamond.css`](./button-diamond.css). It is pure CSS, so there is no script.
