# Horizon Grid button

A synthwave button: a perspective grid floor rushes toward you under a slatted sun on the horizon line. Hover hits the throttle, running the floor four times faster without a jump, and the sun brightens.

Live preview: https://movin.design/components/buttons/horizon-grid/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-horizon-grid
```

Or copy [`button-horizon-grid.tsx`](./button-horizon-grid.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-horizon-grid.html`](./button-horizon-grid.html) where it goes and include [`button-horizon-grid.css`](./button-horizon-grid.css). [`button-horizon-grid.js`](./button-horizon-grid.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
