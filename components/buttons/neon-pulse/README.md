# Neon Pulse button

A white neon glow breathes in and out continuously around the button using layered box-shadows — ideal for a primary CTA that demands attention. Pure CSS, no dependencies.

Live preview: https://movin.design/components/buttons/neon-pulse/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-neon-pulse.json
```

Or copy [`button-neon-pulse.tsx`](./button-neon-pulse.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-neon-pulse.html`](./button-neon-pulse.html) where it goes and include [`button-neon-pulse.css`](./button-neon-pulse.css). It is pure CSS, so there is no script.
