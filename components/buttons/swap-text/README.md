# Swap Text button

The button label slides upward out of frame on hover while a secondary label slides in from below — a clean way to surface a call-to-action hint. Pure CSS transitions, no dependencies.

Live preview: https://movin.design/components/buttons/swap-text/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-swap-text.json
```

Or copy [`button-swap-text.tsx`](./button-swap-text.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-swap-text.html`](./button-swap-text.html) where it goes and include [`button-swap-text.css`](./button-swap-text.css). It is pure CSS, so there is no script.
