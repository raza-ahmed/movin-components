# Force Field button

Hover raises a honeycomb shield around the button. A click sends a ripple through the hex cells from the exact point you clicked (the centre, from the keyboard), lighting each ring of cells as it passes.

Live preview: https://movin.design/components/buttons/force-field/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-force-field
```

Or copy [`button-force-field.tsx`](./button-force-field.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-force-field.html`](./button-force-field.html) where it goes and include [`button-force-field.css`](./button-force-field.css). [`button-force-field.js`](./button-force-field.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
