# Spool button

A download button: the underline unwinds onto a spinning reel as the file comes in, the reel fills with the wound tape, then caps over and turns into a tick as it saves.

Live preview: https://movin.design/components/buttons/spool/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-spool
```

Or copy [`button-spool.tsx`](./button-spool.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-spool.html`](./button-spool.html) where it goes and include [`button-spool.css`](./button-spool.css). [`button-spool.js`](./button-spool.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
