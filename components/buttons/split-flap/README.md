# Split-Flap button

An airport departures board. Each letter is a split-flap tile; on hover the tiles flip left to right through a few random characters on hinged leaves before landing on the next label, and flip back when the cursor leaves. Interrupting mid-flip retargets cleanly.

Live preview: https://movin.design/components/buttons/split-flap/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-split-flap
```

Or copy [`button-split-flap.tsx`](./button-split-flap.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-split-flap.html`](./button-split-flap.html) where it goes and include [`button-split-flap.css`](./button-split-flap.css). [`button-split-flap.js`](./button-split-flap.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
