# Echo Stack button

Ghost copies of the button hide behind it. On hover they fan out up and to the left in depth, each fainter than the last and lagging slightly; a click slams them all back into the button with a punch.

Live preview: https://movin.design/components/buttons/echo-stack/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-echo-stack
```

Or copy [`button-echo-stack.tsx`](./button-echo-stack.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-echo-stack.html`](./button-echo-stack.html) where it goes and include [`button-echo-stack.css`](./button-echo-stack.css). [`button-echo-stack.js`](./button-echo-stack.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
