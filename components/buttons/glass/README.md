# Glass button

A frosted glass pane floating over drifting soft lights. Move the cursor around it and the lights behind the glass gather toward the pointer one after another, while a rim light slides round the pane's edge to face it.

Live preview: https://movin.design/components/buttons/glass/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-glass
```

Or copy [`button-glass.tsx`](./button-glass.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-glass.html`](./button-glass.html) where it goes and include [`button-glass.css`](./button-glass.css). [`button-glass.js`](./button-glass.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
