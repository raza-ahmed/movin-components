# Circuit button

A button wired into a circuit board. On hover, current pulses race along every trace from the pads into the button, and the button powers up as the first pulses arrive.

Live preview: https://movin.design/components/buttons/circuit/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-circuit
```

Or copy [`button-circuit.tsx`](./button-circuit.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-circuit.html`](./button-circuit.html) where it goes and include [`button-circuit.css`](./button-circuit.css). It is pure CSS, so there is no script.
