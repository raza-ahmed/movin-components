# Morph Text button

On hover the label melts into the next word. Both words blur through each other while letter-spacing shifts, and an SVG alpha-threshold filter turns the overlap into liquid letterforms instead of a crossfade. Pure CSS, no script.

Live preview: https://movin.design/components/buttons/morph-text/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-morph-text.json
```

Or copy [`button-morph-text.tsx`](./button-morph-text.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-morph-text.html`](./button-morph-text.html) where it goes and include [`button-morph-text.css`](./button-morph-text.css). It is pure CSS, so there is no script.
