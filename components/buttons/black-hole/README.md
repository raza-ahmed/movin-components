# Black Hole button

Hover and the label spirals into a singularity: each letter orbits into the centre, the far ones last, while an accretion disc spins up in 3D. The core flares and a new word emerges from it.

Live preview: https://movin.design/components/buttons/black-hole/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-black-hole
```

Or copy [`button-black-hole.tsx`](./button-black-hole.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-black-hole.html`](./button-black-hole.html) where it goes and include [`button-black-hole.css`](./button-black-hole.css). [`button-black-hole.js`](./button-black-hole.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
