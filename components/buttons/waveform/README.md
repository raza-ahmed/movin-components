# Waveform button

A pill button filled with equaliser bars that idle gently, then swell and dance around the cursor as if it were the sound source, brightening where the energy is highest.

Live preview: https://movin.design/components/buttons/waveform/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-waveform
```

Or copy [`button-waveform.tsx`](./button-waveform.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-waveform.html`](./button-waveform.html) where it goes and include [`button-waveform.css`](./button-waveform.css). [`button-waveform.js`](./button-waveform.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
