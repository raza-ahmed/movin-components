# Brushstroke button

A link button that paints one dry-brush ink stroke behind its label on hover, left to right, while the thin rule beneath fades and the label turns to read over the ink.

Live preview: https://movin.design/components/buttons/brushstroke/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-brushstroke
```

Or copy [`button-brushstroke.tsx`](./button-brushstroke.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-brushstroke.html`](./button-brushstroke.html) where it goes and include [`button-brushstroke.css`](./button-brushstroke.css). It is pure CSS, so there is no script.
