# Particle Text button

The label is redrawn from every inked pixel of the word, one canvas particle each, springing to its home. The cursor brushes the particles aside like dust and a click blows the word apart, weakening the spring for a moment so it drifts before pulling back together.

Live preview: https://movin.design/components/buttons/particle-text/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-particle-text.json
```

Or copy [`button-particle-text.tsx`](./button-particle-text.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-particle-text.html`](./button-particle-text.html) where it goes and include [`button-particle-text.css`](./button-particle-text.css). [`button-particle-text.js`](./button-particle-text.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
