# Fingerprint button

Press and hold to scan a fingerprint. A beam sweeps over the pad while the ridges draw in one after another; let go early and they fade back. Hold long enough and it reads Verified, then resets.

Live preview: https://movin.design/components/buttons/fingerprint/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-fingerprint
```

Or copy [`button-fingerprint.tsx`](./button-fingerprint.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-fingerprint.html`](./button-fingerprint.html) where it goes and include [`button-fingerprint.css`](./button-fingerprint.css). [`button-fingerprint.js`](./button-fingerprint.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
