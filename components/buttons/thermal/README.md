# Thermal button

A heat camera as a button. The cursor leaves a warm trail that blooms outward in blocky cells and cools slowly, banded like a thermal readout, with the peak temperature shown in the corner.

Live preview: https://movin.design/components/buttons/thermal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-thermal
```

Or copy [`button-thermal.tsx`](./button-thermal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-thermal.html`](./button-thermal.html) where it goes and include [`button-thermal.css`](./button-thermal.css). [`button-thermal.js`](./button-thermal.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
