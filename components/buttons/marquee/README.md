# Marquee button

A ticket button framed in theatre marquee bulbs: on hover the lights chase round the border, and when you press they all flash together.

Live preview: https://movin.design/components/buttons/marquee/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-marquee
```

Or copy [`button-marquee.tsx`](./button-marquee.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-marquee.html`](./button-marquee.html) where it goes and include [`button-marquee.css`](./button-marquee.css). It is pure CSS, so there is no script.
