# Liquid Chrome button

A polished metal pill. Its banded reflections drift slowly on their own and slide against the cursor as you move over it, the way they would on a curved surface, with a specular hotspot following the pointer.

Live preview: https://movin.design/components/buttons/liquid-chrome/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-liquid-chrome
```

Or copy [`button-liquid-chrome.tsx`](./button-liquid-chrome.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-liquid-chrome.html`](./button-liquid-chrome.html) where it goes and include [`button-liquid-chrome.css`](./button-liquid-chrome.css). [`button-liquid-chrome.js`](./button-liquid-chrome.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
