# Launch button

Click to launch: the button counts down T-3, T-2, T-1 while it rumbles and its engine flickers, then lifts off with a full flame and smoke puffs fanning along the ground, drops back in and lands with a bounce.

Live preview: https://movin.design/components/buttons/launch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-launch
```

Or copy [`button-launch.tsx`](./button-launch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-launch.html`](./button-launch.html) where it goes and include [`button-launch.css`](./button-launch.css). [`button-launch.js`](./button-launch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
