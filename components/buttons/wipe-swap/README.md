# Wipe Swap button

On hover, the primary label slides out to the left while a secondary label simultaneously slides in from the right, both driven by the same translateX transition. Different from swap-text which moves vertically; this is a horizontal wipe with distinct label content. No dependencies.

Live preview: https://movin.design/components/buttons/wipe-swap/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-wipe-swap
```

Or copy [`button-wipe-swap.tsx`](./button-wipe-swap.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-wipe-swap.html`](./button-wipe-swap.html) where it goes and include [`button-wipe-swap.css`](./button-wipe-swap.css). It is pure CSS, so there is no script.
