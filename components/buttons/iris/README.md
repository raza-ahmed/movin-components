# Iris button

A camera aperture as a button. Six shaded blades meet in a closed iris; on hover or focus they twist open together to reveal the action glowing inside, and close again when you leave.

Live preview: https://movin.design/components/buttons/iris/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-iris
```

Or copy [`button-iris.tsx`](./button-iris.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-iris.html`](./button-iris.html) where it goes and include [`button-iris.css`](./button-iris.css). [`button-iris.js`](./button-iris.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
