# Border Beam button

On hover, a white light beam races continuously around the button border. A 2px-padded wrapper div clips a large rotating conic-gradient square — only the border gap is visible, creating the illusion of a beam orbiting the perimeter. The button interior stays dark. No dependencies.

Live preview: https://movin.design/components/buttons/border-beam/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-border-beam
```

Or copy [`button-border-beam.tsx`](./button-border-beam.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-border-beam.html`](./button-border-beam.html) where it goes and include [`button-border-beam.css`](./button-border-beam.css). It is pure CSS, so there is no script.
