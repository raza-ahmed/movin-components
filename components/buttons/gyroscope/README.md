# Gyroscope button

Three gimbal rings, each with a glowing bead, tumble in 3D around a pill button. Hover or focus locks them: every ring swings flat with a spring into one halo around the button, which lights up.

Live preview: https://movin.design/components/buttons/gyroscope/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-gyroscope
```

Or copy [`button-gyroscope.tsx`](./button-gyroscope.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-gyroscope.html`](./button-gyroscope.html) where it goes and include [`button-gyroscope.css`](./button-gyroscope.css). It is pure CSS, so there is no script.
