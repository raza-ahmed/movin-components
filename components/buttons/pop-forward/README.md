# Pop Forward button

On hover, the button pops toward the viewer using CSS 3D transforms: translateZ(28px) and scale(1.06) with a spring cubic-bezier. A deep drop shadow grows to reinforce the depth illusion. Requires a perspective wrapper on the parent element.

Live preview: https://movin.design/components/buttons/pop-forward/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-pop-forward.json
```

Or copy [`button-pop-forward.tsx`](./button-pop-forward.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-pop-forward.html`](./button-pop-forward.html) where it goes and include [`button-pop-forward.css`](./button-pop-forward.css). It is pure CSS, so there is no script.
