# Wireframe button

A 3D slab drawn in wire, turned at an angle with dashed hidden edges. On hover it squares up to face you and materialises face by face, each side filling in a beat after the last.

Live preview: https://movin.design/components/buttons/wireframe/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-wireframe
```

Or copy [`button-wireframe.tsx`](./button-wireframe.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-wireframe.html`](./button-wireframe.html) where it goes and include [`button-wireframe.css`](./button-wireframe.css). It is pure CSS, so there is no script.
