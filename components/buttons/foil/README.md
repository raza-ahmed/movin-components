# Foil button

A members button with foil-stamped lettering on a deep plate: the metallic sheen follows your pointer across the letters, sweeps through on keyboard focus, and a press debosses the plate.

Live preview: https://movin.design/components/buttons/foil/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-foil
```

Or copy [`button-foil.tsx`](./button-foil.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-foil.html`](./button-foil.html) where it goes and include [`button-foil.css`](./button-foil.css). [`button-foil.js`](./button-foil.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
