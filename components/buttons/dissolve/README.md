# Dissolve button

A hold to delete button: while you hold it, a bar fills and the label crumbles into sand from the right, each letter drifting and turning away. Let go early and the letters gather back; hold to the end and it offers Undo.

Live preview: https://movin.design/components/buttons/dissolve/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-dissolve
```

Or copy [`button-dissolve.tsx`](./button-dissolve.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-dissolve.html`](./button-dissolve.html) where it goes and include [`button-dissolve.css`](./button-dissolve.css). [`button-dissolve.js`](./button-dissolve.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
