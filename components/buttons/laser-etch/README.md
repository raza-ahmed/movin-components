# Laser Etch button

An outlined label waits to be engraved. On hover a laser line sweeps across the button, filling the letters in solid behind it and throwing sparks from the beam, then switches off once the pass is done.

Live preview: https://movin.design/components/buttons/laser-etch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-laser-etch
```

Or copy [`button-laser-etch.tsx`](./button-laser-etch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-laser-etch.html`](./button-laser-etch.html) where it goes and include [`button-laser-etch.css`](./button-laser-etch.css). It is pure CSS, so there is no script.
