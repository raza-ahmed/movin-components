# Hologram button

A button projected as a hologram: it floats above an emitter on a cone of light, with scanlines and a bright band rolling down its face. At rest it flickers like a weak signal; on hover the projection steadies, rises and the cone and emitter brighten.

Live preview: https://movin.design/components/buttons/hologram/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-hologram
```

Or copy [`button-hologram.tsx`](./button-hologram.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-hologram.html`](./button-hologram.html) where it goes and include [`button-hologram.css`](./button-hologram.css). It is pure CSS, so there is no script.
