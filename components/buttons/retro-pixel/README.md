# Retro Pixel button

8-bit game-style button with a chunky pixel border (outline + box-shadow), scanline overlay via repeating-linear-gradient, monospace font, and a stepped jitter shake animation on press. The outer wrapper uses a black frame to simulate a cartridge slot border. No dependencies.

Live preview: https://movin.design/components/buttons/retro-pixel/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-retro-pixel
```

Or copy [`button-retro-pixel.tsx`](./button-retro-pixel.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-retro-pixel.html`](./button-retro-pixel.html) where it goes and include [`button-retro-pixel.css`](./button-retro-pixel.css). It is pure CSS, so there is no script.
