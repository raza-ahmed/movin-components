# Constellation button

Drifting points of light fill the button and wire themselves together whenever they pass close. Move the cursor over it and nearby nodes reach out to it with lines and drift toward it.

Live preview: https://movin.design/components/buttons/constellation/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-constellation
```

Or copy [`button-constellation.tsx`](./button-constellation.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-constellation.html`](./button-constellation.html) where it goes and include [`button-constellation.css`](./button-constellation.css). [`button-constellation.js`](./button-constellation.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
