# Pattern Lock button

A lock button with a 3x3 pattern pad. Drag through four or more dots to unlock: each dot lights with a springy halo and a glowing line follows your finger. Too short a pattern shakes it off; a plain click plays a demo pattern for you.

Live preview: https://movin.design/components/buttons/pattern-lock/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-pattern-lock
```

Or copy [`button-pattern-lock.tsx`](./button-pattern-lock.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-pattern-lock.html`](./button-pattern-lock.html) where it goes and include [`button-pattern-lock.css`](./button-pattern-lock.css). [`button-pattern-lock.js`](./button-pattern-lock.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
