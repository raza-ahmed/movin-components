# CRT Power button

A tiny CRT screen as a power button. A click switches it off the way old tubes did: the picture collapses to a bright line, then a dot, and an afterglow lingers. Another click powers it back up with a flicker.

Live preview: https://movin.design/components/buttons/crt-power/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-crt-power
```

Or copy [`button-crt-power.tsx`](./button-crt-power.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-crt-power.html`](./button-crt-power.html) where it goes and include [`button-crt-power.css`](./button-crt-power.css). [`button-crt-power.js`](./button-crt-power.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
