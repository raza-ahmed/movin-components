# Stitch button

Hover and a needle sews a running stitch round the button border, the stitches appearing behind it through pre-punched holes; leave and the stitches unpick in reverse.

Live preview: https://movin.design/components/buttons/stitch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-stitch
```

Or copy [`button-stitch.tsx`](./button-stitch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-stitch.html`](./button-stitch.html) where it goes and include [`button-stitch.css`](./button-stitch.css). It is pure CSS, so there is no script.
