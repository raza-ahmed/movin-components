# Dispatch button

A send button that folds into a paper plane: on click the plane glides off in an arc, banking as it goes and leaving a fading trail, and the button settles on Sent.

Live preview: https://movin.design/components/buttons/dispatch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-dispatch
```

Or copy [`button-dispatch.tsx`](./button-dispatch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-dispatch.html`](./button-dispatch.html) where it goes and include [`button-dispatch.css`](./button-dispatch.css). [`button-dispatch.js`](./button-dispatch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
