# Tesla button

A button between two electrodes. At rest a short spark crackles now and then; on hover live arcs leap across the top of the button, redrawn many times a second, and a click discharges a burst of bolts with a flash.

Live preview: https://movin.design/components/buttons/tesla/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-tesla
```

Or copy [`button-tesla.tsx`](./button-tesla.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-tesla.html`](./button-tesla.html) where it goes and include [`button-tesla.css`](./button-tesla.css). [`button-tesla.js`](./button-tesla.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
