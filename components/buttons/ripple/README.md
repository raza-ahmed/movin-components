# Ripple button

A soft white ripple circle expands from the exact click point and fades out — Material Design's satisfying click feedback pattern. Pure CSS animation, no dependencies.

Live preview: https://movin.design/components/buttons/ripple/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-ripple.json
```

Or copy [`button-ripple.tsx`](./button-ripple.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-ripple.html`](./button-ripple.html) where it goes and include [`button-ripple.css`](./button-ripple.css). [`button-ripple.js`](./button-ripple.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
