# Glitch button

Two cloned text layers are absolutely positioned over the button. On hover, staggered clip-path animations in steps() slice each clone into horizontal bands while offsetting them in opposite directions — one dark, one bright — creating a channel-split digital glitch effect. No dependencies.

Live preview: https://movin.design/components/buttons/glitch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-glitch.json
```

Or copy [`button-glitch.tsx`](./button-glitch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-glitch.html`](./button-glitch.html) where it goes and include [`button-glitch.css`](./button-glitch.css). It is pure CSS, so there is no script.
