# Moire button

Two identical ring gratings overlap inside the button. One centre circles slowly by itself and follows the cursor on hover, so the overlap beats into moving op-art fringes around the label.

Live preview: https://movin.design/components/buttons/moire/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-moire
```

Or copy [`button-moire.tsx`](./button-moire.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-moire.html`](./button-moire.html) where it goes and include [`button-moire.css`](./button-moire.css). [`button-moire.js`](./button-moire.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
