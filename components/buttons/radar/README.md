# Radar button

A round radar scope as a button. A beam sweeps round the range rings, and each contact lights up the moment the beam passes over it, then fades. Hover brightens the rim with a soft glow.

Live preview: https://movin.design/components/buttons/radar/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-radar
```

Or copy [`button-radar.tsx`](./button-radar.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-radar.html`](./button-radar.html) where it goes and include [`button-radar.css`](./button-radar.css). It is pure CSS, so there is no script.
