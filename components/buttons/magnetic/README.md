# Magnetic button

The button follows the cursor with spring physics, pulling toward the mouse like a magnet and bouncing back on leave.

Live preview: https://movin.design/components/buttons/magnetic/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-magnetic
```

Or copy [`button-magnetic.tsx`](./button-magnetic.tsx) into your project. Dependencies: framer-motion.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-magnetic.html`](./button-magnetic.html) where it goes and include [`button-magnetic.css`](./button-magnetic.css). [`button-magnetic.js`](./button-magnetic.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
