# Shimmer Sweep button

A skewed diagonal glare band slides across the button from left to right on hover. The glare is a semi-transparent white gradient on an absolutely-positioned span. The transition is one-shot on mouseenter (no reverse on mouseleave), giving a clean premium feel. No dependencies.

Live preview: https://movin.design/components/buttons/shimmer-sweep/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/button-shimmer-sweep.json
```

Or copy [`button-shimmer-sweep.tsx`](./button-shimmer-sweep.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-shimmer-sweep.html`](./button-shimmer-sweep.html) where it goes and include [`button-shimmer-sweep.css`](./button-shimmer-sweep.css). It is pure CSS, so there is no script.
