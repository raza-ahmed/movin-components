# Tide button

Liquid rises inside the button on hover with two SVG wave layers rolling across its surface, and sloshes against the walls when the cursor moves fast: horizontal pointer speed tips the water on a spring. The label splits colour at the waterline through mix-blend-mode.

Live preview: https://movin.design/components/buttons/tide/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-tide
```

Or copy [`button-tide.tsx`](./button-tide.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-tide.html`](./button-tide.html) where it goes and include [`button-tide.css`](./button-tide.css). [`button-tide.js`](./button-tide.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
