# Warp button

A starfield drifts slowly out from the centre of the button. On hover the stars stretch into hyperspace streaks and race past, and the label spreads as if accelerating.

Live preview: https://movin.design/components/buttons/warp/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-warp
```

Or copy [`button-warp.tsx`](./button-warp.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-warp.html`](./button-warp.html) where it goes and include [`button-warp.css`](./button-warp.css). It is pure CSS, so there is no script.
