# Octagon button

An 8-sided button shaped with a CSS clip-path polygon. On hover, the entire shape rotates 22.5 degrees with a spring overshoot, the background gradient fills in, and the inner text counter-rotates to stay upright.

Live preview: https://movin.design/components/buttons/octagon/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-octagon
```

Or copy [`button-octagon.tsx`](./button-octagon.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`button-octagon.html`](./button-octagon.html) where it goes and include [`button-octagon.css`](./button-octagon.css). It is pure CSS, so there is no script.
