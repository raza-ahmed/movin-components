# Bell button

A notify me button: pressed, the bell swings and settles with its clapper a beat behind, sound rings ripple out from it and the label confirms you are on the list.

Live preview: https://movin.design/components/buttons/bell/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-bell
```

Or copy [`button-bell.tsx`](./button-bell.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-bell.html`](./button-bell.html) where it goes and include [`button-bell.css`](./button-bell.css). [`button-bell.js`](./button-bell.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
