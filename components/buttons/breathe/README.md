# Breathe button

A calm breathing session button: at rest its halo breathes slowly; press it and it guides you through breathing in, holding and breathing out for two rounds, the halo swelling and shrinking with each step.

Live preview: https://movin.design/components/buttons/breathe/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/button-breathe
```

Or copy [`button-breathe.tsx`](./button-breathe.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`button-breathe.html`](./button-breathe.html) where it goes and include [`button-breathe.css`](./button-breathe.css). [`button-breathe.js`](./button-breathe.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
