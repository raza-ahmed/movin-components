# Grid wave loader

A five by five grid of dots with a ripple running through it from corner to corner, each dot swelling, brightening and settling as it passes.

Live preview: https://movin.design/components/loaders/grid-wave/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-grid-wave
```

Or copy [`loader-grid-wave.tsx`](./loader-grid-wave.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-grid-wave.html`](./loader-grid-wave.html) where it goes and include [`loader-grid-wave.css`](./loader-grid-wave.css). It is pure CSS, so there is no script.
