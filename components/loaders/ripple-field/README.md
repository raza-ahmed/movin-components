# Ripple Field loader

A 9x9 field of dots with ripples spreading outward from the centre, each dot swelling and brightening as a wavefront passes.

Live preview: https://movin.design/components/loaders/ripple-field/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-ripple-field
```

Or copy [`loader-ripple-field.tsx`](./loader-ripple-field.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-ripple-field.html`](./loader-ripple-field.html) where it goes and include [`loader-ripple-field.css`](./loader-ripple-field.css). It is pure CSS, so there is no script.
