# Pages loader

An open book whose pages turn over one after another, each brightening as it lifts past the spine and settling on the left.

Live preview: https://movin.design/components/loaders/pages/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-pages
```

Or copy [`loader-pages.tsx`](./loader-pages.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-pages.html`](./loader-pages.html) where it goes and include [`loader-pages.css`](./loader-pages.css). It is pure CSS, so there is no script.
