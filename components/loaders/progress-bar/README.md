# Progress Bar loader

An indeterminate progress bar: a gradient shimmer slides across a pill-shaped track from left to right on loop. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/progress-bar/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-progress-bar
```

Or copy [`loader-progress-bar.tsx`](./loader-progress-bar.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-progress-bar.html`](./loader-progress-bar.html) where it goes and include [`loader-progress-bar.css`](./loader-progress-bar.css). It is pure CSS, so there is no script.
