# Signal loader

A wireless signal: the source lights first, then each arc outward in turn, all hold, then go dark together and start again.

Live preview: https://movin.design/components/loaders/signal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-signal
```

Or copy [`loader-signal.tsx`](./loader-signal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-signal.html`](./loader-signal.html) where it goes and include [`loader-signal.css`](./loader-signal.css). It is pure CSS, so there is no script.
