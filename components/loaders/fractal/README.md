# Fractal loader

A Sierpinski triangle of 27 cells that light up in a wave running through the recursion order, corner by corner, then dim back down, over and over.

Live preview: https://movin.design/components/loaders/fractal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-fractal
```

Or copy [`loader-fractal.tsx`](./loader-fractal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-fractal.html`](./loader-fractal.html) where it goes and include [`loader-fractal.css`](./loader-fractal.css). It is pure CSS, so there is no script.
