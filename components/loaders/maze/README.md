# Maze loader

A generated maze solves itself: the route draws from the entrance in the top corner to the exit in the bottom one, the goal flashes as it arrives, and the line fades before solving again.

Live preview: https://movin.design/components/loaders/maze/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-maze
```

Or copy [`loader-maze.tsx`](./loader-maze.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-maze.html`](./loader-maze.html) where it goes and include [`loader-maze.css`](./loader-maze.css). It is pure CSS, so there is no script.
