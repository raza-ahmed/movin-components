# Slide Puzzle loader

A 3x3 sliding puzzle where the gap walks round the edge forever, so the ring of tiles keeps rotating with a springy slide, the bright key tile riding round with them.

Live preview: https://movin.design/components/loaders/slide-puzzle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-slide-puzzle
```

Or copy [`loader-slide-puzzle.tsx`](./loader-slide-puzzle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`loader-slide-puzzle.html`](./loader-slide-puzzle.html) where it goes and include [`loader-slide-puzzle.css`](./loader-slide-puzzle.css). [`loader-slide-puzzle.js`](./loader-slide-puzzle.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
