# Pendulum Wave loader

A pendulum wave seen from above: twelve bobs swing at slightly different periods, so they fall in and out of step, forming snakes, travelling waves and apparent chaos before lining up in unison again every twelve seconds.

Live preview: https://movin.design/components/loaders/pendulum-wave/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-pendulum-wave
```

Or copy [`loader-pendulum-wave.tsx`](./loader-pendulum-wave.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-pendulum-wave.html`](./loader-pendulum-wave.html) where it goes and include [`loader-pendulum-wave.css`](./loader-pendulum-wave.css). It is pure CSS, so there is no script.
