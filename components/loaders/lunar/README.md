# Lunar loader

The moon running through its phases, new to full and back to new, with a true curved terminator and faint craters showing through.

Live preview: https://movin.design/components/loaders/lunar/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-lunar
```

Or copy [`loader-lunar.tsx`](./loader-lunar.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-lunar.html`](./loader-lunar.html) where it goes and include [`loader-lunar.css`](./loader-lunar.css). It is pure CSS, so there is no script.
