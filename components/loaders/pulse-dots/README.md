# Pulse Dots loader

Three dots that scale and fade in a left-to-right wave. Staggered CSS keyframes, no dependencies.

Live preview: https://movin.design/components/loaders/pulse-dots/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-pulse-dots.json
```

Or copy [`loader-pulse-dots.tsx`](./loader-pulse-dots.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-pulse-dots.html`](./loader-pulse-dots.html) where it goes and include [`loader-pulse-dots.css`](./loader-pulse-dots.css). It is pure CSS, so there is no script.
