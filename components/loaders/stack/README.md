# Stack loader

Three blocks drop one after another onto a shelf and stack up, each landing with a squash and a little recoil, then the finished stack slides off and the next one starts. Pure CSS.

Live preview: https://movin.design/components/loaders/stack/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-stack
```

Or copy [`loader-stack.tsx`](./loader-stack.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-stack.html`](./loader-stack.html) where it goes and include [`loader-stack.css`](./loader-stack.css). It is pure CSS, so there is no script.
