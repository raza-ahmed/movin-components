# Lava loader

A lava lamp. Blobs of wax drift up from a warm pool at the bottom, stretch, pinch off and melt back into it, merging whenever they touch. The goo is a blur + contrast filter on the layer, so there is no SVG filter or id to collide. Pure CSS.

Live preview: https://movin.design/components/loaders/lava/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-lava.json
```

Or copy [`loader-lava.tsx`](./loader-lava.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-lava.html`](./loader-lava.html) where it goes and include [`loader-lava.css`](./loader-lava.css). It is pure CSS, so there is no script.
