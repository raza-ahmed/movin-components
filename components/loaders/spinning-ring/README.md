# Spinning Ring loader

A circular ring with a transparent track and a solid arc that spins continuously. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/spinning-ring/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-spinning-ring.json
```

Or copy [`loader-spinning-ring.tsx`](./loader-spinning-ring.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-spinning-ring.html`](./loader-spinning-ring.html) where it goes and include [`loader-spinning-ring.css`](./loader-spinning-ring.css). It is pure CSS, so there is no script.
