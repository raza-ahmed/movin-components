# Flip Square loader

A gradient rounded square continuously tumbling on its Y axis using CSS 3D perspective: a satisfying single-element loader. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/flip-square/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-flip-square
```

Or copy [`loader-flip-square.tsx`](./loader-flip-square.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-flip-square.html`](./loader-flip-square.html) where it goes and include [`loader-flip-square.css`](./loader-flip-square.css). It is pure CSS, so there is no script.
