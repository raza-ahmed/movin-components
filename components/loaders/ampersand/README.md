# Ampersand loader

An ampersand written in one unbroken stroke behind a glowing nib, held for a moment, then wiped away from where it began.

Live preview: https://movin.design/components/loaders/ampersand/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-ampersand
```

Or copy [`loader-ampersand.tsx`](./loader-ampersand.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-ampersand.html`](./loader-ampersand.html) where it goes and include [`loader-ampersand.css`](./loader-ampersand.css). It is pure CSS, so there is no script.
