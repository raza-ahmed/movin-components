# Odometer loader

Rolling digit reels count from 000 to 100 percent in uneven jumps, like a real transfer; each reel rolls forward through its digits with a little bounce, then the count holds and starts over.

Live preview: https://movin.design/components/loaders/odometer/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-odometer
```

Or copy [`loader-odometer.tsx`](./loader-odometer.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`loader-odometer.html`](./loader-odometer.html) where it goes and include [`loader-odometer.css`](./loader-odometer.css). [`loader-odometer.js`](./loader-odometer.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
