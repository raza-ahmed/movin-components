# Morph loader

A single element that continuously morphs through three shapes — circle, blob, and square — while rotating and shifting color. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/morph/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-morph.json
```

Or copy [`loader-morph.tsx`](./loader-morph.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-morph.html`](./loader-morph.html) where it goes and include [`loader-morph.css`](./loader-morph.css). It is pure CSS, so there is no script.
