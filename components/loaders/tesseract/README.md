# Tesseract loader

A four-dimensional cube, a tesseract, turning through the fourth axis and projected down to a wireframe. The inner and outer cubes swap places endlessly while the whole shadow drifts, and the cube nearer in 4D is drawn brighter.

Live preview: https://movin.design/components/loaders/tesseract/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-tesseract
```

Or copy [`loader-tesseract.tsx`](./loader-tesseract.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`loader-tesseract.html`](./loader-tesseract.html) where it goes and include [`loader-tesseract.css`](./loader-tesseract.css). [`loader-tesseract.js`](./loader-tesseract.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
