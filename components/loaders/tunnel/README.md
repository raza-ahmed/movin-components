# Tunnel loader

Rounded frames rush out of a point of light at the centre, twisting as they come, like flying down a wormhole.

Live preview: https://movin.design/components/loaders/tunnel/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-tunnel
```

Or copy [`loader-tunnel.tsx`](./loader-tunnel.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-tunnel.html`](./loader-tunnel.html) where it goes and include [`loader-tunnel.css`](./loader-tunnel.css). It is pure CSS, so there is no script.
