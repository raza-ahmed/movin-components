# Skeleton loader

A shimmer content placeholder: avatar, name, and body line shapes with a sweeping highlight. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/skeleton/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-skeleton
```

Or copy [`loader-skeleton.tsx`](./loader-skeleton.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-skeleton.html`](./loader-skeleton.html) where it goes and include [`loader-skeleton.css`](./loader-skeleton.css). It is pure CSS, so there is no script.
