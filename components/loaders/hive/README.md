# Hive loader

Seven hexagon cells of a honeycomb: the six outer cells light round the comb in turn while the core pulses at twice the pace.

Live preview: https://movin.design/components/loaders/hive/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-hive
```

Or copy [`loader-hive.tsx`](./loader-hive.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-hive.html`](./loader-hive.html) where it goes and include [`loader-hive.css`](./loader-hive.css). It is pure CSS, so there is no script.
