# Text Shimmer loader

The word "Loading" rendered in uppercase with a bright spotlight sweeping across it via background-clip:text — a text-as-canvas shimmer effect. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/text-shimmer/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-text-shimmer
```

Or copy [`loader-text-shimmer.tsx`](./loader-text-shimmer.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-text-shimmer.html`](./loader-text-shimmer.html) where it goes and include [`loader-text-shimmer.css`](./loader-text-shimmer.css). It is pure CSS, so there is no script.
