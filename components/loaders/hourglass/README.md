# Hourglass loader

An hourglass: sand drains from the top bulb in a thin stream and piles up in the bottom one, then the glass flips over with a little overshoot and it starts again. The flip lands on the exact frame the loop restarts on, so it never jumps. Pure CSS.

Live preview: https://movin.design/components/loaders/hourglass/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-hourglass
```

Or copy [`loader-hourglass.tsx`](./loader-hourglass.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-hourglass.html`](./loader-hourglass.html) where it goes and include [`loader-hourglass.css`](./loader-hourglass.css). It is pure CSS, so there is no script.
