# Line Clear loader

A tiny falling-block game: pieces drop and settle until the bottom rows are complete, the rows flash and clear, and the board starts again.

Live preview: https://movin.design/components/loaders/line-clear/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-line-clear
```

Or copy [`loader-line-clear.tsx`](./loader-line-clear.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`loader-line-clear.html`](./loader-line-clear.html) where it goes and include [`loader-line-clear.css`](./loader-line-clear.css). [`loader-line-clear.js`](./loader-line-clear.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
