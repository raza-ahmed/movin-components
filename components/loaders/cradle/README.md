# Newton's Cradle loader

Five balls hanging from a bar on strings. The end ball swings out and falls back; the knock travels through the still middle three and kicks the far ball out, and back again, with easing that slows at the top of each swing like a real pendulum. Pure CSS.

Live preview: https://movin.design/components/loaders/cradle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-cradle.json
```

Or copy [`loader-cradle.tsx`](./loader-cradle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-cradle.html`](./loader-cradle.html) where it goes and include [`loader-cradle.css`](./loader-cradle.css). It is pure CSS, so there is no script.
