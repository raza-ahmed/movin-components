# Clock loader

A small clock face with twelve ticks: the minute hand sweeps round once a beat while the hour hand creeps along at a twelfth of the speed, so time visibly passes while you wait. Pure CSS.

Live preview: https://movin.design/components/loaders/clock/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-clock
```

Or copy [`loader-clock.tsx`](./loader-clock.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-clock.html`](./loader-clock.html) where it goes and include [`loader-clock.css`](./loader-clock.css). It is pure CSS, so there is no script.
