# Ring Text loader

LOADING · PLEASE WAIT set round a circle like a badge, turning slowly, while a bright highlight chases round the letters and a dot breathes in the middle. Each letter is a span placed by its index. Pure CSS.

Live preview: https://movin.design/components/loaders/ring-text/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-ring-text.json
```

Or copy [`loader-ring-text.tsx`](./loader-ring-text.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-ring-text.html`](./loader-ring-text.html) where it goes and include [`loader-ring-text.css`](./loader-ring-text.css). It is pure CSS, so there is no script.
