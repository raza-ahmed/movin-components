# Binary Star loader

Two stars of different sizes orbit their shared centre with comet trails behind them, while a small planet circles both on a wider, slower path.

Live preview: https://movin.design/components/loaders/binary-star/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-binary-star
```

Or copy [`loader-binary-star.tsx`](./loader-binary-star.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-binary-star.html`](./loader-binary-star.html) where it goes and include [`loader-binary-star.css`](./loader-binary-star.css). It is pure CSS, so there is no script.
