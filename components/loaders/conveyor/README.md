# Conveyor loader

Parcels ride a moving belt over turning rollers, then tip over the end and drop off, one after another.

Live preview: https://movin.design/components/loaders/conveyor/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-conveyor
```

Or copy [`loader-conveyor.tsx`](./loader-conveyor.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-conveyor.html`](./loader-conveyor.html) where it goes and include [`loader-conveyor.css`](./loader-conveyor.css). It is pure CSS, so there is no script.
