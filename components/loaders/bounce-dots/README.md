# Bounce Dots loader

Three dots that bounce vertically in sequence: the classic typing-indicator pattern. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/bounce-dots/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-bounce-dots
```

Or copy [`loader-bounce-dots.tsx`](./loader-bounce-dots.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-bounce-dots.html`](./loader-bounce-dots.html) where it goes and include [`loader-bounce-dots.css`](./loader-bounce-dots.css). It is pure CSS, so there is no script.
