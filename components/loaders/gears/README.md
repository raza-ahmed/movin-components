# Gears loader

Two meshed gears, ten teeth and seven, turning against each other at the right ratio (the small one 10/7 as fast) so the teeth stay engaged all the way round. The tooth outlines are generated from real gear geometry. Pure CSS rotation.

Live preview: https://movin.design/components/loaders/gears/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-gears
```

Or copy [`loader-gears.tsx`](./loader-gears.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-gears.html`](./loader-gears.html) where it goes and include [`loader-gears.css`](./loader-gears.css). It is pure CSS, so there is no script.
