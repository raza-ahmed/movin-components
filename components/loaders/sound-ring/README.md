# Sound Ring loader

A circular spectrum: forty bars round a ring pump to their own beats in clusters, like frequency bands, while the whole ring turns slowly.

Live preview: https://movin.design/components/loaders/sound-ring/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-sound-ring
```

Or copy [`loader-sound-ring.tsx`](./loader-sound-ring.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-sound-ring.html`](./loader-sound-ring.html) where it goes and include [`loader-sound-ring.css`](./loader-sound-ring.css). It is pure CSS, so there is no script.
