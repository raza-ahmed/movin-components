# Tumble loader

A block tumbles over and over along a dashed floor: it tips onto its next face about its leading corner and lands, again and again, while the floor slides back under it in step, so it rolls forever without leaving its spot. Pure CSS.

Live preview: https://movin.design/components/loaders/tumble/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-tumble.json
```

Or copy [`loader-tumble.tsx`](./loader-tumble.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-tumble.html`](./loader-tumble.html) where it goes and include [`loader-tumble.css`](./loader-tumble.css). It is pure CSS, so there is no script.
