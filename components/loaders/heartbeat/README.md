# Heartbeat loader

A heart monitor: a bright trace with a fading tail runs across the screen through a spike, led by a glowing dot that rides the same line, and fades out at the edges before coming round again. Pure CSS.

Live preview: https://movin.design/components/loaders/heartbeat/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-heartbeat.json
```

Or copy [`loader-heartbeat.tsx`](./loader-heartbeat.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-heartbeat.html`](./loader-heartbeat.html) where it goes and include [`loader-heartbeat.css`](./loader-heartbeat.css). It is pure CSS, so there is no script.
