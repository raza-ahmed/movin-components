# Equalizer loader

Five bars each running an independent height animation at a different duration — the unsynchronized cadences create an organic music-equalizer feel. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/equalizer/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-equalizer.json
```

Or copy [`loader-equalizer.tsx`](./loader-equalizer.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-equalizer.html`](./loader-equalizer.html) where it goes and include [`loader-equalizer.css`](./loader-equalizer.css). It is pure CSS, so there is no script.
