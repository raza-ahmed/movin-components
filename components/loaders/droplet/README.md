# Droplet loader

A drop falls, stretching as it speeds up, splashes a crown of beads up off the surface and sends two ripples spreading outward.

Live preview: https://movin.design/components/loaders/droplet/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-droplet
```

Or copy [`loader-droplet.tsx`](./loader-droplet.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-droplet.html`](./loader-droplet.html) where it goes and include [`loader-droplet.css`](./loader-droplet.css). It is pure CSS, so there is no script.
