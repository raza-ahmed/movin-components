# Dual Ring loader

Two concentric rings rotating in opposite directions at different speeds — bright outer ring clockwise, dimmer inner ring counter-clockwise. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/dual-ring/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-dual-ring.json
```

Or copy [`loader-dual-ring.tsx`](./loader-dual-ring.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-dual-ring.html`](./loader-dual-ring.html) where it goes and include [`loader-dual-ring.css`](./loader-dual-ring.css). It is pure CSS, so there is no script.
