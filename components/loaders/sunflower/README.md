# Sunflower loader

Forty-eight dots laid out the way seeds pack in a sunflower head (each turned by the golden angle and pushed out by the square root of its index), with a wave of light pulsing out from the centre as the head turns slowly. The layout is CSS maths on one index per dot. Pure CSS.

Live preview: https://movin.design/components/loaders/sunflower/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-sunflower.json
```

Or copy [`loader-sunflower.tsx`](./loader-sunflower.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-sunflower.html`](./loader-sunflower.html) where it goes and include [`loader-sunflower.css`](./loader-sunflower.css). It is pure CSS, so there is no script.
