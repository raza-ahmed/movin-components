# Fireflies loader

Seven fireflies drifting on their own slow paths and blinking in turn, each with a different pace and rhythm.

Live preview: https://movin.design/components/loaders/fireflies/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-fireflies
```

Or copy [`loader-fireflies.tsx`](./loader-fireflies.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-fireflies.html`](./loader-fireflies.html) where it goes and include [`loader-fireflies.css`](./loader-fireflies.css). It is pure CSS, so there is no script.
