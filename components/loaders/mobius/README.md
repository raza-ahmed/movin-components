# Mobius loader

A Mobius band built from slices: each one is twisted by half its angle round the loop, so the band carries a single half twist. The slices roll round their own loop endlessly while the whole band turns slowly in 3D.

Live preview: https://movin.design/components/loaders/mobius/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-mobius
```

Or copy [`loader-mobius.tsx`](./loader-mobius.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-mobius.html`](./loader-mobius.html) where it goes and include [`loader-mobius.css`](./loader-mobius.css). It is pure CSS, so there is no script.
