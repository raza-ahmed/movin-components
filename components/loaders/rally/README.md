# Rally loader

Two paddles keep a ball in play across a dashed net, like the first video game: the ball bounces off the walls, picks up a little spin off each paddle, and each paddle tracks it only while it is coming its way.

Live preview: https://movin.design/components/loaders/rally/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-rally
```

Or copy [`loader-rally.tsx`](./loader-rally.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`loader-rally.html`](./loader-rally.html) where it goes and include [`loader-rally.css`](./loader-rally.css). [`loader-rally.js`](./loader-rally.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
