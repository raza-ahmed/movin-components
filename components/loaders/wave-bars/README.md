# Wave Bars loader

Five vertical bars in distinct colors that scale up and down in a rippling wave sequence. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/wave-bars/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-wave-bars.json
```

Or copy [`loader-wave-bars.tsx`](./loader-wave-bars.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-wave-bars.html`](./loader-wave-bars.html) where it goes and include [`loader-wave-bars.css`](./loader-wave-bars.css). It is pure CSS, so there is no script.
