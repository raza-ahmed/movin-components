# Color Bounce loader

Five dots (each a step lighter than the last), bouncing vertically in a rolling wave. A tonalul take on the classic typing indicator. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/color-bounce/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-color-bounce
```

Or copy [`loader-color-bounce.tsx`](./loader-color-bounce.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-color-bounce.html`](./loader-color-bounce.html) where it goes and include [`loader-color-bounce.css`](./loader-color-bounce.css). It is pure CSS, so there is no script.
