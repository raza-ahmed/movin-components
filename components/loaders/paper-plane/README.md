# Paper Plane loader

A paper plane loops the loop along a dotted flight path, banking to follow every curve, then flies out and round again.

Live preview: https://movin.design/components/loaders/paper-plane/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-paper-plane
```

Or copy [`loader-paper-plane.tsx`](./loader-paper-plane.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-paper-plane.html`](./loader-paper-plane.html) where it goes and include [`loader-paper-plane.css`](./loader-paper-plane.css). It is pure CSS, so there is no script.
