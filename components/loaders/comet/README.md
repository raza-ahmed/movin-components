# Comet loader

A conic-gradient ring that spins like a comet tail: gray-to-white arc on a masked circle. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/comet/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-comet
```

Or copy [`loader-comet.tsx`](./loader-comet.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-comet.html`](./loader-comet.html) where it goes and include [`loader-comet.css`](./loader-comet.css). It is pure CSS, so there is no script.
