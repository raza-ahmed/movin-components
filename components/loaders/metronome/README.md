# Metronome loader

A metronome: the weighted arm swings across its scale and a light flashes at each end of the arc, exactly on the beat.

Live preview: https://movin.design/components/loaders/metronome/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-metronome
```

Or copy [`loader-metronome.tsx`](./loader-metronome.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-metronome.html`](./loader-metronome.html) where it goes and include [`loader-metronome.css`](./loader-metronome.css). It is pure CSS, so there is no script.
