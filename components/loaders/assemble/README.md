# Assemble loader

Sixteen scattered particles fly in from all sides and lock together into a block, the block turns a quarter, then bursts apart in new directions and gathers again.

Live preview: https://movin.design/components/loaders/assemble/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-assemble
```

Or copy [`loader-assemble.tsx`](./loader-assemble.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-assemble.html`](./loader-assemble.html) where it goes and include [`loader-assemble.css`](./loader-assemble.css). It is pure CSS, so there is no script.
