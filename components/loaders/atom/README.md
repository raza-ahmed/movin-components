# Atom loader

A glowing nucleus with three electrons on orbits tilted 60 degrees apart, each racing round its own ellipse at a different speed. The orbits are rotated boxes and each electron rides an elliptical offset-path inside its own. Pure CSS.

Live preview: https://movin.design/components/loaders/atom/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-atom.json
```

Or copy [`loader-atom.tsx`](./loader-atom.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-atom.html`](./loader-atom.html) where it goes and include [`loader-atom.css`](./loader-atom.css). It is pure CSS, so there is no script.
