# Loom loader

A loom weaving: a shuttle carries the weft over and under the warp threads, row by row and back again, until the cloth is woven, then it is cleared and begins again.

Live preview: https://movin.design/components/loaders/loom/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-loom
```

Or copy [`loader-loom.tsx`](./loader-loom.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-loom.html`](./loader-loom.html) where it goes and include [`loader-loom.css`](./loader-loom.css). It is pure CSS, so there is no script.
