# Event Horizon loader

A black hole: a spinning accretion disc passes in front of the hole, and light from the disc's far side is lensed into a glowing ring arching up and over it, flickering softly.

Live preview: https://movin.design/components/loaders/event-horizon/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-event-horizon
```

Or copy [`loader-event-horizon.tsx`](./loader-event-horizon.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-event-horizon.html`](./loader-event-horizon.html) where it goes and include [`loader-event-horizon.css`](./loader-event-horizon.css). It is pure CSS, so there is no script.
