# Vortex loader

Particles spiral in from the rim of a vortex, slow at the edge and whipping round faster as they fall toward a pulsing dark core.

Live preview: https://movin.design/components/loaders/vortex/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-vortex
```

Or copy [`loader-vortex.tsx`](./loader-vortex.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-vortex.html`](./loader-vortex.html) where it goes and include [`loader-vortex.css`](./loader-vortex.css). It is pure CSS, so there is no script.
