# Bouncing Ball loader

A squash-and-stretch ball with a synced shadow: multi-stop keyframes fake physical bounce physics. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/bouncing-ball/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-bouncing-ball
```

Or copy [`loader-bouncing-ball.tsx`](./loader-bouncing-ball.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-bouncing-ball.html`](./loader-bouncing-ball.html) where it goes and include [`loader-bouncing-ball.css`](./loader-bouncing-ball.css). It is pure CSS, so there is no script.
