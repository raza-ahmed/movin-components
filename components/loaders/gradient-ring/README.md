# Gradient Ring loader

A spinning ring with a light-to-dark conic gradient in one continuous arc. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/gradient-ring/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-gradient-ring.json
```

Or copy [`loader-gradient-ring.tsx`](./loader-gradient-ring.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-gradient-ring.html`](./loader-gradient-ring.html) where it goes and include [`loader-gradient-ring.css`](./loader-gradient-ring.css). It is pure CSS, so there is no script.
