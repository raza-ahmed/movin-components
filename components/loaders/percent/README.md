# Percent loader

A progress ring with a percentage that loads the way real progress feels: a quick start, a long slow middle, a stall near the end, then the last stretch at once, a tick, and round again.

Live preview: https://movin.design/components/loaders/percent/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-percent
```

Or copy [`loader-percent.tsx`](./loader-percent.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`loader-percent.html`](./loader-percent.html) where it goes and include [`loader-percent.css`](./loader-percent.css). [`loader-percent.js`](./loader-percent.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
