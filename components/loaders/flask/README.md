# Flask loader

A round-bottom flask fills with a sloshing liquid as bubbles rise through it, holds full for a moment, then drains, over and over.

Live preview: https://movin.design/components/loaders/flask/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-flask
```

Or copy [`loader-flask.tsx`](./loader-flask.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`loader-flask.html`](./loader-flask.html) where it goes and include [`loader-flask.css`](./loader-flask.css). [`loader-flask.js`](./loader-flask.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
