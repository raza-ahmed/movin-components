# Seam loader

A needle sews a line of stitches round a rounded square of cloth with the thread following it, then the seam is pulled away and it starts again.

Live preview: https://movin.design/components/loaders/seam/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-seam
```

Or copy [`loader-seam.tsx`](./loader-seam.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-seam.html`](./loader-seam.html) where it goes and include [`loader-seam.css`](./loader-seam.css). It is pure CSS, so there is no script.
