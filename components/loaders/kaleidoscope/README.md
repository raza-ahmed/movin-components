# Kaleidoscope loader

A turning kaleidoscope: three drifting shapes in one wedge are mirrored into six, so they meet and part in symmetric patterns while the whole disc slowly rotates.

Live preview: https://movin.design/components/loaders/kaleidoscope/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-kaleidoscope
```

Or copy [`loader-kaleidoscope.tsx`](./loader-kaleidoscope.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-kaleidoscope.html`](./loader-kaleidoscope.html) where it goes and include [`loader-kaleidoscope.css`](./loader-kaleidoscope.css). It is pure CSS, so there is no script.
