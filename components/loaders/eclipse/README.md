# Eclipse loader

A solar eclipse on loop: the moon slides across the sun, slowing as it covers it, and at totality the corona flares out around the black disc before the moon drifts on and the sun returns. Pure CSS.

Live preview: https://movin.design/components/loaders/eclipse/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-eclipse
```

Or copy [`loader-eclipse.tsx`](./loader-eclipse.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-eclipse.html`](./loader-eclipse.html) where it goes and include [`loader-eclipse.css`](./loader-eclipse.css). It is pure CSS, so there is no script.
