# Neon Ripple loader

Three concentric light rings that expand outward from a glowing core dot. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/neon-ripple/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-neon-ripple.json
```

Or copy [`loader-neon-ripple.tsx`](./loader-neon-ripple.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-neon-ripple.html`](./loader-neon-ripple.html) where it goes and include [`loader-neon-ripple.css`](./loader-neon-ripple.css). It is pure CSS, so there is no script.
