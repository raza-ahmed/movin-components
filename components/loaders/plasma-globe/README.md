# Plasma Globe loader

A plasma globe: live filaments crawl from the glowing electrode out to the glass, each wandering and flickering, their feet drifting slowly round the sphere where they strike it.

Live preview: https://movin.design/components/loaders/plasma-globe/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-plasma-globe
```

Or copy [`loader-plasma-globe.tsx`](./loader-plasma-globe.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`loader-plasma-globe.html`](./loader-plasma-globe.html) where it goes and include [`loader-plasma-globe.css`](./loader-plasma-globe.css). [`loader-plasma-globe.js`](./loader-plasma-globe.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
