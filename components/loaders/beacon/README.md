# Beacon loader

A lighthouse on its rock: the beam sweeps round, narrowing and flaring as it faces you, then swings out the other side, over a slow rolling sea.

Live preview: https://movin.design/components/loaders/beacon/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-beacon
```

Or copy [`loader-beacon.tsx`](./loader-beacon.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-beacon.html`](./loader-beacon.html) where it goes and include [`loader-beacon.css`](./loader-beacon.css). It is pure CSS, so there is no script.
