# Mosaic loader

A 3×3 grid of grayscale tiles that pulse in and out with a ripple delay, creating a vibrant mosaic shimmer effect. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/mosaic/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-mosaic
```

Or copy [`loader-mosaic.tsx`](./loader-mosaic.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-mosaic.html`](./loader-mosaic.html) where it goes and include [`loader-mosaic.css`](./loader-mosaic.css). It is pure CSS, so there is no script.
