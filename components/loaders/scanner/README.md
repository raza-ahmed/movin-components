# Scanner loader

A barcode scanner: a laser line sweeps up and down the code while a band of light travels with it, lighting each bar it crosses.

Live preview: https://movin.design/components/loaders/scanner/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-scanner
```

Or copy [`loader-scanner.tsx`](./loader-scanner.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-scanner.html`](./loader-scanner.html) where it goes and include [`loader-scanner.css`](./loader-scanner.css). It is pure CSS, so there is no script.
