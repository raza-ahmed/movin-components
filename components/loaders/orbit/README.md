# Orbit loader

A dot orbits a center point along a faint circular track. Pure CSS rotation, no dependencies.

Live preview: https://movin.design/components/loaders/orbit/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-orbit
```

Or copy [`loader-orbit.tsx`](./loader-orbit.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-orbit.html`](./loader-orbit.html) where it goes and include [`loader-orbit.css`](./loader-orbit.css). It is pure CSS, so there is no script.
