# Fold loader

A square of paper folds in half from the bottom, then in half again from the right, holds, and opens back out, with each flap shading darker as it turns away from the light.

Live preview: https://movin.design/components/loaders/fold/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-fold
```

Or copy [`loader-fold.tsx`](./loader-fold.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-fold.html`](./loader-fold.html) where it goes and include [`loader-fold.css`](./loader-fold.css). It is pure CSS, so there is no script.
