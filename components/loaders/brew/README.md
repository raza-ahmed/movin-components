# Brew loader

A cup of coffee on its saucer with three threads of steam curling up and thinning out, each on its own rhythm.

Live preview: https://movin.design/components/loaders/brew/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-brew
```

Or copy [`loader-brew.tsx`](./loader-brew.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-brew.html`](./loader-brew.html) where it goes and include [`loader-brew.css`](./loader-brew.css). It is pure CSS, so there is no script.
