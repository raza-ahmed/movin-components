# Dots Circle loader

Eight dots arranged in a clock face, fading in and out in radial sequence — the classic OS-native loading indicator pattern. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/dots-circle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-dots-circle
```

Or copy [`loader-dots-circle.tsx`](./loader-dots-circle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-dots-circle.html`](./loader-dots-circle.html) where it goes and include [`loader-dots-circle.css`](./loader-dots-circle.css). It is pure CSS, so there is no script.
