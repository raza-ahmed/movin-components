# Globe loader

A wireframe planet of meridians and latitude rings spinning in 3D, with a satellite on a tilted orbit circling it.

Live preview: https://movin.design/components/loaders/globe/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-globe
```

Or copy [`loader-globe.tsx`](./loader-globe.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-globe.html`](./loader-globe.html) where it goes and include [`loader-globe.css`](./loader-globe.css). It is pure CSS, so there is no script.
