# Coil loader

A weight bobs on a spring hanging from a bar. The coil stretches open as the weight drops and bunches tight as it rises, with the back half of every turn drawn dimmer so it reads as a helix.

Live preview: https://movin.design/components/loaders/coil/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-coil
```

Or copy [`loader-coil.tsx`](./loader-coil.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-coil.html`](./loader-coil.html) where it goes and include [`loader-coil.css`](./loader-coil.css). It is pure CSS, so there is no script.
