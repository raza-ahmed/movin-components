# Sundial loader

The sun arcs over a sundial and the gnomon's shadow sweeps across the hours, long in the morning, short at noon and long again by evening.

Live preview: https://movin.design/components/loaders/sundial/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-sundial
```

Or copy [`loader-sundial.tsx`](./loader-sundial.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-sundial.html`](./loader-sundial.html) where it goes and include [`loader-sundial.css`](./loader-sundial.css). It is pure CSS, so there is no script.
