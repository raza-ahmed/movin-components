# Terrain loader

A plane of dots seen in perspective rolls with crossing waves, the crests rising and brightening, like a landscape breathing.

Live preview: https://movin.design/components/loaders/terrain/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-terrain
```

Or copy [`loader-terrain.tsx`](./loader-terrain.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-terrain.html`](./loader-terrain.html) where it goes and include [`loader-terrain.css`](./loader-terrain.css). It is pure CSS, so there is no script.
