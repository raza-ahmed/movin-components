# Infinity loader

A bright streak with a fading tail races endlessly round a figure-eight track, crossing itself in the middle. Two dash segments on the same SVG path, offset so the head always leads the tail. Pure CSS.

Live preview: https://movin.design/components/loaders/infinity/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-infinity
```

Or copy [`loader-infinity.tsx`](./loader-infinity.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-infinity.html`](./loader-infinity.html) where it goes and include [`loader-infinity.css`](./loader-infinity.css). It is pure CSS, so there is no script.
