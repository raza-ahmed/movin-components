# Galaxy loader

Two spiral arms of twinkling stars wheel slowly round a glowing core, the outer stars smaller and fainter.

Live preview: https://movin.design/components/loaders/galaxy/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-galaxy
```

Or copy [`loader-galaxy.tsx`](./loader-galaxy.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-galaxy.html`](./loader-galaxy.html) where it goes and include [`loader-galaxy.css`](./loader-galaxy.css). It is pure CSS, so there is no script.
