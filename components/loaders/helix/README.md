# Helix loader

Two dots oscillating vertically in opposite phase with scaleX depth — a DNA helix cross-section effect. Pure CSS, no dependencies.

Live preview: https://movin.design/components/loaders/helix/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-helix.json
```

Or copy [`loader-helix.tsx`](./loader-helix.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-helix.html`](./loader-helix.html) where it goes and include [`loader-helix.css`](./loader-helix.css). It is pure CSS, so there is no script.
