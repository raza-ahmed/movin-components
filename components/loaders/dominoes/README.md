# Dominoes loader

Seven dominoes topple in a chain, each falling faster as it goes and coming to rest leaning on the next (the last one falls flat), then they stand back up one by one in the same order. Pure CSS.

Live preview: https://movin.design/components/loaders/dominoes/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/loader-dominoes.json
```

Or copy [`loader-dominoes.tsx`](./loader-dominoes.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`loader-dominoes.html`](./loader-dominoes.html) where it goes and include [`loader-dominoes.css`](./loader-dominoes.css). It is pure CSS, so there is no script.
