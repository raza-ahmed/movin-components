# Pixel Spinner loader

A chunky 8-bit spinner: a ring of square pixels with a bright segment and a fading tail stepping round it, one pixel at a time.

Live preview: https://movin.design/components/loaders/pixel-spinner/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/loader-pixel-spinner
```

Or copy [`loader-pixel-spinner.tsx`](./loader-pixel-spinner.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`loader-pixel-spinner.html`](./loader-pixel-spinner.html) where it goes and include [`loader-pixel-spinner.css`](./loader-pixel-spinner.css). [`loader-pixel-spinner.js`](./loader-pixel-spinner.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
