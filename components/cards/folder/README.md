# Folder card

A file folder that opens on hover: the front flap tilts down toward you and the papers inside fan up and out, one after another.

Live preview: https://movin.design/components/cards/folder/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-folder
```

Or copy [`card-folder.tsx`](./card-folder.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-folder.html`](./card-folder.html) where it goes and include [`card-folder.css`](./card-folder.css). It is pure CSS, so there is no script.
