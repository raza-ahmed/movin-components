# Showcase card

A product on a turntable: a small 3D cube speaker turns slowly on a plinth above its own floor reflection. Hover spins the turntable up without a jump and sweeps a band of light across the card.

Live preview: https://movin.design/components/cards/showcase/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-showcase
```

Or copy [`card-showcase.tsx`](./card-showcase.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-showcase.html`](./card-showcase.html) where it goes and include [`card-showcase.css`](./card-showcase.css). [`card-showcase.js`](./card-showcase.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
