# Countdown card

A launch countdown: days, hours, minutes and seconds on rolling digit reels that spring to each new value, with a small ring draining once a minute in the corner.

Live preview: https://movin.design/components/cards/countdown/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-countdown
```

Or copy [`card-countdown.tsx`](./card-countdown.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-countdown.html`](./card-countdown.html) where it goes and include [`card-countdown.css`](./card-countdown.css). [`card-countdown.js`](./card-countdown.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
