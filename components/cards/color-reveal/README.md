# Color Reveal card

A solid mid-gray overlay slides up from the bottom on hover, fully covering the card with secondary content. Pure CSS transitions, no dependencies.

Live preview: https://movin.design/components/cards/color-reveal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/card-color-reveal.json
```

Or copy [`card-color-reveal.tsx`](./card-color-reveal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-color-reveal.html`](./card-color-reveal.html) where it goes and include [`card-color-reveal.css`](./card-color-reveal.css). It is pure CSS, so there is no script.
