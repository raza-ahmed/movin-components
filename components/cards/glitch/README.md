# Glitch card

On hover, two ghost copies of the card clip to random horizontal bands and translate sideways (one inverted, one overexposed), simulating a corrupted signal. Pure CSS keyframes with step() timing for a digital glitch aesthetic.

Live preview: https://movin.design/components/cards/glitch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-glitch
```

Or copy [`card-glitch.tsx`](./card-glitch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-glitch.html`](./card-glitch.html) where it goes and include [`card-glitch.css`](./card-glitch.css). It is pure CSS, so there is no script.
