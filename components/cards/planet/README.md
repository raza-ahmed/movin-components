# Planet card

A planet card: a shaded world turns as its cloud bands drift across it, and a small moon orbits, passing behind the planet and then in front of it.

Live preview: https://movin.design/components/cards/planet/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-planet
```

Or copy [`card-planet.tsx`](./card-planet.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-planet.html`](./card-planet.html) where it goes and include [`card-planet.css`](./card-planet.css). It is pure CSS, so there is no script.
