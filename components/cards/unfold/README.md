# Unfold card

A folded walking map. Hover and the gatefold flaps swing open in 3D, right then left, the inside catches the light, and the route draws across the map with its stops popping in.

Live preview: https://movin.design/components/cards/unfold/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-unfold
```

Or copy [`card-unfold.tsx`](./card-unfold.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-unfold.html`](./card-unfold.html) where it goes and include [`card-unfold.css`](./card-unfold.css). It is pure CSS, so there is no script.
