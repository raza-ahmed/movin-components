# Lenticular card

A ridged plastic lenticular card holding two pictures. Moving across it tilts the card and switches day to night through interleaved strips that widen with a registered custom property, flickering exactly like printed lenticulars, with a sheen running along the ridges.

Live preview: https://movin.design/components/cards/lenticular/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/card-lenticular.json
```

Or copy [`card-lenticular.tsx`](./card-lenticular.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-lenticular.html`](./card-lenticular.html) where it goes and include [`card-lenticular.css`](./card-lenticular.css). [`card-lenticular.js`](./card-lenticular.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
