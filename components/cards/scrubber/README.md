# Scrubber card

A month schedule you flick through: drag or flick the ruler and it glides on with momentum before snapping to a day, the ticks swell under the needle like a dock, and each day's events flip in from the direction you moved.

Live preview: https://movin.design/components/cards/scrubber/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-scrubber
```

Or copy [`card-scrubber.tsx`](./card-scrubber.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-scrubber.html`](./card-scrubber.html) where it goes and include [`card-scrubber.css`](./card-scrubber.css). [`card-scrubber.js`](./card-scrubber.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
