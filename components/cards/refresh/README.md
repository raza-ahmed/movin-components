# Refresh card

A feed you pull down to refresh: the list stretches with growing resistance, the arrow turns over as you near the release point, and letting go spins a loader and slides a new item in.

Live preview: https://movin.design/components/cards/refresh/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-refresh
```

Or copy [`card-refresh.tsx`](./card-refresh.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-refresh.html`](./card-refresh.html) where it goes and include [`card-refresh.css`](./card-refresh.css). [`card-refresh.js`](./card-refresh.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
