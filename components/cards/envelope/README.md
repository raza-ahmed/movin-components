# Envelope card

An envelope with a seal. On hover the flap swings open in 3D and, once past edge-on, drops behind the letter through a delayed z-index; then an invitation card slides up out of the pocket. Leaving reverses it in order. Pure CSS.

Live preview: https://movin.design/components/cards/envelope/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-envelope
```

Or copy [`card-envelope.tsx`](./card-envelope.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-envelope.html`](./card-envelope.html) where it goes and include [`card-envelope.css`](./card-envelope.css). It is pure CSS, so there is no script.
