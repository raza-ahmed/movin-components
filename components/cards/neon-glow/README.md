# Neon Glow card

On hover the card border lights up in silver and a layered box-shadow creates a bright neon halo effect. Pure CSS transitions, no dependencies.

Live preview: https://movin.design/components/cards/neon-glow/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-neon-glow
```

Or copy [`card-neon-glow.tsx`](./card-neon-glow.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-neon-glow.html`](./card-neon-glow.html) where it goes and include [`card-neon-glow.css`](./card-neon-glow.css). It is pure CSS, so there is no script.
