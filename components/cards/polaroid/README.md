# Polaroid card

An instant photo that develops as you hover: the milky film clears and the blurred, flat image sharpens and gains contrast over a couple of seconds, while the print tilts and lifts. A handwritten caption sits on the white border.

Live preview: https://movin.design/components/cards/polaroid/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-polaroid
```

Or copy [`card-polaroid.tsx`](./card-polaroid.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-polaroid.html`](./card-polaroid.html) where it goes and include [`card-polaroid.css`](./card-polaroid.css). It is pure CSS, so there is no script.
