# Wipe Reveal card

Hover sweeps a clip-path from inset(0 0 100% 0) to inset(0 0 0 0): a bottom-to-top wipe that reveals hidden card content. A placeholder state fades out simultaneously. Sharp cubic-bezier easing gives the reveal a crisp, decisive feel.

Live preview: https://movin.design/components/cards/wipe-reveal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-wipe-reveal
```

Or copy [`card-wipe-reveal.tsx`](./card-wipe-reveal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-wipe-reveal.html`](./card-wipe-reveal.html) where it goes and include [`card-wipe-reveal.css`](./card-wipe-reveal.css). It is pure CSS, so there is no script.
