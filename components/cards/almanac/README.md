# Almanac card

A tear-off desk calendar card: click it and today's page tears free from the binding, twists and drops away, showing tomorrow underneath.

Live preview: https://movin.design/components/cards/almanac/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-almanac
```

Or copy [`card-almanac.tsx`](./card-almanac.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-almanac.html`](./card-almanac.html) where it goes and include [`card-almanac.css`](./card-almanac.css). [`card-almanac.js`](./card-almanac.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
