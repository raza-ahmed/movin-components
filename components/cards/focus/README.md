# Focus card

A scene in depth that you focus like a camera: move the pointer up and down and the focus pulls between the far mountains and the near grass, with a distance readout and a scale marker following.

Live preview: https://movin.design/components/cards/focus/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-focus
```

Or copy [`card-focus.tsx`](./card-focus.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-focus.html`](./card-focus.html) where it goes and include [`card-focus.css`](./card-focus.css). [`card-focus.js`](./card-focus.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
