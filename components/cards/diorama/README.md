# Diorama card

A paper-cut landscape behind a window frame. On hover the card turns in 3D and its four paper layers (sky, far mountains, near hills, frame) pull apart in depth, each casting a shadow on the next; the cursor keeps steering the turn.

Live preview: https://movin.design/components/cards/diorama/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/card-diorama.json
```

Or copy [`card-diorama.tsx`](./card-diorama.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-diorama.html`](./card-diorama.html) where it goes and include [`card-diorama.css`](./card-diorama.css). [`card-diorama.js`](./card-diorama.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
