# Dimmer card

A smart-light card: drag the wide slider and the bulb fills with light, the card warms with a glow behind it and the readout follows, down to Off.

Live preview: https://movin.design/components/cards/dimmer/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-dimmer
```

Or copy [`card-dimmer.tsx`](./card-dimmer.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-dimmer.html`](./card-dimmer.html) where it goes and include [`card-dimmer.css`](./card-dimmer.css). [`card-dimmer.js`](./card-dimmer.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
