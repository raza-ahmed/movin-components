# Rings card

An activity rings card: each ring sweeps round from empty to its share of the goal, a beat after the one outside it, with the totals listed beside them.

Live preview: https://movin.design/components/cards/rings/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-rings
```

Or copy [`card-rings.tsx`](./card-rings.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-rings.html`](./card-rings.html) where it goes and include [`card-rings.css`](./card-rings.css). [`card-rings.js`](./card-rings.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
