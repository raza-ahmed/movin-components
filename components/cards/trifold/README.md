# Tri-fold card

A folded brochure showing its cover. On hover the right panel swings open, then the left, each shading as it turns away from the light, laying out three steps side by side; leaving folds it back up in reverse order. Pure CSS.

Live preview: https://movin.design/components/cards/trifold/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/card-trifold.json
```

Or copy [`card-trifold.tsx`](./card-trifold.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-trifold.html`](./card-trifold.html) where it goes and include [`card-trifold.css`](./card-trifold.css). It is pure CSS, so there is no script.
