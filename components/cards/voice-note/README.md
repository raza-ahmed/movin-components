# Voice Note card

A voice-note bubble: press play and the waveform fills from left to right as it plays while the timer counts, click anywhere on the waveform to seek, and it stops and resets at the end.

Live preview: https://movin.design/components/cards/voice-note/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-voice-note
```

Or copy [`card-voice-note.tsx`](./card-voice-note.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-voice-note.html`](./card-voice-note.html) where it goes and include [`card-voice-note.css`](./card-voice-note.css). [`card-voice-note.js`](./card-voice-note.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
