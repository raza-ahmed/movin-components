# Wallet card

A leather wallet card: on hover the three cards inside fan up out of the stitched pocket, each to its own angle, a beat apart.

Live preview: https://movin.design/components/cards/wallet/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-wallet
```

Or copy [`card-wallet.tsx`](./card-wallet.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-wallet.html`](./card-wallet.html) where it goes and include [`card-wallet.css`](./card-wallet.css). It is pure CSS, so there is no script.
