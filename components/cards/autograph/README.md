# Autograph card

A profile card whose signature writes itself on the line when you hover, the name first and then the flourish, at a pen's pace.

Live preview: https://movin.design/components/cards/autograph/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-autograph
```

Or copy [`card-autograph.tsx`](./card-autograph.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-autograph.html`](./card-autograph.html) where it goes and include [`card-autograph.css`](./card-autograph.css). It is pure CSS, so there is no script.
