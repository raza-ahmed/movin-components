# Compass card

A compass card whose needle swings toward the cursor anywhere on the page with a damped wobble, overshooting and settling like a real needle; left alone it hunts gently. The heading and direction read out below.

Live preview: https://movin.design/components/cards/compass/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-compass
```

Or copy [`card-compass.tsx`](./card-compass.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-compass.html`](./card-compass.html) where it goes and include [`card-compass.css`](./card-compass.css). [`card-compass.js`](./card-compass.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
