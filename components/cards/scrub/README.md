# Scrub card

A video card you preview by moving across the thumbnail: the pointer position picks the frame of a paper plane's flight, a bar under it tracks the position and a chip shows the time.

Live preview: https://movin.design/components/cards/scrub/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-scrub
```

Or copy [`card-scrub.tsx`](./card-scrub.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-scrub.html`](./card-scrub.html) where it goes and include [`card-scrub.css`](./card-scrub.css). [`card-scrub.js`](./card-scrub.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
