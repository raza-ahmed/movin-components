# Cube card

A stats card with four faces on a 3D cube: the arrow buttons turn it to the next face with a springy rotation, and the dots below track which face is showing.

Live preview: https://movin.design/components/cards/cube/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-cube
```

Or copy [`card-cube.tsx`](./card-cube.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-cube.html`](./card-cube.html) where it goes and include [`card-cube.css`](./card-cube.css). [`card-cube.js`](./card-cube.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
