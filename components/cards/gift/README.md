# Gift card

A gift card in a box: click and the bow unties, the lid lifts off and tips away, then the card with its code rises out of the box with a little overshoot.

Live preview: https://movin.design/components/cards/gift/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-gift
```

Or copy [`card-gift.tsx`](./card-gift.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-gift.html`](./card-gift.html) where it goes and include [`card-gift.css`](./card-gift.css). [`card-gift.js`](./card-gift.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
