# Layers card

Hover explodes the card into its stacked layers in isometric view, like a design file: surface, media, text and action float apart in depth, each labelled with its name.

Live preview: https://movin.design/components/cards/layers/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-layers
```

Or copy [`card-layers.tsx`](./card-layers.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-layers.html`](./card-layers.html) where it goes and include [`card-layers.css`](./card-layers.css). It is pure CSS, so there is no script.
