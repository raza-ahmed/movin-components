# Poll card

A poll card: vote and the options turn into result bars that grow to their share one after another while the percentages count up, with your choice ticked.

Live preview: https://movin.design/components/cards/poll/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-poll
```

Or copy [`card-poll.tsx`](./card-poll.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-poll.html`](./card-poll.html) where it goes and include [`card-poll.css`](./card-poll.css). [`card-poll.js`](./card-poll.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
