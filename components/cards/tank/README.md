# Tank card

A storage card filled with liquid. Move the cursor across it and the liquid leans toward you and sloshes, stirring the surface where you cross it; Clean up drains it to a lower level with a splash, and the percentage follows.

Live preview: https://movin.design/components/cards/tank/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-tank
```

Or copy [`card-tank.tsx`](./card-tank.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-tank.html`](./card-tank.html) where it goes and include [`card-tank.css`](./card-tank.css). [`card-tank.js`](./card-tank.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
