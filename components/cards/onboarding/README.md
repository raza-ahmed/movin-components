# Onboarding card

A three-step intro card: Next slides the new step in from the right and Back from the left, while the progress pill stretches across to the new dot and pulls its tail after it.

Live preview: https://movin.design/components/cards/onboarding/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-onboarding
```

Or copy [`card-onboarding.tsx`](./card-onboarding.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-onboarding.html`](./card-onboarding.html) where it goes and include [`card-onboarding.css`](./card-onboarding.css). [`card-onboarding.js`](./card-onboarding.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
