# ID Badge card

An access badge: on hover a scan line sweeps down it, each field ticks as the line passes its row, and a CLEARED stamp slams onto the photo at the end.

Live preview: https://movin.design/components/cards/id-badge/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-id-badge
```

Or copy [`card-id-badge.tsx`](./card-id-badge.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-id-badge.html`](./card-id-badge.html) where it goes and include [`card-id-badge.css`](./card-id-badge.css). It is pure CSS, so there is no script.
