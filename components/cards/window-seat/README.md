# Window seat card

A flight card with a cabin window: on hover the shade slides up on clouds drifting past the wing.

Live preview: https://movin.design/components/cards/window-seat/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-window-seat
```

Or copy [`card-window-seat.tsx`](./card-window-seat.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-window-seat.html`](./card-window-seat.html) where it goes and include [`card-window-seat.css`](./card-window-seat.css). It is pure CSS, so there is no script.
