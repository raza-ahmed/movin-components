# Diff card

A code card with Before and After: removed lines get struck through and fold away, added lines open up in their place, and the gutter marks each change with + or −.

Live preview: https://movin.design/components/cards/diff/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-diff
```

Or copy [`card-diff.tsx`](./card-diff.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-diff.html`](./card-diff.html) where it goes and include [`card-diff.css`](./card-diff.css). [`card-diff.js`](./card-diff.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
