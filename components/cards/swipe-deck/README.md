# Swipe Deck card

A deck of cards you fling. Drag the top card and it tilts with the throw while a Keep or Skip stamp fades in by direction; let go far enough and it flies off and tucks in at the back of the deck as the next card rises. Arrow keys swipe too.

Live preview: https://movin.design/components/cards/swipe-deck/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/card-swipe-deck.json
```

Or copy [`card-swipe-deck.tsx`](./card-swipe-deck.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-swipe-deck.html`](./card-swipe-deck.html) where it goes and include [`card-swipe-deck.css`](./card-swipe-deck.css). [`card-swipe-deck.js`](./card-swipe-deck.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
