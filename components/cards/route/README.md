# Route card

A map card where a car drives the route between pins, the road ahead bright and the driven part fading back, while the ETA in the panel counts down to Arrived.

Live preview: https://movin.design/components/cards/route/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-route
```

Or copy [`card-route.tsx`](./card-route.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-route.html`](./card-route.html) where it goes and include [`card-route.css`](./card-route.css). [`card-route.js`](./card-route.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
