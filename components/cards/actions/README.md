# Actions card

An inbox row you swipe: drag it left and Archive and Delete slide out from under it with some resistance, or right to Flag; let go past halfway and it stays open.

Live preview: https://movin.design/components/cards/actions/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-actions
```

Or copy [`card-actions.tsx`](./card-actions.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-actions.html`](./card-actions.html) where it goes and include [`card-actions.css`](./card-actions.css). [`card-actions.js`](./card-actions.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
