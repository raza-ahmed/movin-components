# Boarding Pass card

A flight ticket with a tear-off stub: on hover the little plane flies the dashed route arc from origin to destination, banking to follow the curve.

Live preview: https://movin.design/components/cards/boarding-pass/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-boarding-pass
```

Or copy [`card-boarding-pass.tsx`](./card-boarding-pass.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-boarding-pass.html`](./card-boarding-pass.html) where it goes and include [`card-boarding-pass.css`](./card-boarding-pass.css). It is pure CSS, so there is no script.
