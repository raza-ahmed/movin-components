# Streak card

A weekly habit card: check in today and its circle fills from the centre, a tick draws, the streak count rolls up by one and the flame flares.

Live preview: https://movin.design/components/cards/streak/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-streak
```

Or copy [`card-streak.tsx`](./card-streak.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-streak.html`](./card-streak.html) where it goes and include [`card-streak.css`](./card-streak.css). [`card-streak.js`](./card-streak.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
