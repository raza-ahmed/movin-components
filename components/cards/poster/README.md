# Poster card

A type poster: on hover the headline flips letter by letter from MAKE IT to MOVE IT, each letter swinging on its baseline, while hazard stripes slide in across the top and keep moving.

Live preview: https://movin.design/components/cards/poster/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-poster
```

Or copy [`card-poster.tsx`](./card-poster.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-poster.html`](./card-poster.html) where it goes and include [`card-poster.css`](./card-poster.css). It is pure CSS, so there is no script.
