# Fortune card

A fortune cookie card: click it and the cookie cracks in two, crumbs fall and the slip of paper slides out with your fortune and lucky numbers; click again for another.

Live preview: https://movin.design/components/cards/fortune/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-fortune
```

Or copy [`card-fortune.tsx`](./card-fortune.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-fortune.html`](./card-fortune.html) where it goes and include [`card-fortune.css`](./card-fortune.css). [`card-fortune.js`](./card-fortune.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
