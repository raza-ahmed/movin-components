# Accordion card

An FAQ card: open a question and its answer slides open to its natural height as the plus turns into a minus, closing the one that was open.

Live preview: https://movin.design/components/cards/accordion/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-accordion
```

Or copy [`card-accordion.tsx`](./card-accordion.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-accordion.html`](./card-accordion.html) where it goes and include [`card-accordion.css`](./card-accordion.css). [`card-accordion.js`](./card-accordion.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
