# Shatter card

A sealed mystery card. Click and it cracks from exactly where you clicked into 3D shards that fly apart and fall away, revealing a reward underneath; click again and the shards fly back and reassemble.

Live preview: https://movin.design/components/cards/shatter/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-shatter
```

Or copy [`card-shatter.tsx`](./card-shatter.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-shatter.html`](./card-shatter.html) where it goes and include [`card-shatter.css`](./card-shatter.css). [`card-shatter.js`](./card-shatter.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
