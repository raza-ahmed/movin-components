# Storage card

A disk usage card with a stacked bar of categories: point at a segment or its legend row and that segment swells while the rest dim, and the reading switches to its size.

Live preview: https://movin.design/components/cards/storage/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-storage
```

Or copy [`card-storage.tsx`](./card-storage.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-storage.html`](./card-storage.html) where it goes and include [`card-storage.css`](./card-storage.css). [`card-storage.js`](./card-storage.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
