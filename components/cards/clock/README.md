# Clock card

A world clock: pick a city and the hands swing round to its local time with a little overshoot, while the seconds hand keeps ticking.

Live preview: https://movin.design/components/cards/clock/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-clock
```

Or copy [`card-clock.tsx`](./card-clock.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-clock.html`](./card-clock.html) where it goes and include [`card-clock.css`](./card-clock.css). [`card-clock.js`](./card-clock.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
