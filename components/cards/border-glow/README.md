# Border Glow card

A conic highlight spins continuously around the card edge; on hover it brightens to white and casts a soft blurred halo. Uses @property for the angle and a transitionable colour.

Live preview: https://movin.design/components/cards/border-glow/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-border-glow
```

Or copy [`card-border-glow.tsx`](./card-border-glow.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-border-glow.html`](./card-border-glow.html) where it goes and include [`card-border-glow.css`](./card-border-glow.css). It is pure CSS, so there is no script.
