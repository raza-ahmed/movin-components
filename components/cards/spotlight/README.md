# Spotlight card

A soft radial light fades in and follows the cursor across the card, like a torch, while the border lights up. Pure CSS + mouse tracking, no dependencies.

Live preview: https://movin.design/components/cards/spotlight/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/card-spotlight.json
```

Or copy [`card-spotlight.tsx`](./card-spotlight.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-spotlight.html`](./card-spotlight.html) where it goes and include [`card-spotlight.css`](./card-spotlight.css). [`card-spotlight.js`](./card-spotlight.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
