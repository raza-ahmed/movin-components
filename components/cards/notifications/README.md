# Notifications card

Three notifications stacked into one: open the stack and they spring apart into a list, a beat apart; clear them and they slide away one after another before the empty state fades in.

Live preview: https://movin.design/components/cards/notifications/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-notifications
```

Or copy [`card-notifications.tsx`](./card-notifications.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-notifications.html`](./card-notifications.html) where it goes and include [`card-notifications.css`](./card-notifications.css). [`card-notifications.js`](./card-notifications.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
