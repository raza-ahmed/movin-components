# Note card

A sticky note pinned to the card: sweep the pointer past it and its bottom edge lifts in the draft, harder the faster you move, then flutters back down on a loose spring.

Live preview: https://movin.design/components/cards/note/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-note
```

Or copy [`card-note.tsx`](./card-note.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-note.html`](./card-note.html) where it goes and include [`card-note.css`](./card-note.css). [`card-note.js`](./card-note.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
