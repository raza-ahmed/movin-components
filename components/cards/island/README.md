# Island card

A compact now-playing pill with live equaliser bars that morphs into a full player card on hover, Dynamic Island style: it springs wider and taller, and the artwork, progress and controls stagger in once there is room.

Live preview: https://movin.design/components/cards/island/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-island
```

Or copy [`card-island.tsx`](./card-island.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-island.html`](./card-island.html) where it goes and include [`card-island.css`](./card-island.css). It is pure CSS, so there is no script.
