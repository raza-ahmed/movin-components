# Pop-out card

A framed planet card: on hover the planet breaks out of the frame toward you, rising and growing with a drop shadow, while the frame tilts back and sinks away.

Live preview: https://movin.design/components/cards/pop-out/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-pop-out
```

Or copy [`card-pop-out.tsx`](./card-pop-out.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-pop-out.html`](./card-pop-out.html) where it goes and include [`card-pop-out.css`](./card-pop-out.css). It is pure CSS, so there is no script.
