# Like card

A photo card you like by double-clicking the picture: a big heart pops over it and floats away, the small heart below fills with a burst of sparks, and the count rolls up.

Live preview: https://movin.design/components/cards/like/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-like
```

Or copy [`card-like.tsx`](./card-like.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-like.html`](./card-like.html) where it goes and include [`card-like.css`](./card-like.css). [`card-like.js`](./card-like.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
