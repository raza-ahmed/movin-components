# Ink Reveal card

A liquid blob of ink trails the cursor across the card, a head and a tapering tail of droplets melting together through an SVG goo filter inside an alpha mask, and wherever it flows it reveals an inverted version of the card. A click floods the whole card.

Live preview: https://movin.design/components/cards/ink-reveal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/card-ink-reveal.json
```

Or copy [`card-ink-reveal.tsx`](./card-ink-reveal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-ink-reveal.html`](./card-ink-reveal.html) where it goes and include [`card-ink-reveal.css`](./card-ink-reveal.css). [`card-ink-reveal.js`](./card-ink-reveal.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
