# Gradient Drift card

The card header runs a multi-stop grayscale gradient that slowly drifts left-to-right in a continuous loop — an ambient living colour effect. Pure CSS, no dependencies.

Live preview: https://movin.design/components/cards/gradient-drift/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/card-gradient-drift.json
```

Or copy [`card-gradient-drift.tsx`](./card-gradient-drift.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-gradient-drift.html`](./card-gradient-drift.html) where it goes and include [`card-gradient-drift.css`](./card-gradient-drift.css). It is pure CSS, so there is no script.
