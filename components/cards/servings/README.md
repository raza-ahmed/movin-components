# Servings card

A recipe card: change the servings and every quantity rescales, the old figure rolling out as the new one rolls in, one ingredient after another.

Live preview: https://movin.design/components/cards/servings/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-servings
```

Or copy [`card-servings.tsx`](./card-servings.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-servings.html`](./card-servings.html) where it goes and include [`card-servings.css`](./card-servings.css). [`card-servings.js`](./card-servings.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
