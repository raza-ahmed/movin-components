# Scratch-off card

A scratch card. Drag across the silver foil (a canvas) to erase it with destination-out strokes while flakes fall from the scratch; once about half is gone the rest dissolves and the prize pops. Keyboard users get a Reveal button, and Scratch again resets it.

Live preview: https://movin.design/components/cards/scratch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/card-scratch.json
```

Or copy [`card-scratch.tsx`](./card-scratch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-scratch.html`](./card-scratch.html) where it goes and include [`card-scratch.css`](./card-scratch.css). [`card-scratch.js`](./card-scratch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
