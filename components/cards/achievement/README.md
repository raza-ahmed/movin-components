# Achievement card

Click to unlock an achievement: the badge flips over from a lock to a glowing medal, rays burst behind it and sparks fly out, and the XP bar fills with the points gained. Click again to reset.

Live preview: https://movin.design/components/cards/achievement/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-achievement
```

Or copy [`card-achievement.tsx`](./card-achievement.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-achievement.html`](./card-achievement.html) where it goes and include [`card-achievement.css`](./card-achievement.css). [`card-achievement.js`](./card-achievement.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
