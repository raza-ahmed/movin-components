# Hover Lift card

Card floats upward and casts a deeper shadow on hover. Spring overshoot easing gives it a satisfying pop. Pure CSS transitions, no dependencies.

Live preview: https://movin.design/components/cards/hover-lift/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/card-hover-lift.json
```

Or copy [`card-hover-lift.tsx`](./card-hover-lift.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-hover-lift.html`](./card-hover-lift.html) where it goes and include [`card-hover-lift.css`](./card-hover-lift.css). It is pure CSS, so there is no script.
