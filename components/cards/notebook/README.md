# Notebook card

A reporter's notebook card: on hover the elastic band slips off and the cover flips up and over the spiral to the to-do page underneath.

Live preview: https://movin.design/components/cards/notebook/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-notebook
```

Or copy [`card-notebook.tsx`](./card-notebook.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-notebook.html`](./card-notebook.html) where it goes and include [`card-notebook.css`](./card-notebook.css). It is pure CSS, so there is no script.
