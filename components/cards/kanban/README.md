# Kanban card

A two-column board: drag a task across and it lifts and tilts as you carry it, a dashed gap opens where it will land, and it settles into the other column as the rest glide over.

Live preview: https://movin.design/components/cards/kanban/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-kanban
```

Or copy [`card-kanban.tsx`](./card-kanban.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-kanban.html`](./card-kanban.html) where it goes and include [`card-kanban.css`](./card-kanban.css). [`card-kanban.js`](./card-kanban.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
