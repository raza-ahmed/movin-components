# X-Ray card

A finished card with an x-ray lens: move the pointer over it and a round lens follows, showing the wireframe underneath, the same layout drawn as dashed boxes on a grid with each element's spec.

Live preview: https://movin.design/components/cards/x-ray/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-x-ray
```

Or copy [`card-x-ray.tsx`](./card-x-ray.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-x-ray.html`](./card-x-ray.html) where it goes and include [`card-x-ray.css`](./card-x-ray.css). [`card-x-ray.js`](./card-x-ray.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
