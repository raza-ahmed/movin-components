# Orbit Profile card

A profile card whose skill tags orbit the avatar in a tilted ring, passing in front and behind. On hover the orbit stops, the avatar and name lift, and the tags fly down and settle into a neat row.

Live preview: https://movin.design/components/cards/orbit-profile/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-orbit-profile
```

Or copy [`card-orbit-profile.tsx`](./card-orbit-profile.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-orbit-profile.html`](./card-orbit-profile.html) where it goes and include [`card-orbit-profile.css`](./card-orbit-profile.css). [`card-orbit-profile.js`](./card-orbit-profile.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
