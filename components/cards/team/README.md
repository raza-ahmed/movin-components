# Team card

A team card with overlapping avatars: hover the group and they spread apart one after another, the +3 chip folds away into the rest of the team, and pointing at a face names it.

Live preview: https://movin.design/components/cards/team/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-team
```

Or copy [`card-team.tsx`](./card-team.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-team.html`](./card-team.html) where it goes and include [`card-team.css`](./card-team.css). [`card-team.js`](./card-team.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
