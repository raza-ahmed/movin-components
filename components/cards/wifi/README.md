# Wi-Fi card

A network picker: choose a network and its signal arcs pulse while it connects, then it ticks and moves to the top of the list as the others shift down.

Live preview: https://movin.design/components/cards/wifi/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-wifi
```

Or copy [`card-wifi.tsx`](./card-wifi.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-wifi.html`](./card-wifi.html) where it goes and include [`card-wifi.css`](./card-wifi.css). [`card-wifi.js`](./card-wifi.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
