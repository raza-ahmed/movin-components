# Shimmer card

A bright diagonal light streak sweeps across the card on hover using a CSS ::after pseudo-element, and the border stays lit while hovered. Resets instantly on mouse-leave. Pure CSS, no dependencies.

Live preview: https://movin.design/components/cards/shimmer/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-shimmer
```

Or copy [`card-shimmer.tsx`](./card-shimmer.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-shimmer.html`](./card-shimmer.html) where it goes and include [`card-shimmer.css`](./card-shimmer.css). It is pure CSS, so there is no script.
