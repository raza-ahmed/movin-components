# Cart card

A product card: add it to the cart and a copy of the product flies in an arc into the cart icon, which bumps as its badge pops up with the new count.

Live preview: https://movin.design/components/cards/cart/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-cart
```

Or copy [`card-cart.tsx`](./card-cart.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-cart.html`](./card-cart.html) where it goes and include [`card-cart.css`](./card-cart.css). [`card-cart.js`](./card-cart.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
