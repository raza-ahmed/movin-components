# Spoiler card

A message with a hidden spoiler: the hidden words shimmer under drifting, twinkling specks, and a click scatters the specks outward from where you clicked as the words fade in.

Live preview: https://movin.design/components/cards/spoiler/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-spoiler
```

Or copy [`card-spoiler.tsx`](./card-spoiler.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-spoiler.html`](./card-spoiler.html) where it goes and include [`card-spoiler.css`](./card-spoiler.css). [`card-spoiler.js`](./card-spoiler.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
