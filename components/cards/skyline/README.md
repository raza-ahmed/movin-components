# Skyline card

An activity grid as a 3D city: twelve weeks of days become bars that rise in a diagonal wave. Move the pointer and the whole city turns to follow it; hover a bar to light it and read its date and count.

Live preview: https://movin.design/components/cards/skyline/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-skyline
```

Or copy [`card-skyline.tsx`](./card-skyline.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-skyline.html`](./card-skyline.html) where it goes and include [`card-skyline.css`](./card-skyline.css). [`card-skyline.js`](./card-skyline.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
