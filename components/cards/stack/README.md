# Stack card

Three layered cards sit in a tight stack at rest. On hover they fan outward (back card rotates −6° and slides left, middle rotates +5° and slides right, front card lifts upward), using a spring cubic-bezier that physically overshoots before settling.

Live preview: https://movin.design/components/cards/stack/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-stack
```

Or copy [`card-stack.tsx`](./card-stack.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-stack.html`](./card-stack.html) where it goes and include [`card-stack.css`](./card-stack.css). It is pure CSS, so there is no script.
