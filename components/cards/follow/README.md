# Follow card

A profile card whose Follow button turns into Following with a drawn tick, while the follower count rolls up by one and a ring draws itself round the avatar.

Live preview: https://movin.design/components/cards/follow/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-follow
```

Or copy [`card-follow.tsx`](./card-follow.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-follow.html`](./card-follow.html) where it goes and include [`card-follow.css`](./card-follow.css). [`card-follow.js`](./card-follow.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
