# Magnetic card

Card layers move toward the cursor at different strengths (the orb the most, the backdrop at 30%, the text at 15%), creating a parallax depth illusion without any 3D rotation or perspective.

Live preview: https://movin.design/components/cards/magnetic/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-magnetic
```

Or copy [`card-magnetic.tsx`](./card-magnetic.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-magnetic.html`](./card-magnetic.html) where it goes and include [`card-magnetic.css`](./card-magnetic.css). [`card-magnetic.js`](./card-magnetic.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
