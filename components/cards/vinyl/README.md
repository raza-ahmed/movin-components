# Vinyl card

A record in its sleeve: on hover the vinyl slides out of the sleeve and spins up, its grooves catching a fixed sheen, while the tonearm swings in over it a beat later.

Live preview: https://movin.design/components/cards/vinyl/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-vinyl
```

Or copy [`card-vinyl.tsx`](./card-vinyl.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-vinyl.html`](./card-vinyl.html) where it goes and include [`card-vinyl.css`](./card-vinyl.css). [`card-vinyl.js`](./card-vinyl.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
