# Checklist card

A to-do card: ticking an item draws its check and strikes its text, the progress ring steps round, and finishing the list pops in a new heading.

Live preview: https://movin.design/components/cards/checklist/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-checklist
```

Or copy [`card-checklist.tsx`](./card-checklist.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-checklist.html`](./card-checklist.html) where it goes and include [`card-checklist.css`](./card-checklist.css). [`card-checklist.js`](./card-checklist.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
