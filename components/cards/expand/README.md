# Expand card

A compact article row that opens into a full card: the thumbnail grows into a banner, the title and meta slide down beneath it and the summary fades in; close it and it all folds back.

Live preview: https://movin.design/components/cards/expand/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-expand
```

Or copy [`card-expand.tsx`](./card-expand.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-expand.html`](./card-expand.html) where it goes and include [`card-expand.css`](./card-expand.css). [`card-expand.js`](./card-expand.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
