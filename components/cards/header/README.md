# Header card

A profile card that scrolls inside itself: as you scroll the posts, the cover shrinks into a slim header and the avatar travels up into it, shrinking, while the name fades in beside it.

Live preview: https://movin.design/components/cards/header/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-header
```

Or copy [`card-header.tsx`](./card-header.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-header.html`](./card-header.html) where it goes and include [`card-header.css`](./card-header.css). [`card-header.js`](./card-header.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
