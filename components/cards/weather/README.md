# Weather card

A weather card with light rain falling behind the reading. Hover brings the storm in: the rain thickens, the cloud darkens, lightning flashes with the sky, and the reading changes to match.

Live preview: https://movin.design/components/cards/weather/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-weather
```

Or copy [`card-weather.tsx`](./card-weather.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-weather.html`](./card-weather.html) where it goes and include [`card-weather.css`](./card-weather.css). [`card-weather.js`](./card-weather.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
