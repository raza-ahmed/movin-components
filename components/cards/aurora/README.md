# Aurora card

Three blurred light blobs of different brightness drift slowly behind the card content; on hover the aurora blooms brighter and wider. Pure CSS keyframes, no dependencies.

Live preview: https://movin.design/components/cards/aurora/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/card-aurora.json
```

Or copy [`card-aurora.tsx`](./card-aurora.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-aurora.html`](./card-aurora.html) where it goes and include [`card-aurora.css`](./card-aurora.css). It is pure CSS, so there is no script.
