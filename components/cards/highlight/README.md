# Highlight card

A testimonial whose key phrases get a marker swept behind them, one after the other and across line breaks, when the card comes into view; hover it to sweep again.

Live preview: https://movin.design/components/cards/highlight/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-highlight
```

Or copy [`card-highlight.tsx`](./card-highlight.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-highlight.html`](./card-highlight.html) where it goes and include [`card-highlight.css`](./card-highlight.css). [`card-highlight.js`](./card-highlight.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
