# Holo Foil card

A collectible trading card. It tilts toward the cursor while a silver holographic foil (light bands plus a sparkle screen, colour-dodged) slides across it and a glare follows the light, like a rare card turned under a lamp.

Live preview: https://movin.design/components/cards/holo/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-holo
```

Or copy [`card-holo.tsx`](./card-holo.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-holo.html`](./card-holo.html) where it goes and include [`card-holo.css`](./card-holo.css). [`card-holo.js`](./card-holo.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
