# Matchbox card

A restaurant booking card drawn as a matchbox: on hover the drawer slides out of its printed sleeve with the booking inside, a row of matches beside it.

Live preview: https://movin.design/components/cards/matchbox/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-matchbox
```

Or copy [`card-matchbox.tsx`](./card-matchbox.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-matchbox.html`](./card-matchbox.html) where it goes and include [`card-matchbox.css`](./card-matchbox.css). It is pure CSS, so there is no script.
