# Book card

A hardback book card: on hover the cover swings open in 3D past the spine, and the book slides over so the spread stays centred, showing the inscription on the first page.

Live preview: https://movin.design/components/cards/book/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-book
```

Or copy [`card-book.tsx`](./card-book.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`card-book.html`](./card-book.html) where it goes and include [`card-book.css`](./card-book.css). It is pure CSS, so there is no script.
