# Bank Card card

A brushed-metal bank card. On hover it lifts and tilts, the contactless waves pulse, and the masked number scrambles into view digit by digit, left to right; leave and it masks again.

Live preview: https://movin.design/components/cards/bank-card/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-bank-card
```

Or copy [`card-bank-card.tsx`](./card-bank-card.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-bank-card.html`](./card-bank-card.html) where it goes and include [`card-bank-card.css`](./card-bank-card.css). [`card-bank-card.js`](./card-bank-card.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
