# Pricing card

A plan card with a Monthly and Yearly switch: the knob slides across, the price digits roll to the new amount a beat apart, the billing note changes and a Save badge drops in for yearly.

Live preview: https://movin.design/components/cards/pricing/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/card-pricing
```

Or copy [`card-pricing.tsx`](./card-pricing.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`card-pricing.html`](./card-pricing.html) where it goes and include [`card-pricing.css`](./card-pricing.css). [`card-pricing.js`](./card-pricing.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
