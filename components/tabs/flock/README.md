# Flock tab set

Sales tabs with a dotted underline that flies to the new tab like a flock of birds: each dot takes its own arc, a beat after the last, and they line up again on landing.

Live preview: https://movin.design/components/tabs/flock/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-flock
```

Or copy [`tab-flock.tsx`](./tab-flock.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-flock.html`](./tab-flock.html) where it goes and include [`tab-flock.css`](./tab-flock.css). [`tab-flock.js`](./tab-flock.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
