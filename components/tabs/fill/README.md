# Fill tab set

Drink tabs that fill up like a glass: the chosen tab fills from the bottom with a moving wave on top, and the one you left drains.

Live preview: https://movin.design/components/tabs/fill/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-fill
```

Or copy [`tab-fill.tsx`](./tab-fill.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-fill.html`](./tab-fill.html) where it goes and include [`tab-fill.css`](./tab-fill.css). [`tab-fill.js`](./tab-fill.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
