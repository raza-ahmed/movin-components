# Cube tab set

Quarterly plans on the faces of a 3D cube: pick a quarter and the cube turns the short way round to that face.

Live preview: https://movin.design/components/tabs/cube/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-cube
```

Or copy [`tab-cube.tsx`](./tab-cube.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-cube.html`](./tab-cube.html) where it goes and include [`tab-cube.css`](./tab-cube.css). [`tab-cube.js`](./tab-cube.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
