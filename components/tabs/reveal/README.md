# Reveal tab set

Times of day as tabs: the new panel opens in a circle spreading from under the tab you picked, over the one you left.

Live preview: https://movin.design/components/tabs/reveal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-reveal
```

Or copy [`tab-reveal.tsx`](./tab-reveal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-reveal.html`](./tab-reveal.html) where it goes and include [`tab-reveal.css`](./tab-reveal.css). [`tab-reveal.js`](./tab-reveal.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
