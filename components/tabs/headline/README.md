# Headline tab set

Newspaper section tabs: pick a section and the front page spins in from nowhere with its new headline, like a newsreel stop-press.

Live preview: https://movin.design/components/tabs/headline/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-headline
```

Or copy [`tab-headline.tsx`](./tab-headline.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-headline.html`](./tab-headline.html) where it goes and include [`tab-headline.css`](./tab-headline.css). [`tab-headline.js`](./tab-headline.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
