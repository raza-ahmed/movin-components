# Lamp tab set

Reading tabs under a hanging lamp: the lamp swings over to the tab you pick, sways and settles, lighting it with a cone of light.

Live preview: https://movin.design/components/tabs/lamp/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-lamp
```

Or copy [`tab-lamp.tsx`](./tab-lamp.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-lamp.html`](./tab-lamp.html) where it goes and include [`tab-lamp.css`](./tab-lamp.css). [`tab-lamp.js`](./tab-lamp.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
