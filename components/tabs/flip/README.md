# Flip tab set

A contact card as tabs: the card flips over on its vertical axis to show the new side, turning left or right with the direction you moved.

Live preview: https://movin.design/components/tabs/flip/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-flip
```

Or copy [`tab-flip.tsx`](./tab-flip.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-flip.html`](./tab-flip.html) where it goes and include [`tab-flip.css`](./tab-flip.css). [`tab-flip.js`](./tab-flip.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
