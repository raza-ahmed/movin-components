# Metro tab set

Stop tabs on a metro line: the train rides the line to the chosen stop, easing in and braking, its doors open once it stops and the stop's notes appear.

Live preview: https://movin.design/components/tabs/metro/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-metro
```

Or copy [`tab-metro.tsx`](./tab-metro.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-metro.html`](./tab-metro.html) where it goes and include [`tab-metro.css`](./tab-metro.css). [`tab-metro.js`](./tab-metro.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
