# Brackets tab set

Tabs marked by a pair of brackets: they glide over to the new label and clamp in around it with a little squeeze.

Live preview: https://movin.design/components/tabs/brackets/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-brackets
```

Or copy [`tab-brackets.tsx`](./tab-brackets.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-brackets.html`](./tab-brackets.html) where it goes and include [`tab-brackets.css`](./tab-brackets.css). [`tab-brackets.js`](./tab-brackets.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
