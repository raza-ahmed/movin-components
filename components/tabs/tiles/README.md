# Tiles tab set

App tiles: the chosen tile grows into the big slot with its icon and words, while the one it replaces shrinks down into the row of small tiles.

Live preview: https://movin.design/components/tabs/tiles/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-tiles
```

Or copy [`tab-tiles.tsx`](./tab-tiles.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-tiles.html`](./tab-tiles.html) where it goes and include [`tab-tiles.css`](./tab-tiles.css). [`tab-tiles.js`](./tab-tiles.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
