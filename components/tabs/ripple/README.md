# Ripple tab set

Library tabs where picking one sends a ripple through the letters of every label, starting from where you clicked and fading as it travels.

Live preview: https://movin.design/components/tabs/ripple/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-ripple
```

Or copy [`tab-ripple.tsx`](./tab-ripple.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-ripple.html`](./tab-ripple.html) where it goes and include [`tab-ripple.css`](./tab-ripple.css). [`tab-ripple.js`](./tab-ripple.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
