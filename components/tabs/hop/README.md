# Hop tab set

Feed tabs where a dot hops in an arc from the old tab to the new one and lands with a squash.

Live preview: https://movin.design/components/tabs/hop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-hop
```

Or copy [`tab-hop.tsx`](./tab-hop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-hop.html`](./tab-hop.html) where it goes and include [`tab-hop.css`](./tab-hop.css). [`tab-hop.js`](./tab-hop.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
