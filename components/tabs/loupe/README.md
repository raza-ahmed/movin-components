# Loupe tab set

Collection tabs read through a loupe: the magnifier glides to the chosen tab and inside it an enlarged copy of the row slides along in register, so the label is always magnified.

Live preview: https://movin.design/components/tabs/loupe/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-loupe
```

Or copy [`tab-loupe.tsx`](./tab-loupe.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-loupe.html`](./tab-loupe.html) where it goes and include [`tab-loupe.css`](./tab-loupe.css). [`tab-loupe.js`](./tab-loupe.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
