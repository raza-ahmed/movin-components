# Expand tab set

Icon tabs where the active one opens out to show its label inside a pill, while the others close back down to their icons.

Live preview: https://movin.design/components/tabs/expand/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-expand
```

Or copy [`tab-expand.tsx`](./tab-expand.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-expand.html`](./tab-expand.html) where it goes and include [`tab-expand.css`](./tab-expand.css). [`tab-expand.js`](./tab-expand.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
