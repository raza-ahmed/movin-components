# Piano tab set

Song section tabs as piano keys: the key you choose stays pressed down, and a note floats up from it each time you play a new section.

Live preview: https://movin.design/components/tabs/piano/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-piano
```

Or copy [`tab-piano.tsx`](./tab-piano.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-piano.html`](./tab-piano.html) where it goes and include [`tab-piano.css`](./tab-piano.css). [`tab-piano.js`](./tab-piano.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
