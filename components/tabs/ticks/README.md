# Ticks tab set

Mail tabs over a row of fine ticks: the ticks under the active tab stand tall and bright, and switching sends that crest travelling across to the new one.

Live preview: https://movin.design/components/tabs/ticks/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-ticks
```

Or copy [`tab-ticks.tsx`](./tab-ticks.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-ticks.html`](./tab-ticks.html) where it goes and include [`tab-ticks.css`](./tab-ticks.css). [`tab-ticks.js`](./tab-ticks.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
