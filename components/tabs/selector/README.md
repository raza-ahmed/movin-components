# Selector tab set

Mode tabs on a rotary selector: the knob turns to point at the chosen mode with a firm detent, and the labels sit round the dial at each stop.

Live preview: https://movin.design/components/tabs/selector/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-selector
```

Or copy [`tab-selector.tsx`](./tab-selector.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-selector.html`](./tab-selector.html) where it goes and include [`tab-selector.css`](./tab-selector.css). [`tab-selector.js`](./tab-selector.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
