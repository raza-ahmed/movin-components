# Preview tab set

Site tabs with a hover card that sketches each page: the card glides and resizes from tab to tab instead of reappearing, then fades when you leave.

Live preview: https://movin.design/components/tabs/preview/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-preview
```

Or copy [`tab-preview.tsx`](./tab-preview.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-preview.html`](./tab-preview.html) where it goes and include [`tab-preview.css`](./tab-preview.css). [`tab-preview.js`](./tab-preview.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
