# Jukebox tab set

A jukebox song picker: the old record slides off the deck, the new one slides on and spins, the tonearm lifts and drops back, and an equaliser plays beside the title.

Live preview: https://movin.design/components/tabs/jukebox/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-jukebox
```

Or copy [`tab-jukebox.tsx`](./tab-jukebox.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-jukebox.html`](./tab-jukebox.html) where it goes and include [`tab-jukebox.css`](./tab-jukebox.css). [`tab-jukebox.js`](./tab-jukebox.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
