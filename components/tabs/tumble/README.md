# Tumble tab set

Forecast tabs whose pill turns over end on end like a domino, hinged on the edge it is heading for, once for every tab it crosses.

Live preview: https://movin.design/components/tabs/tumble/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-tumble
```

Or copy [`tab-tumble.tsx`](./tab-tumble.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-tumble.html`](./tab-tumble.html) where it goes and include [`tab-tumble.css`](./tab-tumble.css). [`tab-tumble.js`](./tab-tumble.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
