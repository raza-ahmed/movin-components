# Stack tab set

Payment cards as tabs: the chosen card comes to the front of the deck and the others shuffle back behind it.

Live preview: https://movin.design/components/tabs/stack/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-stack
```

Or copy [`tab-stack.tsx`](./tab-stack.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-stack.html`](./tab-stack.html) where it goes and include [`tab-stack.css`](./tab-stack.css). [`tab-stack.js`](./tab-stack.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
