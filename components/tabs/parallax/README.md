# Parallax tab set

Walk tabs over a landscape in layers: switching slides the far hills a little, the near ground a lot and the place name furthest, so the scene has depth.

Live preview: https://movin.design/components/tabs/parallax/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-parallax
```

Or copy [`tab-parallax.tsx`](./tab-parallax.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-parallax.html`](./tab-parallax.html) where it goes and include [`tab-parallax.css`](./tab-parallax.css). [`tab-parallax.js`](./tab-parallax.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
