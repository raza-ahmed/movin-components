# Marquee tab set

Showtime tabs with the active one framed in chasing marquee bulbs; pick another and the frame of lights travels across to it.

Live preview: https://movin.design/components/tabs/marquee/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-marquee
```

Or copy [`tab-marquee.tsx`](./tab-marquee.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-marquee.html`](./tab-marquee.html) where it goes and include [`tab-marquee.css`](./tab-marquee.css). [`tab-marquee.js`](./tab-marquee.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
