# Film tab set

Acts on a strip of film: the strip advances through the gate in steps, a jump and a hold per frame, with the shutter blinking over each pull.

Live preview: https://movin.design/components/tabs/film/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-film
```

Or copy [`tab-film.tsx`](./tab-film.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-film.html`](./tab-film.html) where it goes and include [`tab-film.css`](./tab-film.css). [`tab-film.js`](./tab-film.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
