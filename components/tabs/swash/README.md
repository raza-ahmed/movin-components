# Swash tab set

Restaurant tabs in italic serif: a calligraphic swash writes itself under the chosen word, ending in a small loop and a flick, while the old one unwrites.

Live preview: https://movin.design/components/tabs/swash/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-swash
```

Or copy [`tab-swash.tsx`](./tab-swash.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-swash.html`](./tab-swash.html) where it goes and include [`tab-swash.css`](./tab-swash.css). [`tab-swash.js`](./tab-swash.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
