# Reels tab set

A lunch slot machine: pick a dish and the lever pulls, the reel spins a full turn with a motion blur and stops on your pick.

Live preview: https://movin.design/components/tabs/reels/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-reels
```

Or copy [`tab-reels.tsx`](./tab-reels.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-reels.html`](./tab-reels.html) where it goes and include [`tab-reels.css`](./tab-reels.css). [`tab-reels.js`](./tab-reels.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
