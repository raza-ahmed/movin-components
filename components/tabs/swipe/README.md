# Swipe tab set

Feed tabs over swipeable panels: drag the panels sideways and the underline tracks your finger between the tabs, snapping to the nearest when you let go.

Live preview: https://movin.design/components/tabs/swipe/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-swipe
```

Or copy [`tab-swipe.tsx`](./tab-swipe.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-swipe.html`](./tab-swipe.html) where it goes and include [`tab-swipe.css`](./tab-swipe.css). [`tab-swipe.js`](./tab-swipe.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
