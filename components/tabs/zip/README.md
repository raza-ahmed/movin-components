# Zip tab set

Checkout tabs on a zip: the slider rides to the chosen tab, meshing the teeth behind it and parting them ahead, its pull swinging from the speed.

Live preview: https://movin.design/components/tabs/zip/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-zip
```

Or copy [`tab-zip.tsx`](./tab-zip.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-zip.html`](./tab-zip.html) where it goes and include [`tab-zip.css`](./tab-zip.css). [`tab-zip.js`](./tab-zip.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
