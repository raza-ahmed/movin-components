# Notch tab set

A bottom bar with a notch cut under the active icon, which rises into a floating circle above the bar; pick another and the notch flows along to it.

Live preview: https://movin.design/components/tabs/notch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-notch
```

Or copy [`tab-notch.tsx`](./tab-notch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-notch.html`](./tab-notch.html) where it goes and include [`tab-notch.css`](./tab-notch.css). [`tab-notch.js`](./tab-notch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
