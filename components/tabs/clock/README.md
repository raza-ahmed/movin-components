# Clock tab set

A world clock as tabs: pick a city and the clock hands spin forward to its local time, the minute hand whirling through the hours in between.

Live preview: https://movin.design/components/tabs/clock/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-clock
```

Or copy [`tab-clock.tsx`](./tab-clock.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-clock.html`](./tab-clock.html) where it goes and include [`tab-clock.css`](./tab-clock.css). [`tab-clock.js`](./tab-clock.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
