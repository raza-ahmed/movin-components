# Curtain tab set

Theatre acts as tabs: the curtains sweep shut, the scene changes behind them and they open again on the next act.

Live preview: https://movin.design/components/tabs/curtain/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-curtain
```

Or copy [`tab-curtain.tsx`](./tab-curtain.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-curtain.html`](./tab-curtain.html) where it goes and include [`tab-curtain.css`](./tab-curtain.css). [`tab-curtain.js`](./tab-curtain.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
