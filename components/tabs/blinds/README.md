# Blinds tab set

Gallery tabs where the new picture appears behind a set of blinds that open across it, slat by slat.

Live preview: https://movin.design/components/tabs/blinds/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-blinds
```

Or copy [`tab-blinds.tsx`](./tab-blinds.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-blinds.html`](./tab-blinds.html) where it goes and include [`tab-blinds.css`](./tab-blinds.css). [`tab-blinds.js`](./tab-blinds.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
