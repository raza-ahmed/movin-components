# Tilt tab set

Appearance tabs on a beam balanced over a pivot: pick a tab and the beam tips towards it, so the ball rolls down to it, and the beam levels out as the ball arrives.

Live preview: https://movin.design/components/tabs/tilt/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-tilt
```

Or copy [`tab-tilt.tsx`](./tab-tilt.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-tilt.html`](./tab-tilt.html) where it goes and include [`tab-tilt.css`](./tab-tilt.css). [`tab-tilt.js`](./tab-tilt.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
