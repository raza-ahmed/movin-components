# Blocks tab set

Game world tabs with an underline built of blocks: new blocks fall in and stack, bottom row first, while the old ones crumble and drop away.

Live preview: https://movin.design/components/tabs/blocks/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-blocks
```

Or copy [`tab-blocks.tsx`](./tab-blocks.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-blocks.html`](./tab-blocks.html) where it goes and include [`tab-blocks.css`](./tab-blocks.css). [`tab-blocks.js`](./tab-blocks.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
