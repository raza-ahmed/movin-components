# Wheel tab set

Days of the week on a turning wheel: pick one and the wheel rolls it to the front while the rest turn away into depth.

Live preview: https://movin.design/components/tabs/wheel/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-wheel
```

Or copy [`tab-wheel.tsx`](./tab-wheel.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-wheel.html`](./tab-wheel.html) where it goes and include [`tab-wheel.css`](./tab-wheel.css). [`tab-wheel.js`](./tab-wheel.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
