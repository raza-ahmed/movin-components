# Lens tab set

View tabs with a liquid glass lens: the glass slides to the new tab, stretching as it moves and settling with a wobble, blurring and brightening what is underneath.

Live preview: https://movin.design/components/tabs/lens/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-lens
```

Or copy [`tab-lens.tsx`](./tab-lens.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-lens.html`](./tab-lens.html) where it goes and include [`tab-lens.css`](./tab-lens.css). [`tab-lens.js`](./tab-lens.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
