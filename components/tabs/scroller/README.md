# Scroller tab set

More category tabs than fit: the row scrolls with faded edges and arrow buttons, and the one you pick glides to the middle under a sliding pill.

Live preview: https://movin.design/components/tabs/scroller/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-scroller
```

Or copy [`tab-scroller.tsx`](./tab-scroller.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-scroller.html`](./tab-scroller.html) where it goes and include [`tab-scroller.css`](./tab-scroller.css). [`tab-scroller.js`](./tab-scroller.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
