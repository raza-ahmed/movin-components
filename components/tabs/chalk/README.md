# Chalk tab set

Lessons on a chalkboard: an eraser rubs out the old underline, leaving a faint smudge, and a fresh chalk line scratches in under the new lesson.

Live preview: https://movin.design/components/tabs/chalk/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-chalk
```

Or copy [`tab-chalk.tsx`](./tab-chalk.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-chalk.html`](./tab-chalk.html) where it goes and include [`tab-chalk.css`](./tab-chalk.css). [`tab-chalk.js`](./tab-chalk.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
