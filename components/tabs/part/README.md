# Part tab set

A segmented range picker whose labels step up out of the way as the pill slides beneath them, more the faster it goes, then settle back.

Live preview: https://movin.design/components/tabs/part/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-part
```

Or copy [`tab-part.tsx`](./tab-part.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-part.html`](./tab-part.html) where it goes and include [`tab-part.css`](./tab-part.css). [`tab-part.js`](./tab-part.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
