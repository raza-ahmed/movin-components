# Squiggle tab set

Notes tabs with a playful underline: it wiggles into a wave while it travels to the new tab and lies flat again once it arrives.

Live preview: https://movin.design/components/tabs/squiggle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-squiggle
```

Or copy [`tab-squiggle.tsx`](./tab-squiggle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-squiggle.html`](./tab-squiggle.html) where it goes and include [`tab-squiggle.css`](./tab-squiggle.css). [`tab-squiggle.js`](./tab-squiggle.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
