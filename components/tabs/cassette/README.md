# Cassette tab set

Tracks on a tape: pick one and the reels wind fast forward or back to it, the near-empty reel spinning hardest, the tape packs trading size and the counter running.

Live preview: https://movin.design/components/tabs/cassette/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-cassette
```

Or copy [`tab-cassette.tsx`](./tab-cassette.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-cassette.html`](./tab-cassette.html) where it goes and include [`tab-cassette.css`](./tab-cassette.css). [`tab-cassette.js`](./tab-cassette.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
