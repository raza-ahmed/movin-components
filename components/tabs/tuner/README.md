# Tuner tab set

Radio station tabs on a tuning dial: the needle sweeps across the frequency scale to the one you pick, and the panel tunes in from static as it arrives.

Live preview: https://movin.design/components/tabs/tuner/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-tuner
```

Or copy [`tab-tuner.tsx`](./tab-tuner.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-tuner.html`](./tab-tuner.html) where it goes and include [`tab-tuner.css`](./tab-tuner.css). [`tab-tuner.js`](./tab-tuner.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
