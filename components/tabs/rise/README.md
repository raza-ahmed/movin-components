# Rise tab set

Uppercase tabs whose letters roll up one by one into the lit word, and keep rolling upward out of the word you left rather than back down, with a hairline rule sliding under the active tab.

Live preview: https://movin.design/components/tabs/rise/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-rise
```

Or copy [`tab-rise.tsx`](./tab-rise.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-rise.html`](./tab-rise.html) where it goes and include [`tab-rise.css`](./tab-rise.css). [`tab-rise.js`](./tab-rise.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
