# Fold tab set

Menu tabs where the new list unfolds down from its top edge like a paper flap, with a shadow lifting as it opens.

Live preview: https://movin.design/components/tabs/fold/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-fold
```

Or copy [`tab-fold.tsx`](./tab-fold.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-fold.html`](./tab-fold.html) where it goes and include [`tab-fold.css`](./tab-fold.css). [`tab-fold.js`](./tab-fold.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
