# Envelope tab set

Letters from friends as postage-stamp tabs: pick a stamp and that friend's letter rises out of the envelope.

Live preview: https://movin.design/components/tabs/envelope/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-envelope
```

Or copy [`tab-envelope.tsx`](./tab-envelope.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-envelope.html`](./tab-envelope.html) where it goes and include [`tab-envelope.css`](./tab-envelope.css). [`tab-envelope.js`](./tab-envelope.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
