# Dock tab set

App tabs in a dock that magnifies the icons near your pointer, with a dot under the open app and its screen above.

Live preview: https://movin.design/components/tabs/dock/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-dock
```

Or copy [`tab-dock.tsx`](./tab-dock.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-dock.html`](./tab-dock.html) where it goes and include [`tab-dock.css`](./tab-dock.css). [`tab-dock.js`](./tab-dock.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
