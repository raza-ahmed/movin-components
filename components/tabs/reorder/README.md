# Reorder tab set

Tabs you can drag into a new order, the others shuffling out of the way; Alt with the arrow keys moves them from the keyboard, and the new position is announced.

Live preview: https://movin.design/components/tabs/reorder/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-reorder
```

Or copy [`tab-reorder.tsx`](./tab-reorder.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-reorder.html`](./tab-reorder.html) where it goes and include [`tab-reorder.css`](./tab-reorder.css). [`tab-reorder.js`](./tab-reorder.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
