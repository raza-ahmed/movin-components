# Stories tab set

Story tabs as progress bars: each bar fills while its story plays and moves on by itself, pausing while you hover or focus, with a pause button.

Live preview: https://movin.design/components/tabs/stories/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-stories
```

Or copy [`tab-stories.tsx`](./tab-stories.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-stories.html`](./tab-stories.html) where it goes and include [`tab-stories.css`](./tab-stories.css). [`tab-stories.js`](./tab-stories.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
