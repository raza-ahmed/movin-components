# Overview tab set

Library tabs where switching zooms out to show every panel side by side, slides along to the new one and zooms back in on it.

Live preview: https://movin.design/components/tabs/overview/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-overview
```

Or copy [`tab-overview.tsx`](./tab-overview.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-overview.html`](./tab-overview.html) where it goes and include [`tab-overview.css`](./tab-overview.css). [`tab-overview.js`](./tab-overview.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
