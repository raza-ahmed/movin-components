# Fog tab set

Views through misted window panes: the chosen pane is wiped clear in the direction you moved, and the one you left slowly mists back over.

Live preview: https://movin.design/components/tabs/fog/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-fog
```

Or copy [`tab-fog.tsx`](./tab-fog.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-fog.html`](./tab-fog.html) where it goes and include [`tab-fog.css`](./tab-fog.css). [`tab-fog.js`](./tab-fog.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
