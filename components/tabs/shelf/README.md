# Shelf tab set

Book spines as tabs: the book you pick tips forward off the shelf and the others settle back, and its title, author and a note appear below.

Live preview: https://movin.design/components/tabs/shelf/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-shelf
```

Or copy [`tab-shelf.tsx`](./tab-shelf.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-shelf.html`](./tab-shelf.html) where it goes and include [`tab-shelf.css`](./tab-shelf.css). [`tab-shelf.js`](./tab-shelf.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
