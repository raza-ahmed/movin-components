# Goo tab set

A segmented control whose pill is liquid: it pours from tab to tab, stretching a thinning bridge behind it before it pulls back into one drop.

Live preview: https://movin.design/components/tabs/goo/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-goo
```

Or copy [`tab-goo.tsx`](./tab-goo.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-goo.html`](./tab-goo.html) where it goes and include [`tab-goo.css`](./tab-goo.css). [`tab-goo.js`](./tab-goo.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
