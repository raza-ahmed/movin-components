# Doors tab set

Rooms behind doors: the chosen door swings open on its hinge to show the lit room, a beat after the one you left starts to close.

Live preview: https://movin.design/components/tabs/doors/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-doors
```

Or copy [`tab-doors.tsx`](./tab-doors.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-doors.html`](./tab-doors.html) where it goes and include [`tab-doors.css`](./tab-doors.css). [`tab-doors.js`](./tab-doors.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
