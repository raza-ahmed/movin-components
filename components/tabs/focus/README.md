# Focus tab set

Topic tabs with depth of field: labels soften with distance from the chosen one, and switching racks focus across the row; pointing at a tab racks to it for a look.

Live preview: https://movin.design/components/tabs/focus/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-focus
```

Or copy [`tab-focus.tsx`](./tab-focus.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-focus.html`](./tab-focus.html) where it goes and include [`tab-focus.css`](./tab-focus.css). [`tab-focus.js`](./tab-focus.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
