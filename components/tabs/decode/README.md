# Decode tab set

Project tabs where the heading scrambles through symbols and locks into the new words letter by letter, left to right.

Live preview: https://movin.design/components/tabs/decode/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-decode
```

Or copy [`tab-decode.tsx`](./tab-decode.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-decode.html`](./tab-decode.html) where it goes and include [`tab-decode.css`](./tab-decode.css). [`tab-decode.js`](./tab-decode.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
