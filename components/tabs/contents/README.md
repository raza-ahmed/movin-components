# Contents tab set

Vertical tabs set like a contents page: italic numerals, and a leader line that draws out to the chosen chapter as its page fades in.

Live preview: https://movin.design/components/tabs/contents/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-contents
```

Or copy [`tab-contents.tsx`](./tab-contents.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-contents.html`](./tab-contents.html) where it goes and include [`tab-contents.css`](./tab-contents.css). [`tab-contents.js`](./tab-contents.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
