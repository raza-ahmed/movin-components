# Caret tab set

Product tabs over a card whose pointer slides along its top edge to sit under the active tab, while the new text slides in from the side you moved towards.

Live preview: https://movin.design/components/tabs/caret/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-caret
```

Or copy [`tab-caret.tsx`](./tab-caret.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-caret.html`](./tab-caret.html) where it goes and include [`tab-caret.css`](./tab-caret.css). [`tab-caret.js`](./tab-caret.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
