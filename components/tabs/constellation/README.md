# Constellation tab set

Constellations as tabs: the stars glide into the next shape, the old lines vanish and the new ones draw themselves in once the stars arrive.

Live preview: https://movin.design/components/tabs/constellation/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-constellation
```

Or copy [`tab-constellation.tsx`](./tab-constellation.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-constellation.html`](./tab-constellation.html) where it goes and include [`tab-constellation.css`](./tab-constellation.css). [`tab-constellation.js`](./tab-constellation.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
