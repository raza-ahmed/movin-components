# Pixels tab set

Game level tabs: the new level shows through tile by tile as a cover of pixels clears in a scattered order.

Live preview: https://movin.design/components/tabs/pixels/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-pixels
```

Or copy [`tab-pixels.tsx`](./tab-pixels.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-pixels.html`](./tab-pixels.html) where it goes and include [`tab-pixels.css`](./tab-pixels.css). [`tab-pixels.js`](./tab-pixels.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
