# Shutter tab set

Camera mode tabs as icon buttons: the active one fills as six iris blades close over it, and they open again on the tab you left.

Live preview: https://movin.design/components/tabs/shutter/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-shutter
```

Or copy [`tab-shutter.tsx`](./tab-shutter.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-shutter.html`](./tab-shutter.html) where it goes and include [`tab-shutter.css`](./tab-shutter.css). [`tab-shutter.js`](./tab-shutter.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
