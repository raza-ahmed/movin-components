# Torch tab set

Stream tabs lit by a soft torch that follows your pointer along the row, above an underline that slides to the active tab.

Live preview: https://movin.design/components/tabs/torch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-torch
```

Or copy [`tab-torch.tsx`](./tab-torch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-torch.html`](./tab-torch.html) where it goes and include [`tab-torch.css`](./tab-torch.css). [`tab-torch.js`](./tab-torch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
