# Patch tab set

Phone lines on a switchboard: the plug lifts out, arcs to the new jack and pushes in, and the cord swings after it on real rope physics until it hangs still.

Live preview: https://movin.design/components/tabs/patch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-patch
```

Or copy [`tab-patch.tsx`](./tab-patch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-patch.html`](./tab-patch.html) where it goes and include [`tab-patch.css`](./tab-patch.css). [`tab-patch.js`](./tab-patch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
