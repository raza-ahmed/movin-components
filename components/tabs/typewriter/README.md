# Typewriter tab set

Letter tabs whose text types itself out behind a blinking caret each time you switch.

Live preview: https://movin.design/components/tabs/typewriter/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-typewriter
```

Or copy [`tab-typewriter.tsx`](./tab-typewriter.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-typewriter.html`](./tab-typewriter.html) where it goes and include [`tab-typewriter.css`](./tab-typewriter.css). [`tab-typewriter.js`](./tab-typewriter.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
