# Stencil tab set

A segmented control whose pill inverts the labels exactly where it covers them, so letters split in two as it slides between tabs.

Live preview: https://movin.design/components/tabs/stencil/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-stencil
```

Or copy [`tab-stencil.tsx`](./tab-stencil.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-stencil.html`](./tab-stencil.html) where it goes and include [`tab-stencil.css`](./tab-stencil.css). [`tab-stencil.js`](./tab-stencil.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
