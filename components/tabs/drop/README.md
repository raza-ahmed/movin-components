# Drop tab set

Range tabs over a stats panel: the old panel falls out of the bottom tipping over, and the new one drops in from above and bounces to rest.

Live preview: https://movin.design/components/tabs/drop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-drop
```

Or copy [`tab-drop.tsx`](./tab-drop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-drop.html`](./tab-drop.html) where it goes and include [`tab-drop.css`](./tab-drop.css). [`tab-drop.js`](./tab-drop.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
