# Kern tab set

Collection tabs in small caps whose active label opens its letter spacing; the row reflows around it, so every other label slides aside to make room.

Live preview: https://movin.design/components/tabs/kern/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-kern
```

Or copy [`tab-kern.tsx`](./tab-kern.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-kern.html`](./tab-kern.html) where it goes and include [`tab-kern.css`](./tab-kern.css). [`tab-kern.js`](./tab-kern.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
