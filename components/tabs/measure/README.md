# Measure tab set

Inspector tabs with a designer's dimension line spanning the active tab and its width in pixels; it stretches across to the new tab while the number counts through every width on the way.

Live preview: https://movin.design/components/tabs/measure/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-measure
```

Or copy [`tab-measure.tsx`](./tab-measure.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-measure.html`](./tab-measure.html) where it goes and include [`tab-measure.css`](./tab-measure.css). [`tab-measure.js`](./tab-measure.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
