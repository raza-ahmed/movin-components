# Popup tab set

Chapter tabs that lie flat on the page like a closed pop-up book: the active label stands up on its hinge with a little spring, and the one you left folds back down.

Live preview: https://movin.design/components/tabs/popup/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-popup
```

Or copy [`tab-popup.tsx`](./tab-popup.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-popup.html`](./tab-popup.html) where it goes and include [`tab-popup.css`](./tab-popup.css). [`tab-popup.js`](./tab-popup.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
