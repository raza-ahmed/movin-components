# Strips tab set

Places as tall strips side by side: the chosen strip widens to show its scene and words, its label lying down, while the rest narrow with their labels standing on end.

Live preview: https://movin.design/components/tabs/strips/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-strips
```

Or copy [`tab-strips.tsx`](./tab-strips.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-strips.html`](./tab-strips.html) where it goes and include [`tab-strips.css`](./tab-strips.css). [`tab-strips.js`](./tab-strips.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
