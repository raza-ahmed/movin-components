# Keys tab set

Tool tabs as keyboard keys: the active key stays pressed down with its light on, and the number keys switch tabs like shortcuts.

Live preview: https://movin.design/components/tabs/keys/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-keys
```

Or copy [`tab-keys.tsx`](./tab-keys.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-keys.html`](./tab-keys.html) where it goes and include [`tab-keys.css`](./tab-keys.css). [`tab-keys.js`](./tab-keys.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
