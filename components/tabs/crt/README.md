# CRT tab set

Channels on an old television: the picture squeezes to a bright line and a dot, swaps, then springs back open on the new channel.

Live preview: https://movin.design/components/tabs/crt/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-crt
```

Or copy [`tab-crt.tsx`](./tab-crt.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-crt.html`](./tab-crt.html) where it goes and include [`tab-crt.css`](./tab-crt.css). [`tab-crt.js`](./tab-crt.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
