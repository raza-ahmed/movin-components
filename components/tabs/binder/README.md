# Binder tab set

A ring binder with index tabs down the edge of the page: the chosen tab pulls out and the page turns to its section.

Live preview: https://movin.design/components/tabs/binder/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-binder
```

Or copy [`tab-binder.tsx`](./tab-binder.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-binder.html`](./tab-binder.html) where it goes and include [`tab-binder.css`](./tab-binder.css). [`tab-binder.js`](./tab-binder.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
