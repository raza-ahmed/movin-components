# Editor tab set

Code editor tabs: the accent line slides over to the new file and its lines of code come in one by one.

Live preview: https://movin.design/components/tabs/editor/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-editor
```

Or copy [`tab-editor.tsx`](./tab-editor.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-editor.html`](./tab-editor.html) where it goes and include [`tab-editor.css`](./tab-editor.css). [`tab-editor.js`](./tab-editor.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
