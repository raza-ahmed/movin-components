# Orbit tab set

Planet tabs with a small moon orbiting the active label, passing behind it and in front of it on a tilted ellipse; pick another and it swings across into orbit around the new one.

Live preview: https://movin.design/components/tabs/orbit/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-orbit
```

Or copy [`tab-orbit.tsx`](./tab-orbit.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-orbit.html`](./tab-orbit.html) where it goes and include [`tab-orbit.css`](./tab-orbit.css). [`tab-orbit.js`](./tab-orbit.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
