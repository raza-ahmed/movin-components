# Carry tab set

Product tabs whose label flies down and grows into the panel heading when picked, while the old heading shrinks back up into its own tab.

Live preview: https://movin.design/components/tabs/carry/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-carry
```

Or copy [`tab-carry.tsx`](./tab-carry.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-carry.html`](./tab-carry.html) where it goes and include [`tab-carry.css`](./tab-carry.css). [`tab-carry.js`](./tab-carry.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
