# Ribbon tab set

Recipe tabs with a bookmark ribbon: it drops down onto the active tab while the old one pulls back up.

Live preview: https://movin.design/components/tabs/ribbon/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-ribbon
```

Or copy [`tab-ribbon.tsx`](./tab-ribbon.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-ribbon.html`](./tab-ribbon.html) where it goes and include [`tab-ribbon.css`](./tab-ribbon.css). [`tab-ribbon.js`](./tab-ribbon.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
