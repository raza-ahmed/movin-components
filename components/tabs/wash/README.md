# Wash tab set

Palette tabs marked by a watercolour wash: the soft blot glides to the new tab and blooms into the paper, its edge roughened like paint soaking in.

Live preview: https://movin.design/components/tabs/wash/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-wash
```

Or copy [`tab-wash.tsx`](./tab-wash.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-wash.html`](./tab-wash.html) where it goes and include [`tab-wash.css`](./tab-wash.css). [`tab-wash.js`](./tab-wash.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
