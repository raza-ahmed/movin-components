# Tape tab set

Collection tags held by washi tape: the tape peels off the old tag from one end and a fresh strip unrolls and presses down onto the new one.

Live preview: https://movin.design/components/tabs/tape/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-tape
```

Or copy [`tab-tape.tsx`](./tab-tape.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-tape.html`](./tab-tape.html) where it goes and include [`tab-tape.css`](./tab-tape.css). [`tab-tape.js`](./tab-tape.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
