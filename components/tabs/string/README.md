# String tab set

Section tabs over a taut string with a bead weighing it down at the active tab: the bead slides over and the string twangs when it lands.

Live preview: https://movin.design/components/tabs/string/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-string
```

Or copy [`tab-string.tsx`](./tab-string.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-string.html`](./tab-string.html) where it goes and include [`tab-string.css`](./tab-string.css). [`tab-string.js`](./tab-string.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
