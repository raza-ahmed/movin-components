# Scroll tab set

Decree tabs on a scroll: pick a numeral and the parchment unrolls from the top rod with its roll travelling down, revealing the new decree.

Live preview: https://movin.design/components/tabs/scroll/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-scroll
```

Or copy [`tab-scroll.tsx`](./tab-scroll.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-scroll.html`](./tab-scroll.html) where it goes and include [`tab-scroll.css`](./tab-scroll.css). [`tab-scroll.js`](./tab-scroll.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
