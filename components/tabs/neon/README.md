# Neon tab set

Neon signs as tabs: the chosen sign stutters on a few times before it holds, the old one fades off, and a letter of the lit sign buzzes now and then.

Live preview: https://movin.design/components/tabs/neon/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-neon
```

Or copy [`tab-neon.tsx`](./tab-neon.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-neon.html`](./tab-neon.html) where it goes and include [`tab-neon.css`](./tab-neon.css). [`tab-neon.js`](./tab-neon.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
