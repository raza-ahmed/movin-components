# Split tab set

A segmented control that is one continuous bar until you pick: the active tab parts from it, with gaps opening either side and its corners rounding off into a pill of its own.

Live preview: https://movin.design/components/tabs/split/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-split
```

Or copy [`tab-split.tsx`](./tab-split.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-split.html`](./tab-split.html) where it goes and include [`tab-split.css`](./tab-split.css). [`tab-split.js`](./tab-split.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
