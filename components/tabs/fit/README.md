# Fit tab set

Settings tabs whose box eases to the height of each panel, the old content blurring out as the new rows fade in one after another.

Live preview: https://movin.design/components/tabs/fit/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-fit
```

Or copy [`tab-fit.tsx`](./tab-fit.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-fit.html`](./tab-fit.html) where it goes and include [`tab-fit.css`](./tab-fit.css). [`tab-fit.js`](./tab-fit.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
