# Browser tab set

Browser tabs with curved feet: the new tab lifts into place, its icon spins once as the page loads and the page skeleton fades in.

Live preview: https://movin.design/components/tabs/browser/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-browser
```

Or copy [`tab-browser.tsx`](./tab-browser.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-browser.html`](./tab-browser.html) where it goes and include [`tab-browser.css`](./tab-browser.css). [`tab-browser.js`](./tab-browser.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
