# Puck tab set

A segmented control with a raised puck sitting in a recessed groove: it leans into the slide like something with weight and settles flat when it stops.

Live preview: https://movin.design/components/tabs/puck/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-puck
```

Or copy [`tab-puck.tsx`](./tab-puck.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-puck.html`](./tab-puck.html) where it goes and include [`tab-puck.css`](./tab-puck.css). [`tab-puck.js`](./tab-puck.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
