# Pin tab set

Notes on a corkboard: the pin pulls out of one note, arcs over growing as it lifts, pushes into the next and that note swings straight while the old one tilts.

Live preview: https://movin.design/components/tabs/pin/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-pin
```

Or copy [`tab-pin.tsx`](./tab-pin.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-pin.html`](./tab-pin.html) where it goes and include [`tab-pin.css`](./tab-pin.css). [`tab-pin.js`](./tab-pin.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
