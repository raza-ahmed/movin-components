# Develop tab set

Trip tabs as instant photos: pick a place and the new print develops in its frame, surfacing dark and soft from a pale blank and clearing to full contrast.

Live preview: https://movin.design/components/tabs/develop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-develop
```

Or copy [`tab-develop.tsx`](./tab-develop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-develop.html`](./tab-develop.html) where it goes and include [`tab-develop.css`](./tab-develop.css). [`tab-develop.js`](./tab-develop.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
