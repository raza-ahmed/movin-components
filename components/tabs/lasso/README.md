# Lasso tab set

Meal tabs caught with a rope: the loop loosens, flies over spinning, drops wide round the new label and cinches tight, the rope trailing off to a hand.

Live preview: https://movin.design/components/tabs/lasso/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-lasso
```

Or copy [`tab-lasso.tsx`](./tab-lasso.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-lasso.html`](./tab-lasso.html) where it goes and include [`tab-lasso.css`](./tab-lasso.css). [`tab-lasso.js`](./tab-lasso.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
