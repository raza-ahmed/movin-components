# Icons tab set

A bottom bar whose icons act out their meaning when picked: the door opens with a puff from the chimney, the glass scans, the bell rings and the head nods.

Live preview: https://movin.design/components/tabs/icons/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-icons
```

Or copy [`tab-icons.tsx`](./tab-icons.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-icons.html`](./tab-icons.html) where it goes and include [`tab-icons.css`](./tab-icons.css). [`tab-icons.js`](./tab-icons.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
