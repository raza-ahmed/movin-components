# Inchworm tab set

Dashboard tabs with an underline that moves like an inchworm: its leading edge reaches the new tab first and the tail draws up behind it.

Live preview: https://movin.design/components/tabs/inchworm/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-inchworm
```

Or copy [`tab-inchworm.tsx`](./tab-inchworm.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-inchworm.html`](./tab-inchworm.html) where it goes and include [`tab-inchworm.css`](./tab-inchworm.css). [`tab-inchworm.js`](./tab-inchworm.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
