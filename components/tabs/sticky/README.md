# Sticky tab set

Sticky flags on a notepad as to-do tabs: the chosen flag stands up and the note under it settles into place.

Live preview: https://movin.design/components/tabs/sticky/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-sticky
```

Or copy [`tab-sticky.tsx`](./tab-sticky.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-sticky.html`](./tab-sticky.html) where it goes and include [`tab-sticky.css`](./tab-sticky.css). [`tab-sticky.js`](./tab-sticky.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
