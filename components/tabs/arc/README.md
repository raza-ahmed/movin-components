# Arc tab set

Power sources as tabs: an electric arc jumps from the old source to the new one, crackling and flickering for a moment before the new node lights.

Live preview: https://movin.design/components/tabs/arc/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-arc
```

Or copy [`tab-arc.tsx`](./tab-arc.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-arc.html`](./tab-arc.html) where it goes and include [`tab-arc.css`](./tab-arc.css). [`tab-arc.js`](./tab-arc.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
