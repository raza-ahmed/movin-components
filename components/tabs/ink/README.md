# Ink tab set

Mail tabs where ink spreads out from exactly where you pressed the tab and drains away from the one you left.

Live preview: https://movin.design/components/tabs/ink/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-ink
```

Or copy [`tab-ink.tsx`](./tab-ink.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-ink.html`](./tab-ink.html) where it goes and include [`tab-ink.css`](./tab-ink.css). [`tab-ink.js`](./tab-ink.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
