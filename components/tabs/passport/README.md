# Passport tab set

Trips as tabs: pick a country and its entry stamp slams onto the passport page, giving the page a jolt.

Live preview: https://movin.design/components/tabs/passport/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-passport
```

Or copy [`tab-passport.tsx`](./tab-passport.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-passport.html`](./tab-passport.html) where it goes and include [`tab-passport.css`](./tab-passport.css). [`tab-passport.js`](./tab-passport.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
