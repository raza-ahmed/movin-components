# Claw tab set

Arcade tabs in a claw machine: the claw lowers the tab it holds back into its slot, rides the gantry to the one you pick, swinging on its cable, then grips it and lifts it out.

Live preview: https://movin.design/components/tabs/claw/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-claw
```

Or copy [`tab-claw.tsx`](./tab-claw.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-claw.html`](./tab-claw.html) where it goes and include [`tab-claw.css`](./tab-claw.css). [`tab-claw.js`](./tab-claw.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
