# Departures tab set

Destination tabs on a split-flap board: pick a city and every letter of the destination, time and gate flaps over to the new one, cell by cell from left to right.

Live preview: https://movin.design/components/tabs/departures/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-departures
```

Or copy [`tab-departures.tsx`](./tab-departures.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-departures.html`](./tab-departures.html) where it goes and include [`tab-departures.css`](./tab-departures.css). [`tab-departures.js`](./tab-departures.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
