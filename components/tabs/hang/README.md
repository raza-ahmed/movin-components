# Hang tab set

Venue tabs with the panel hung from the active tab on two cords: pick another and the hook slides over, setting the panel swinging before it settles.

Live preview: https://movin.design/components/tabs/hang/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-hang
```

Or copy [`tab-hang.tsx`](./tab-hang.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-hang.html`](./tab-hang.html) where it goes and include [`tab-hang.css`](./tab-hang.css). [`tab-hang.js`](./tab-hang.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
