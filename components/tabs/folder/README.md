# Folder tab set

File folder tabs: the active tab rises and joins the folder body, and the new page of files slides up into it.

Live preview: https://movin.design/components/tabs/folder/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-folder
```

Or copy [`tab-folder.tsx`](./tab-folder.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-folder.html`](./tab-folder.html) where it goes and include [`tab-folder.css`](./tab-folder.css). [`tab-folder.js`](./tab-folder.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
