# Trace tab set

Photo library tabs where a line draws itself around the active tab and unwinds from the one you left.

Live preview: https://movin.design/components/tabs/trace/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-trace
```

Or copy [`tab-trace.tsx`](./tab-trace.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-trace.html`](./tab-trace.html) where it goes and include [`tab-trace.css`](./tab-trace.css). [`tab-trace.js`](./tab-trace.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
