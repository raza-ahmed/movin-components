# Cabinet tab set

Library card-catalogue drawers as vertical tabs: the chosen drawer pulls out and its index card rises beside it with the entry.

Live preview: https://movin.design/components/tabs/cabinet/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/tab-cabinet
```

Or copy [`tab-cabinet.tsx`](./tab-cabinet.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`tab-cabinet.html`](./tab-cabinet.html) where it goes and include [`tab-cabinet.css`](./tab-cabinet.css). [`tab-cabinet.js`](./tab-cabinet.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
