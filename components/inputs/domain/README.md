# Domain input

An email field that finishes the domain for you: after the @ it ghost-completes the likeliest domain, the arrow keys cycle through the alternatives, and Tab accepts with a sweep under the field. A tick draws in once the address is valid.

Live preview: https://movin.design/components/inputs/domain/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-domain
```

Or copy [`input-domain.tsx`](./input-domain.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-domain.html`](./input-domain.html) where it goes and include [`input-domain.css`](./input-domain.css). [`input-domain.js`](./input-domain.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
