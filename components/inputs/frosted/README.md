# Frosted input

On focus, the input transitions to a frosted glass look: backdrop-filter blur increases and the background shifts to semi-transparent white. Clean glassmorphism aesthetic.

Live preview: https://movin.design/components/inputs/frosted/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-frosted
```

Or copy [`input-frosted.tsx`](./input-frosted.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-frosted.html`](./input-frosted.html) where it goes and include [`input-frosted.css`](./input-frosted.css). It is pure CSS, so there is no script.
