# Wobble input

On focus the input jiggles with a CSS keyframe combining rotation and translateX zigzag over 400ms then settles. Playful tactile feedback.

Live preview: https://movin.design/components/inputs/wobble/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-wobble
```

Or copy [`input-wobble.tsx`](./input-wobble.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-wobble.html`](./input-wobble.html) where it goes and include [`input-wobble.css`](./input-wobble.css). It is pure CSS, so there is no script.
