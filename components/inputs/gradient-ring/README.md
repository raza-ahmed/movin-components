# Gradient Ring input

On focus a conic-gradient border continuously rotates around the input using a @property CSS custom property (--gr-angle) animated from 0deg to 360deg. The ring fades in with opacity and fades out on blur.

Live preview: https://movin.design/components/inputs/gradient-ring/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-gradient-ring.json
```

Or copy [`input-gradient-ring.tsx`](./input-gradient-ring.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-gradient-ring.html`](./input-gradient-ring.html) where it goes and include [`input-gradient-ring.css`](./input-gradient-ring.css). It is pure CSS, so there is no script.
