# Drum input

An alarm-time picker made of 3D drums: hour, minute and AM/PM wheels you drag, scroll or arrow through. The numbers sit round real cylinders that turn under a raised lens and snap to the nearest row.

Live preview: https://movin.design/components/inputs/drum/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-drum
```

Or copy [`input-drum.tsx`](./input-drum.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-drum.html`](./input-drum.html) where it goes and include [`input-drum.css`](./input-drum.css). [`input-drum.js`](./input-drum.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
