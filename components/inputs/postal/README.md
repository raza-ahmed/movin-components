# Postal input

A postcode field drawn as postage stamps: each character is stamped into its own perforated stamp at a slight angle, and the row is franked with wavy lines once it is complete.

Live preview: https://movin.design/components/inputs/postal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-postal
```

Or copy [`input-postal.tsx`](./input-postal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-postal.html`](./input-postal.html) where it goes and include [`input-postal.css`](./input-postal.css). [`input-postal.js`](./input-postal.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
