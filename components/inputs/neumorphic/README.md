# Neumorphic input

Outer raised dual-shadow transitions to an inset pressed dual-shadow on focus, making the input appear to sink into the soft surface. Smooth 250ms transition.

Live preview: https://movin.design/components/inputs/neumorphic/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-neumorphic.json
```

Or copy [`input-neumorphic.tsx`](./input-neumorphic.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-neumorphic.html`](./input-neumorphic.html) where it goes and include [`input-neumorphic.css`](./input-neumorphic.css). It is pure CSS, so there is no script.
