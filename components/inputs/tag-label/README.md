# Tag Label input

On focus the label slides upward and a light pill badge background expands behind it via scaleX. The label transforms from a plain hint into a bold field identifier tag.

Live preview: https://movin.design/components/inputs/tag-label/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-tag-label
```

Or copy [`input-tag-label.tsx`](./input-tag-label.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-tag-label.html`](./input-tag-label.html) where it goes and include [`input-tag-label.css`](./input-tag-label.css). It is pure CSS, so there is no script.
