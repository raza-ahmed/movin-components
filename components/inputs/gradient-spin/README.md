# Gradient Spin input

A conic-gradient border rotates continuously while the input is focused, achieved by spinning a larger gradient square behind a clipped wrapper to simulate an animated gradient border.

Live preview: https://movin.design/components/inputs/gradient-spin/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-gradient-spin.json
```

Or copy [`input-gradient-spin.tsx`](./input-gradient-spin.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-gradient-spin.html`](./input-gradient-spin.html) where it goes and include [`input-gradient-spin.css`](./input-gradient-spin.css). It is pure CSS, so there is no script.
