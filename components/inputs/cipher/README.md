# Cipher input

A password field where every character scrambles through glyphs for a moment before it settles into a dot. Show decodes them all in a wave into the real characters; Hide scrambles them back.

Live preview: https://movin.design/components/inputs/cipher/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-cipher
```

Or copy [`input-cipher.tsx`](./input-cipher.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-cipher.html`](./input-cipher.html) where it goes and include [`input-cipher.css`](./input-cipher.css). [`input-cipher.js`](./input-cipher.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
