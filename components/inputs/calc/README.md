# Calc input

An amount field that does arithmetic: type a sum and the total rolls in beside it digit by digit; Enter swaps the total in with a flash and keeps the sum it came from as a note below.

Live preview: https://movin.design/components/inputs/calc/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-calc
```

Or copy [`input-calc.tsx`](./input-calc.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-calc.html`](./input-calc.html) where it goes and include [`input-calc.css`](./input-calc.css). [`input-calc.js`](./input-calc.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
