# Particle Burst input

Small particles burst outward from the input corners on focus via absolutely positioned spans with staggered CSS animations. A festive, energetic focus confirmation.

Live preview: https://movin.design/components/inputs/particle-burst/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-particle-burst.json
```

Or copy [`input-particle-burst.tsx`](./input-particle-burst.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-particle-burst.html`](./input-particle-burst.html) where it goes and include [`input-particle-burst.css`](./input-particle-burst.css). It is pure CSS, so there is no script.
