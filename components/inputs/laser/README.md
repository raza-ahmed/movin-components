# Laser input

On focus a white laser beam sweeps left-to-right along the bottom border via scaleX keyframe (300ms), leaving a persistent glowing hairline underline.

Live preview: https://movin.design/components/inputs/laser/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-laser
```

Or copy [`input-laser.tsx`](./input-laser.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-laser.html`](./input-laser.html) where it goes and include [`input-laser.css`](./input-laser.css). It is pure CSS, so there is no script.
