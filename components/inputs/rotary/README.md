# Rotary input

Dial a number on a rotary phone: drag a finger hole clockwise to the stop and let go, and the disc springs back at a steady speed while the digit is added. Typing digits in the field dials them too.

Live preview: https://movin.design/components/inputs/rotary/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-rotary
```

Or copy [`input-rotary.tsx`](./input-rotary.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-rotary.html`](./input-rotary.html) where it goes and include [`input-rotary.css`](./input-rotary.css). [`input-rotary.js`](./input-rotary.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
