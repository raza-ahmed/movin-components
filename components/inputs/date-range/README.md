# Date Range input

A stay-dates calendar: pick a first night and a band previews the stay as you hover, then pick the last night and the band settles, gliding across each week row to join the two days.

Live preview: https://movin.design/components/inputs/date-range/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-date-range
```

Or copy [`input-date-range.tsx`](./input-date-range.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-date-range.html`](./input-date-range.html) where it goes and include [`input-date-range.css`](./input-date-range.css). [`input-date-range.js`](./input-date-range.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
