# Count Ring input

An SVG circular ring fills via stroke-dashoffset around a character count badge as the user approaches the limit. The ring brightens from mid-gray to white near the maximum.

Live preview: https://movin.design/components/inputs/count-ring/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-count-ring.json
```

Or copy [`input-count-ring.tsx`](./input-count-ring.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-count-ring.html`](./input-count-ring.html) where it goes and include [`input-count-ring.css`](./input-count-ring.css). [`input-count-ring.js`](./input-count-ring.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
