# Typewriter input

A note field that types like a typewriter: each key strikes the paper with its own slight tilt and ink density, the carriage slides the line along so the type always lands at the strike point, and a bell dings every twenty characters.

Live preview: https://movin.design/components/inputs/typewriter/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-typewriter
```

Or copy [`input-typewriter.tsx`](./input-typewriter.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-typewriter.html`](./input-typewriter.html) where it goes and include [`input-typewriter.css`](./input-typewriter.css). [`input-typewriter.js`](./input-typewriter.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
