# Heat input

A message field that heats up with your typing speed: letters typed fast come out glowing hot and lifted, then cool to the normal colour over a couple of seconds, and a meter shows your words per minute.

Live preview: https://movin.design/components/inputs/heat/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-heat
```

Or copy [`input-heat.tsx`](./input-heat.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-heat.html`](./input-heat.html) where it goes and include [`input-heat.css`](./input-heat.css). [`input-heat.js`](./input-heat.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
