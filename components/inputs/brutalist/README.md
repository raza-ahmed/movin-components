# Brutalist input

Neo-brutalist style: on focus a hard 4px offset black box-shadow slams from an offset position to zero, while the border snaps to high-contrast. Snappy cubic-bezier easing.

Live preview: https://movin.design/components/inputs/brutalist/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-brutalist
```

Or copy [`input-brutalist.tsx`](./input-brutalist.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-brutalist.html`](./input-brutalist.html) where it goes and include [`input-brutalist.css`](./input-brutalist.css). It is pure CSS, so there is no script.
