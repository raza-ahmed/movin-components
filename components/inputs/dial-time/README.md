# Dial time input

A pickup time field: type a 24-hour time and the clock beside it sweeps its hands round to the time with a little overshoot, and says whether it is morning, afternoon or night.

Live preview: https://movin.design/components/inputs/dial-time/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-dial-time
```

Or copy [`input-dial-time.tsx`](./input-dial-time.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-dial-time.html`](./input-dial-time.html) where it goes and include [`input-dial-time.css`](./input-dial-time.css). [`input-dial-time.js`](./input-dial-time.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
