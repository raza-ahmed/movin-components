# Angle input

A dial for gradient angles: drag round the ring and the hand follows, pulling toward each 45-degree mark (Shift snaps to 15), the nearest tick lights, and the number field and a live gradient swatch follow.

Live preview: https://movin.design/components/inputs/angle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-angle
```

Or copy [`input-angle.tsx`](./input-angle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-angle.html`](./input-angle.html) where it goes and include [`input-angle.css`](./input-angle.css). [`input-angle.js`](./input-angle.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
