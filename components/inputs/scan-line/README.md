# Scan Line input

A horizontal scan line sweeps top-to-bottom through the focused input continuously on a ~2s CSS keyframe loop. Futuristic active-state ambient indicator.

Live preview: https://movin.design/components/inputs/scan-line/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-scan-line
```

Or copy [`input-scan-line.tsx`](./input-scan-line.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-scan-line.html`](./input-scan-line.html) where it goes and include [`input-scan-line.css`](./input-scan-line.css). It is pure CSS, so there is no script.
