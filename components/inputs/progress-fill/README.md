# Progress Fill input

The input background fills left-to-right proportional to the typed character count relative to a target length. A calm, satisfying completion indicator with smooth transitions.

Live preview: https://movin.design/components/inputs/progress-fill/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-progress-fill.json
```

Or copy [`input-progress-fill.tsx`](./input-progress-fill.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-progress-fill.html`](./input-progress-fill.html) where it goes and include [`input-progress-fill.css`](./input-progress-fill.css). [`input-progress-fill.js`](./input-progress-fill.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
