# Quill input

A dedication field written with a quill: the quill rides the end of your words, fresh letters land in wet ink that blooms and then dries, and every few words it dips back in the pot.

Live preview: https://movin.design/components/inputs/quill/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-quill
```

Or copy [`input-quill.tsx`](./input-quill.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-quill.html`](./input-quill.html) where it goes and include [`input-quill.css`](./input-quill.css). [`input-quill.js`](./input-quill.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
