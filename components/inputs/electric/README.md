# Electric input

An SVG overlay traces an electric arc around the input border via stroke-dashoffset animation on focus. White neon sparking effect that completes a full perimeter trace.

Live preview: https://movin.design/components/inputs/electric/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-electric.json
```

Or copy [`input-electric.tsx`](./input-electric.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-electric.html`](./input-electric.html) where it goes and include [`input-electric.css`](./input-electric.css). It is pure CSS, so there is no script.
