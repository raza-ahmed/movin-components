# Border Draw input

On focus, four border lines trace around the input clockwise (top, right, bottom, left), each starting after the previous finishes. Pure CSS transforms, no dependencies.

Live preview: https://movin.design/components/inputs/border-draw/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-border-draw
```

Or copy [`input-border-draw.tsx`](./input-border-draw.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-border-draw.html`](./input-border-draw.html) where it goes and include [`input-border-draw.css`](./input-border-draw.css). It is pure CSS, so there is no script.
