# Split Label input

A floating label that splits into its words: on focus each word rises above the field and shrinks on its own, staggered left to right, then drops back in reverse when the field is cleared.

Live preview: https://movin.design/components/inputs/split-label/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-split-label
```

Or copy [`input-split-label.tsx`](./input-split-label.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-split-label.html`](./input-split-label.html) where it goes and include [`input-split-label.css`](./input-split-label.css). [`input-split-label.js`](./input-split-label.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
