# Morph Shape input

Border-radius morphs through a personality arc on focus: sharp (2px) → pill (50px) → settled rounded (10px), played with the Web Animations API so typing is never interrupted.

Live preview: https://movin.design/components/inputs/morph-shape/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-morph-shape
```

Or copy [`input-morph-shape.tsx`](./input-morph-shape.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-morph-shape.html`](./input-morph-shape.html) where it goes and include [`input-morph-shape.css`](./input-morph-shape.css). It is pure CSS, so there is no script.
