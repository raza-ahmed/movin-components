# Ink input

A dedication card where every letter bleeds onto the paper like ink: it lands blurred and slightly large, sharpens as it dries, and leaves a small blot spreading out beneath it.

Live preview: https://movin.design/components/inputs/ink/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-ink
```

Or copy [`input-ink.tsx`](./input-ink.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-ink.html`](./input-ink.html) where it goes and include [`input-ink.css`](./input-ink.css). [`input-ink.js`](./input-ink.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
