# Ripple Type input

Each keystroke triggers a brief border-color ripple pulse on the input via a CSS keyframe that spikes to accent then settles back. The input visually feels each character typed.

Live preview: https://movin.design/components/inputs/ripple-type/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-ripple-type
```

Or copy [`input-ripple-type.tsx`](./input-ripple-type.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-ripple-type.html`](./input-ripple-type.html) where it goes and include [`input-ripple-type.css`](./input-ripple-type.css). [`input-ripple-type.js`](./input-ripple-type.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
