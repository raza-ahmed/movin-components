# Magnetic Label input

The label springs from center-left into the top-left corner of the input on focus using Framer Motion layout animation. Springs back on blur if the field is empty.

Live preview: https://movin.design/components/inputs/magnetic-label/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-magnetic-label.json
```

Or copy [`input-magnetic-label.tsx`](./input-magnetic-label.tsx) into your project. Dependencies: framer-motion.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-magnetic-label.html`](./input-magnetic-label.html) where it goes and include [`input-magnetic-label.css`](./input-magnetic-label.css). It is pure CSS, so there is no script.
