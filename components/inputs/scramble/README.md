# Scramble input

A PIN pad whose keys glide to new places after every press, so the pattern of taps gives nothing away. Four dots fill as you go, and a full PIN shakes the dots and resets.

Live preview: https://movin.design/components/inputs/scramble/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-scramble
```

Or copy [`input-scramble.tsx`](./input-scramble.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-scramble.html`](./input-scramble.html) where it goes and include [`input-scramble.css`](./input-scramble.css). [`input-scramble.js`](./input-scramble.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
