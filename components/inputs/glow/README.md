# Glow input

On focus the border lights up and a soft halo radiates outward via box-shadow. Pure CSS transitions, no dependencies.

Live preview: https://movin.design/components/inputs/glow/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-glow
```

Or copy [`input-glow.tsx`](./input-glow.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-glow.html`](./input-glow.html) where it goes and include [`input-glow.css`](./input-glow.css). It is pure CSS, so there is no script.
