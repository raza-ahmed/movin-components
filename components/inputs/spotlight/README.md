# Spotlight input

A radial gradient spotlight follows the cursor horizontally inside the input as the user mouses over it, creating a torch-light illumination effect within the field.

Live preview: https://movin.design/components/inputs/spotlight/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-spotlight
```

Or copy [`input-spotlight.tsx`](./input-spotlight.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-spotlight.html`](./input-spotlight.html) where it goes and include [`input-spotlight.css`](./input-spotlight.css). [`input-spotlight.js`](./input-spotlight.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
