# Natural Date input

A reminder field that reads plain language: write "next fri 3pm", "tomorrow 9am" or "in 3 days" and a calendar chip flips in with the exact date, time and how long until then.

Live preview: https://movin.design/components/inputs/natural-date/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-natural-date
```

Or copy [`input-natural-date.tsx`](./input-natural-date.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-natural-date.html`](./input-natural-date.html) where it goes and include [`input-natural-date.css`](./input-natural-date.css). [`input-natural-date.js`](./input-natural-date.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
