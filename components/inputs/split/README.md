# Split input

Two opaque panels cover the input at rest like sliding doors. On focus they translate outward (left panel slides left, right panel slides right), revealing a gradient background underneath. A sharp cubic-bezier gives the reveal a decisive, mechanical feel.

Live preview: https://movin.design/components/inputs/split/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-split
```

Or copy [`input-split.tsx`](./input-split.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-split.html`](./input-split.html) where it goes and include [`input-split.css`](./input-split.css). It is pure CSS, so there is no script.
