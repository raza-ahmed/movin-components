# Pin drop input

A meeting place field: type a city and once it can only be one place, a pin drops onto a dotted world map where it is, a ripple rings out and the country appears in the field.

Live preview: https://movin.design/components/inputs/pin-drop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-pin-drop
```

Or copy [`input-pin-drop.tsx`](./input-pin-drop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-pin-drop.html`](./input-pin-drop.html) where it goes and include [`input-pin-drop.css`](./input-pin-drop.css). [`input-pin-drop.js`](./input-pin-drop.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
