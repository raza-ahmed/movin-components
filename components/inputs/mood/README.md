# Mood input

A rating slider with a face: drag it and the mouth bends from a frown to a grin, the brows tilt, the eyes open wider and the cheeks blush as the mood rises, with the word flipping above. The face blinks now and then.

Live preview: https://movin.design/components/inputs/mood/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-mood
```

Or copy [`input-mood.tsx`](./input-mood.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-mood.html`](./input-mood.html) where it goes and include [`input-mood.css`](./input-mood.css). [`input-mood.js`](./input-mood.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
