# Liquid Fill input

An animated liquid wave rises from the bottom of the input via clip-path polygon updated by requestAnimationFrame on focus. The wave oscillates continuously while focused.

Live preview: https://movin.design/components/inputs/liquid-fill/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-liquid-fill.json
```

Or copy [`input-liquid-fill.tsx`](./input-liquid-fill.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-liquid-fill.html`](./input-liquid-fill.html) where it goes and include [`input-liquid-fill.css`](./input-liquid-fill.css). [`input-liquid-fill.js`](./input-liquid-fill.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
