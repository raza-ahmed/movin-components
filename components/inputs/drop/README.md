# Drop Letters input

Every letter you type drops into the field from above with a little tumble and bounce, and letters you delete fall out through the floor. A real input keeps the caret, selection and typing; a mirror line draws the letters over it.

Live preview: https://movin.design/components/inputs/drop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-drop
```

Or copy [`input-drop.tsx`](./input-drop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-drop.html`](./input-drop.html) where it goes and include [`input-drop.css`](./input-drop.css). [`input-drop.js`](./input-drop.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
