# Extrude input

A headline field that renders your text as solid 3D type above it: the extrusion turns to face the pointer, swaying gently on its own when you are elsewhere, and each new letter pops out of the depth.

Live preview: https://movin.design/components/inputs/extrude/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-extrude
```

Or copy [`input-extrude.tsx`](./input-extrude.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-extrude.html`](./input-extrude.html) where it goes and include [`input-extrude.css`](./input-extrude.css). [`input-extrude.js`](./input-extrude.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
