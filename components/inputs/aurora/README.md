# Aurora input

Blurred bands of light drift around the input on focus — a conic gradient whose start angle rotates via an animated @property. When unfocused, the glow fades out.

Live preview: https://movin.design/components/inputs/aurora/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-aurora
```

Or copy [`input-aurora.tsx`](./input-aurora.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-aurora.html`](./input-aurora.html) where it goes and include [`input-aurora.css`](./input-aurora.css). It is pure CSS, so there is no script.
