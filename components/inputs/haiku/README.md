# Haiku input

A haiku field in three lines with syllable beads beside each one that fill as you write five, seven and five; go over and the extra shows, and get all three right for a seal to stamp down.

Live preview: https://movin.design/components/inputs/haiku/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-haiku
```

Or copy [`input-haiku.tsx`](./input-haiku.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-haiku.html`](./input-haiku.html) where it goes and include [`input-haiku.css`](./input-haiku.css). [`input-haiku.js`](./input-haiku.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
