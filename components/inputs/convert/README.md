# Convert input

A unit converter in one field: type a value with a unit (km, mi, m, ft, kg, g, lb, °C, °F) and every conversion in that family appears below, each number counting to its new value as you edit.

Live preview: https://movin.design/components/inputs/convert/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-convert
```

Or copy [`input-convert.tsx`](./input-convert.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-convert.html`](./input-convert.html) where it goes and include [`input-convert.css`](./input-convert.css). [`input-convert.js`](./input-convert.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
