# Lens Search input

Search that starts as a magnifying glass. Focusing it stretches the glass's ring sideways into the field itself while the handle tucks away and a small lens settles inside; empty it and click away and it shrinks back into the glass. Pure CSS.

Live preview: https://movin.design/components/inputs/lens/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-lens
```

Or copy [`input-lens.tsx`](./input-lens.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-lens.html`](./input-lens.html) where it goes and include [`input-lens.css`](./input-lens.css). It is pure CSS, so there is no script.
