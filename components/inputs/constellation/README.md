# Constellation input

Make a wish: every letter you type becomes a star in the night sky above the field, joined to the previous one by a line that draws in, and the whole figure glides to stay centred as it grows.

Live preview: https://movin.design/components/inputs/constellation/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-constellation
```

Or copy [`input-constellation.tsx`](./input-constellation.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-constellation.html`](./input-constellation.html) where it goes and include [`input-constellation.css`](./input-constellation.css). [`input-constellation.js`](./input-constellation.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
