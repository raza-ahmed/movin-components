# Flapboard input

Type a destination and a split-flap departure board rolls every cell through the alphabet to the new letters, one flap at a time, with the status reading Updating until the board settles.

Live preview: https://movin.design/components/inputs/flapboard/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-flapboard
```

Or copy [`input-flapboard.tsx`](./input-flapboard.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-flapboard.html`](./input-flapboard.html) where it goes and include [`input-flapboard.css`](./input-flapboard.css). [`input-flapboard.js`](./input-flapboard.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
