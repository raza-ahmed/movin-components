# Match input

A confirm password pair: beads between the two fields light and link up as each character of the confirmation matches, shake at the first wrong one, and close into a chain when they all match.

Live preview: https://movin.design/components/inputs/match/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-match
```

Or copy [`input-match.tsx`](./input-match.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-match.html`](./input-match.html) where it goes and include [`input-match.css`](./input-match.css). [`input-match.js`](./input-match.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
