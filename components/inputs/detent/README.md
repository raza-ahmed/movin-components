# Detent input

A size slider with detents: the thumb drags sticky against each stop and quick between them, clicks into place with a ring at each new size, and springs onto the nearest stop when you let go.

Live preview: https://movin.design/components/inputs/detent/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-detent
```

Or copy [`input-detent.tsx`](./input-detent.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-detent.html`](./input-detent.html) where it goes and include [`input-detent.css`](./input-detent.css). [`input-detent.js`](./input-detent.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
