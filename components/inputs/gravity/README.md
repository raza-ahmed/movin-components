# Gravity input

A caption field where deleted text does not just vanish: every letter you delete drops out of the field and tumbles away with its own spin and drift, fading as it falls.

Live preview: https://movin.design/components/inputs/gravity/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-gravity
```

Or copy [`input-gravity.tsx`](./input-gravity.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-gravity.html`](./input-gravity.html) where it goes and include [`input-gravity.css`](./input-gravity.css). [`input-gravity.js`](./input-gravity.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
