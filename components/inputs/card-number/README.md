# Card number input

A card payment field: digits drop onto the card face in groups of four as you type, and the card turns over to its signature strip while you enter the security code.

Live preview: https://movin.design/components/inputs/card-number/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-card-number
```

Or copy [`input-card-number.tsx`](./input-card-number.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-card-number.html`](./input-card-number.html) where it goes and include [`input-card-number.css`](./input-card-number.css). [`input-card-number.js`](./input-card-number.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
