# Float Label input

The label lives inside the field at rest and floats above the text on focus or when a value is present. Pure CSS transitions, no dependencies.

Live preview: https://movin.design/components/inputs/float-label/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-float-label
```

Or copy [`input-float-label.tsx`](./input-float-label.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-float-label.html`](./input-float-label.html) where it goes and include [`input-float-label.css`](./input-float-label.css). It is pure CSS, so there is no script.
