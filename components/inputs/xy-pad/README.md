# XY Pad input

Two values on one pad, like a synth filter: drag the puck and it follows with a little lag, leaving a fading trail, with crosshairs through it and both values read out above.

Live preview: https://movin.design/components/inputs/xy-pad/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-xy-pad
```

Or copy [`input-xy-pad.tsx`](./input-xy-pad.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-xy-pad.html`](./input-xy-pad.html) where it goes and include [`input-xy-pad.css`](./input-xy-pad.css). [`input-xy-pad.js`](./input-xy-pad.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
