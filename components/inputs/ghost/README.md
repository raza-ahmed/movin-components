# Ghost Complete input

An email field that finishes the domain for you. Type the @ and the rest of a likely address appears in grey after your caret with a Tab key hint; Tab (or the right arrow, or tapping the hint) washes the ghost text solid and it becomes part of what you typed.

Live preview: https://movin.design/components/inputs/ghost/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-ghost.json
```

Or copy [`input-ghost.tsx`](./input-ghost.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-ghost.html`](./input-ghost.html) where it goes and include [`input-ghost.css`](./input-ghost.css). [`input-ghost.js`](./input-ghost.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
