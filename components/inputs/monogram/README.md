# Monogram input

An engraving name field: as you type your name, your initials set themselves into an interlocked monogram in the crest above, the second letter in italic, each rising out of a blur.

Live preview: https://movin.design/components/inputs/monogram/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-monogram
```

Or copy [`input-monogram.tsx`](./input-monogram.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-monogram.html`](./input-monogram.html) where it goes and include [`input-monogram.css`](./input-monogram.css). [`input-monogram.js`](./input-monogram.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
