# Combination input

A safe dial: spin it by dragging round, scrolling with the arrow keys, read the number under the marker, and enter three numbers in turn. When all three are set, the bolt slides open.

Live preview: https://movin.design/components/inputs/combination/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-combination
```

Or copy [`input-combination.tsx`](./input-combination.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-combination.html`](./input-combination.html) where it goes and include [`input-combination.css`](./input-combination.css). [`input-combination.js`](./input-combination.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
