# Telegraph input

A message field you key in Morse: tap the brass key for a dot or hold it for a dash, a lamp lights while it is down, the tape records each symbol, and pauses decode them into letters and spaces.

Live preview: https://movin.design/components/inputs/telegraph/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-telegraph
```

Or copy [`input-telegraph.tsx`](./input-telegraph.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-telegraph.html`](./input-telegraph.html) where it goes and include [`input-telegraph.css`](./input-telegraph.css). [`input-telegraph.js`](./input-telegraph.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
