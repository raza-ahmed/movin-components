# Scrub input

A number field you can drag: pull sideways on its label and a ruler slides under the value as it scrubs, Shift for steps of ten; or type, or use the arrow keys.

Live preview: https://movin.design/components/inputs/scrub/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-scrub
```

Or copy [`input-scrub.tsx`](./input-scrub.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-scrub.html`](./input-scrub.html) where it goes and include [`input-scrub.css`](./input-scrub.css). [`input-scrub.js`](./input-scrub.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
