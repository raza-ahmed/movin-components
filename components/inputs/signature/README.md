# Signature input

A signature pad with real ink: strokes thin out when you move fast and pool when you slow down, smoothed into curves. Type your name instead and it is set in a script face on the line; Clear starts over.

Live preview: https://movin.design/components/inputs/signature/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-signature
```

Or copy [`input-signature.tsx`](./input-signature.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-signature.html`](./input-signature.html) where it goes and include [`input-signature.css`](./input-signature.css). [`input-signature.js`](./input-signature.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
