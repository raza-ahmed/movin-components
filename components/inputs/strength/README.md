# Strength input

A password strength meter: a segmented bar below the input fills and brightens from dark gray to near-white as the user types, driven by character analysis.

Live preview: https://movin.design/components/inputs/strength/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-strength.json
```

Or copy [`input-strength.tsx`](./input-strength.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-strength.html`](./input-strength.html) where it goes and include [`input-strength.css`](./input-strength.css). [`input-strength.js`](./input-strength.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
