# Underline input

Minimal borderless input — a bright line draws from left to right under the field on focus. Pure CSS transform, no dependencies.

Live preview: https://movin.design/components/inputs/underline/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-underline.json
```

Or copy [`input-underline.tsx`](./input-underline.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-underline.html`](./input-underline.html) where it goes and include [`input-underline.css`](./input-underline.css). It is pure CSS, so there is no script.
