# Wave input

A caption field whose letters ride a travelling wave while it is focused; on blur the wave calms smoothly to a flat line, and new letters fade in on the swell.

Live preview: https://movin.design/components/inputs/wave/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-wave
```

Or copy [`input-wave.tsx`](./input-wave.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-wave.html`](./input-wave.html) where it goes and include [`input-wave.css`](./input-wave.css). [`input-wave.js`](./input-wave.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
