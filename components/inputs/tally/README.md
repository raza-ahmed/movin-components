# Tally input

A lap counter that keeps tally marks: tap the board and a hand-drawn stroke draws in, four uprights and then a slash across them for every five, while the count rolls up. Undo takes the last one back.

Live preview: https://movin.design/components/inputs/tally/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-tally
```

Or copy [`input-tally.tsx`](./input-tally.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-tally.html`](./input-tally.html) where it goes and include [`input-tally.css`](./input-tally.css). [`input-tally.js`](./input-tally.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
