# Measure input

A blueprint title field: your text sits on a grid between baseline and cap-height guides, and a dimension line with end ticks measures its real width in pixels, the number counting as it changes.

Live preview: https://movin.design/components/inputs/measure/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-measure
```

Or copy [`input-measure.tsx`](./input-measure.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`input-measure.html`](./input-measure.html) where it goes and include [`input-measure.css`](./input-measure.css). [`input-measure.js`](./input-measure.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
