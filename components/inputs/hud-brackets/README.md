# HUD Brackets input

Four L-shaped corner brackets animate inward on focus, locking the input in a targeting-reticle frame. Sci-fi HUD aesthetic.

Live preview: https://movin.design/components/inputs/hud-brackets/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-hud-brackets.json
```

Or copy [`input-hud-brackets.tsx`](./input-hud-brackets.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-hud-brackets.html`](./input-hud-brackets.html) where it goes and include [`input-hud-brackets.css`](./input-hud-brackets.css). It is pure CSS, so there is no script.
