# Icon Shift input

A leading icon rotates and shifts on focus with a spring overshoot, while the border glows and a box-shadow ring appears. The icon color transitions from muted to accent, giving the field a lively focused state.

Live preview: https://movin.design/components/inputs/icon-shift/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/input-icon-shift.json
```

Or copy [`input-icon-shift.tsx`](./input-icon-shift.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-icon-shift.html`](./input-icon-shift.html) where it goes and include [`input-icon-shift.css`](./input-icon-shift.css). It is pure CSS, so there is no script.
