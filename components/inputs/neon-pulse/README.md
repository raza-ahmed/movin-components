# Neon Pulse input

A neon glow box-shadow breathes in and out on a looping CSS keyframe while the input is focused. Sci-fi terminal aesthetic in glowing grays.

Live preview: https://movin.design/components/inputs/neon-pulse/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/input-neon-pulse
```

Or copy [`input-neon-pulse.tsx`](./input-neon-pulse.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`input-neon-pulse.html`](./input-neon-pulse.html) where it goes and include [`input-neon-pulse.css`](./input-neon-pulse.css). It is pure CSS, so there is no script.
