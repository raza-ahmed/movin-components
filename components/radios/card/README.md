# Card radio button

A radio group where each option is a full card row with a title and subtitle. Selecting a card reveals a light left-edge accent stripe via inset box-shadow, brightens the border and background, brightens the subtitle, and springs a small dot indicator. Ideal for plan/tier selectors.

Live preview: https://movin.design/components/radios/card/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-card.json
```

Or copy [`radio-card.tsx`](./radio-card.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-card.html`](./radio-card.html) where it goes and include [`radio-card.css`](./radio-card.css). It is pure CSS, so there is no script.
