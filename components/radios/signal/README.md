# Signal radio button

On selection, three concentric arc rings broadcast outward like a radio transmission signal. Each arc scales and fades in sequence (120ms stagger), then a persistent inner glow ring settles. The radio icon vibe made literal.

Live preview: https://movin.design/components/radios/signal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-signal.json
```

Or copy [`radio-signal.tsx`](./radio-signal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-signal.html`](./radio-signal.html) where it goes and include [`radio-signal.css`](./radio-signal.css). It is pure CSS, so there is no script.
