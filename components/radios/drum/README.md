# Drum radio button

An iOS-style picker wheel built on a real radio group. The options sit round a 3D drum that turns to bring the chosen one into the lit band; spin it with the mouse wheel, drag it up and down, click an option, or use the arrow keys. The edges fade away like the curve of a real drum.

Live preview: https://movin.design/components/radios/drum/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-drum.json
```

Or copy [`radio-drum.tsx`](./radio-drum.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-drum.html`](./radio-drum.html) where it goes and include [`radio-drum.css`](./radio-drum.css). [`radio-drum.js`](./radio-drum.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
