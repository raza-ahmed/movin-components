# Delivery radio button

Shipping options with a little delivery truck on a one-week road above them. Choosing an option drives the truck to the day it would arrive (Tomorrow, 2 days, 5–7 days): its wheels spin and its body bobs while it drives, and it turns round when it has to go back.

Live preview: https://movin.design/components/radios/delivery/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-delivery.json
```

Or copy [`radio-delivery.tsx`](./radio-delivery.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-delivery.html`](./radio-delivery.html) where it goes and include [`radio-delivery.css`](./radio-delivery.css). [`radio-delivery.js`](./radio-delivery.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
