# Altitude radio button

Waypoints on a mountain: choose base, camp or summit and the climber follows the zigzag trail up or down to it, the walked trail drawing behind them, and the altitude rolls.

Live preview: https://movin.design/components/radios/altitude/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-altitude
```

Or copy [`radio-altitude.tsx`](./radio-altitude.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-altitude.html`](./radio-altitude.html) where it goes and include [`radio-altitude.css`](./radio-altitude.css). It is pure CSS, so there is no script.
