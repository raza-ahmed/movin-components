# Gravity radio button

A selection ball falls from above with a gravity arc (ease-in) and multi-bounce settling via CSS keyframes. The ball squishes on landing and leaves a faint impact shadow. Physics-inspired with no library dependencies.

Live preview: https://movin.design/components/radios/gravity/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-gravity
```

Or copy [`radio-gravity.tsx`](./radio-gravity.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-gravity.html`](./radio-gravity.html) where it goes and include [`radio-gravity.css`](./radio-gravity.css). It is pure CSS, so there is no script.
