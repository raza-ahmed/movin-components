# Blob radio button

A liquid blob indicator morphs and slides between options using Framer Motion layoutId. The blob stretches horizontally during travel, then snaps back to a round pill shape, simulating organic liquid motion between selection points.

Live preview: https://movin.design/components/radios/blob/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-blob.json
```

Or copy [`radio-blob.tsx`](./radio-blob.tsx) into your project. Dependencies: framer-motion.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-blob.html`](./radio-blob.html) where it goes and include [`radio-blob.css`](./radio-blob.css). [`radio-blob.js`](./radio-blob.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
