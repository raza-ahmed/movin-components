# Specimen radio button

A typeface picker: choose serif, sans or mono and the specimen dissolves and resolves in the new face, like a lens racking focus.

Live preview: https://movin.design/components/radios/specimen/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-specimen
```

Or copy [`radio-specimen.tsx`](./radio-specimen.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-specimen.html`](./radio-specimen.html) where it goes and include [`radio-specimen.css`](./radio-specimen.css). It is pure CSS, so there is no script.
