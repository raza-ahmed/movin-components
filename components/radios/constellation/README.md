# Constellation radio button

On selection, five star dots appear around the option with SVG connecting lines forming a mini constellation. Each star twinkles with a looping opacity animation. Feels like the option is cosmically chosen.

Live preview: https://movin.design/components/radios/constellation/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-constellation
```

Or copy [`radio-constellation.tsx`](./radio-constellation.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-constellation.html`](./radio-constellation.html) where it goes and include [`radio-constellation.css`](./radio-constellation.css). It is pure CSS, so there is no script.
