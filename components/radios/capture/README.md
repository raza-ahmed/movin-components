# Capture radio button

A camera mode picker: the shutter button morphs between photo, record and portrait, video adds a blinking record tag and portrait melts the background behind the subject.

Live preview: https://movin.design/components/radios/capture/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-capture
```

Or copy [`radio-capture.tsx`](./radio-capture.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-capture.html`](./radio-capture.html) where it goes and include [`radio-capture.css`](./radio-capture.css). It is pure CSS, so there is no script.
