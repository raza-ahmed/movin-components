# Traffic radio button

A traffic light where each lamp is an option: choose stop, wait or go and that lamp lights at once, while the old one fades out slowly like a real bulb.

Live preview: https://movin.design/components/radios/traffic/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-traffic
```

Or copy [`radio-traffic.tsx`](./radio-traffic.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-traffic.html`](./radio-traffic.html) where it goes and include [`radio-traffic.css`](./radio-traffic.css). It is pure CSS, so there is no script.
