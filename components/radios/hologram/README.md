# Hologram radio button

Selected option flickers with brightness spikes (CSS filter + translate offsets) then stabilizes into a softly glowing holographic state. Simulates a projector flickering to life, with subtle scan-line stripes overlay.

Live preview: https://movin.design/components/radios/hologram/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-hologram
```

Or copy [`radio-hologram.tsx`](./radio-hologram.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-hologram.html`](./radio-hologram.html) where it goes and include [`radio-hologram.css`](./radio-hologram.css). It is pure CSS, so there is no script.
