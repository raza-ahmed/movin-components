# Finish radio button

A paint finish picker on a sphere: matte spreads the highlight wide and soft, satin tightens it, and gloss sharpens it to a glint with a reflected window and a rim of light.

Live preview: https://movin.design/components/radios/finish/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-finish
```

Or copy [`radio-finish.tsx`](./radio-finish.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-finish.html`](./radio-finish.html) where it goes and include [`radio-finish.css`](./radio-finish.css). It is pure CSS, so there is no script.
