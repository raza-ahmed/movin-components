# Pace radio button

A pace picker: choose walk, jog or run and footprints appear along the trail, spaced further apart and coming faster at each pace.

Live preview: https://movin.design/components/radios/pace/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-pace
```

Or copy [`radio-pace.tsx`](./radio-pace.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-pace.html`](./radio-pace.html) where it goes and include [`radio-pace.css`](./radio-pace.css). It is pure CSS, so there is no script.
