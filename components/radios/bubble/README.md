# Bubble radio button

A radio group with 30px spherical indicators that transform from a flat hollow ring into a 3D gel/bubble using a radial gradient highlight at the top-left and a specular gloss spot. Selected state glows with a soft white aura and inset shine.

Live preview: https://movin.design/components/radios/bubble/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-bubble
```

Or copy [`radio-bubble.tsx`](./radio-bubble.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-bubble.html`](./radio-bubble.html) where it goes and include [`radio-bubble.css`](./radio-bubble.css). It is pure CSS, so there is no script.
