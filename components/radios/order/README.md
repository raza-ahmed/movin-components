# Order radio button

A sort control: choose name, price or rating and the rows slide into the new order with a little spring, while the column you sorted by lights.

Live preview: https://movin.design/components/radios/order/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-order
```

Or copy [`radio-order.tsx`](./radio-order.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-order.html`](./radio-order.html) where it goes and include [`radio-order.css`](./radio-order.css). It is pure CSS, so there is no script.
