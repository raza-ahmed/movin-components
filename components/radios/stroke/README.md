# Stroke radio button

A line style picker: solid, dashed and dotted are one dash pattern the browser tweens between, and the pattern runs along the line once as it changes.

Live preview: https://movin.design/components/radios/stroke/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-stroke
```

Or copy [`radio-stroke.tsx`](./radio-stroke.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-stroke.html`](./radio-stroke.html) where it goes and include [`radio-stroke.css`](./radio-stroke.css). [`radio-stroke.js`](./radio-stroke.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
