# Resolution radio button

A video quality picker: choose 240p, 720p or 4K and the picture breaks into blocks or sharpens, stepping through the resolutions in between.

Live preview: https://movin.design/components/radios/resolution/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-resolution
```

Or copy [`radio-resolution.tsx`](./radio-resolution.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-resolution.html`](./radio-resolution.html) where it goes and include [`radio-resolution.css`](./radio-resolution.css). [`radio-resolution.js`](./radio-resolution.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
