# Floor radio button

Lift buttons as a radio group: press a floor and the doors close, the car rides up or down the shaft to it, and the doors open again; the pressed button lights.

Live preview: https://movin.design/components/radios/floor/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-floor
```

Or copy [`radio-floor.tsx`](./radio-floor.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-floor.html`](./radio-floor.html) where it goes and include [`radio-floor.css`](./radio-floor.css). [`radio-floor.js`](./radio-floor.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
