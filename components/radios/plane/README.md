# Plane radio button

A destination picker with a paper plane: choose a city and the plane flies to it in an arc, banking slightly, then hovers over it with a gentle bob.

Live preview: https://movin.design/components/radios/plane/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-plane
```

Or copy [`radio-plane.tsx`](./radio-plane.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-plane.html`](./radio-plane.html) where it goes and include [`radio-plane.css`](./radio-plane.css). [`radio-plane.js`](./radio-plane.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
