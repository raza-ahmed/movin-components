# Firmness radio button

A mattress firmness picker: each pick drops a ball onto the bed, which sinks deep and settles slowly on soft, and barely gives and bounces on firm.

Live preview: https://movin.design/components/radios/firmness/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-firmness
```

Or copy [`radio-firmness.tsx`](./radio-firmness.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-firmness.html`](./radio-firmness.html) where it goes and include [`radio-firmness.css`](./radio-firmness.css). [`radio-firmness.js`](./radio-firmness.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
