# Burner radio button

A gas burner: choose low, medium or high and the knob turns while the row of flickering flames drops low or roars up, the glow under them following.

Live preview: https://movin.design/components/radios/burner/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-burner
```

Or copy [`radio-burner.tsx`](./radio-burner.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-burner.html`](./radio-burner.html) where it goes and include [`radio-burner.css`](./radio-burner.css). It is pure CSS, so there is no script.
