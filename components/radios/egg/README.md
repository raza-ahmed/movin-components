# Egg radio button

A boiled egg picker: soft swells a glossy yolk that runs over the white, jammy sets it round the edge, hard shrinks it pale and crumbly.

Live preview: https://movin.design/components/radios/egg/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-egg
```

Or copy [`radio-egg.tsx`](./radio-egg.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-egg.html`](./radio-egg.html) where it goes and include [`radio-egg.css`](./radio-egg.css). It is pure CSS, so there is no script.
