# Stamp radio button

Neo-brutalist rubber-stamp interaction: selecting an option scales it down (0.97) with a hard inset shadow, as if physically pressed into the surface. Bold black borders and high-contrast ink-black fills complete the aesthetic.

Live preview: https://movin.design/components/radios/stamp/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-stamp.json
```

Or copy [`radio-stamp.tsx`](./radio-stamp.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-stamp.html`](./radio-stamp.html) where it goes and include [`radio-stamp.css`](./radio-stamp.css). It is pure CSS, so there is no script.
