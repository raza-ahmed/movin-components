# Tide radio button

A tide picker: choose low, mid or high and the sea slowly rises or falls against the marks on the pier, with the waves running and a buoy bobbing on top.

Live preview: https://movin.design/components/radios/tide/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-tide
```

Or copy [`radio-tide.tsx`](./radio-tide.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-tide.html`](./radio-tide.html) where it goes and include [`radio-tide.css`](./radio-tide.css). It is pure CSS, so there is no script.
