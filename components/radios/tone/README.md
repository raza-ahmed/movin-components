# Tone radio button

A message tone picker: formal, casual or playful. The speech bubble changes shape, from a squared card to a rounded pill to a tilted blob, and the message rewrites itself in that voice.

Live preview: https://movin.design/components/radios/tone/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-tone
```

Or copy [`radio-tone.tsx`](./radio-tone.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-tone.html`](./radio-tone.html) where it goes and include [`radio-tone.css`](./radio-tone.css). It is pure CSS, so there is no script.
