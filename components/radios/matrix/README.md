# Matrix radio button

On selection, the label characters cycle through random glyphs (0–9, symbols) before resolving to the real character — a Matrix-style decode effect. Monospace light gray font on dark background. Each character resolves on a staggered delay.

Live preview: https://movin.design/components/radios/matrix/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-matrix.json
```

Or copy [`radio-matrix.tsx`](./radio-matrix.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-matrix.html`](./radio-matrix.html) where it goes and include [`radio-matrix.css`](./radio-matrix.css). [`radio-matrix.js`](./radio-matrix.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
