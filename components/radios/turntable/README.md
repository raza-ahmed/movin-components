# Turntable radio button

A record player speed switch: Off, 33, 45 or 78 rpm. The tone arm swings onto the record when it plays, and the record changes speed smoothly without ever jumping: three nested spinners (33, +12, +33 rpm) are paused or played, never restarted, so their speeds simply add up. Pure CSS.

Live preview: https://movin.design/components/radios/turntable/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-turntable
```

Or copy [`radio-turntable.tsx`](./radio-turntable.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-turntable.html`](./radio-turntable.html) where it goes and include [`radio-turntable.css`](./radio-turntable.css). It is pure CSS, so there is no script.
