# Hop radio button

A size picker where a ball hops tile to tile to the size you choose, one bounce for every tile it crosses, squashing as it lands on each.

Live preview: https://movin.design/components/radios/hop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-hop
```

Or copy [`radio-hop.tsx`](./radio-hop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-hop.html`](./radio-hop.html) where it goes and include [`radio-hop.css`](./radio-hop.css). [`radio-hop.js`](./radio-hop.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
