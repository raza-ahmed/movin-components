# Tuner radio button

Station presets on an old radio dial: pick one and the needle sweeps along the FM band to its frequency, the stereo lamp drops out while it travels and flickers back on as it locks.

Live preview: https://movin.design/components/radios/tuner/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-tuner
```

Or copy [`radio-tuner.tsx`](./radio-tuner.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-tuner.html`](./radio-tuner.html) where it goes and include [`radio-tuner.css`](./radio-tuner.css). [`radio-tuner.js`](./radio-tuner.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
