# Bloom radio button

A growth stage picker on a flower: from a closed bud the petals spread out to half open and then to a full flower, the outer ones last, and the centre grows and glows.

Live preview: https://movin.design/components/radios/bloom/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-bloom
```

Or copy [`radio-bloom.tsx`](./radio-bloom.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-bloom.html`](./radio-bloom.html) where it goes and include [`radio-bloom.css`](./radio-bloom.css). It is pure CSS, so there is no script.
