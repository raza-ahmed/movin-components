# Flip Card radio button

Plan cards that flip. Choosing one turns it over in 3D with a springy settle to reveal its lit back (a tick, the plan and "Selected"), while the card you had before flips back to its front. Pure CSS.

Live preview: https://movin.design/components/radios/flip-card/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-flip-card.json
```

Or copy [`radio-flip-card.tsx`](./radio-flip-card.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-flip-card.html`](./radio-flip-card.html) where it goes and include [`radio-flip-card.css`](./radio-flip-card.css). It is pure CSS, so there is no script.
