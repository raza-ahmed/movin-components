# Crop radio button

An aspect ratio picker: choose 1:1, 4:5 or 16:9 and the crop frame reshapes over the photo with a little overshoot, dimming everything that falls outside it.

Live preview: https://movin.design/components/radios/crop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-crop
```

Or copy [`radio-crop.tsx`](./radio-crop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-crop.html`](./radio-crop.html) where it goes and include [`radio-crop.css`](./radio-crop.css). It is pure CSS, so there is no script.
