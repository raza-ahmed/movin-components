# Paper radio button

A paper size picker: choose A5, A4 or A3 and the sheet grows or shrinks against dashed outlines of the other sizes, with its size in millimetres underneath.

Live preview: https://movin.design/components/radios/paper/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-paper
```

Or copy [`radio-paper.tsx`](./radio-paper.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-paper.html`](./radio-paper.html) where it goes and include [`radio-paper.css`](./radio-paper.css). It is pure CSS, so there is no script.
