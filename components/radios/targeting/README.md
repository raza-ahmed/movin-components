# Targeting radio button

Four L-shaped corner brackets animate inward and lock around the selected option like a targeting reticle. The option glows white inside the locked frame. Unselected options show retracted ghost brackets.

Live preview: https://movin.design/components/radios/targeting/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-targeting.json
```

Or copy [`radio-targeting.tsx`](./radio-targeting.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-targeting.html`](./radio-targeting.html) where it goes and include [`radio-targeting.css`](./radio-targeting.css). It is pure CSS, so there is no script.
