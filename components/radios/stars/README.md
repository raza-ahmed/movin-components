# Stars radio button

A five-star rating that is a real radio group. Hovering previews the rating in grey; choosing fills the stars up to it in a quick left-to-right cascade with a springy pop on the one you picked, and a caption says what the score means. Pure CSS with :has().

Live preview: https://movin.design/components/radios/stars/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-stars
```

Or copy [`radio-stars.tsx`](./radio-stars.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-stars.html`](./radio-stars.html) where it goes and include [`radio-stars.css`](./radio-stars.css). It is pure CSS, so there is no script.
