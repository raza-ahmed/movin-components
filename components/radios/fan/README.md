# Fan radio button

Pick a card. Four playing cards are fanned out in a hand; hovering one nudges it up, and choosing it lifts it clear of the fan, straightens it and turns it face-lit while the rest stay tucked in. Pure CSS.

Live preview: https://movin.design/components/radios/fan/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-fan.json
```

Or copy [`radio-fan.tsx`](./radio-fan.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-fan.html`](./radio-fan.html) where it goes and include [`radio-fan.css`](./radio-fan.css). It is pure CSS, so there is no script.
