# LED radio button

A horizontal radio group styled as neumorphic LED indicator buttons. Unselected state is a dark recessed circle with deep inset shadows. Selected state lights up as a glowing white LED: radial gradient from bright center to deep gray, multi-layer glow box-shadow, and a slow repeating pulse.

Live preview: https://movin.design/components/radios/led/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-led
```

Or copy [`radio-led.tsx`](./radio-led.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-led.html`](./radio-led.html) where it goes and include [`radio-led.css`](./radio-led.css). It is pure CSS, so there is no script.
