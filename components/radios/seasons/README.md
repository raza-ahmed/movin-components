# Seasons radio button

A season picker on a tree: spring buds, full summer leaves, autumn leaves drifting down, then bare branches with snow on them and snow falling.

Live preview: https://movin.design/components/radios/seasons/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-seasons
```

Or copy [`radio-seasons.tsx`](./radio-seasons.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-seasons.html`](./radio-seasons.html) where it goes and include [`radio-seasons.css`](./radio-seasons.css). It is pure CSS, so there is no script.
