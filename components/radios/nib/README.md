# Nib radio button

A nib size picker: choose fine, medium or broad and the pen signs the line again in that width, the nib riding the stroke from the first letter to the flourish.

Live preview: https://movin.design/components/radios/nib/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-nib
```

Or copy [`radio-nib.tsx`](./radio-nib.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-nib.html`](./radio-nib.html) where it goes and include [`radio-nib.css`](./radio-nib.css). [`radio-nib.js`](./radio-nib.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
