# Neural radio button

Six node dots arranged in a hexagonal halo around the radio indicator light up in ripple sequence with staggered animation-delay on selection, connected by faint SVG lines. Simulates a neural network firing pattern.

Live preview: https://movin.design/components/radios/neural/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-neural
```

Or copy [`radio-neural.tsx`](./radio-neural.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-neural.html`](./radio-neural.html) where it goes and include [`radio-neural.css`](./radio-neural.css). It is pure CSS, so there is no script.
