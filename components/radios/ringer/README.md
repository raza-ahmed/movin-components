# Ringer radio button

A ringer mode picker: silent draws a slash across the bell, vibrate shudders the phone in short bursts, ring swings the bell with sound waves rolling out.

Live preview: https://movin.design/components/radios/ringer/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-ringer
```

Or copy [`radio-ringer.tsx`](./radio-ringer.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-ringer.html`](./radio-ringer.html) where it goes and include [`radio-ringer.css`](./radio-ringer.css). It is pure CSS, so there is no script.
