# Brush radio button

A brush size picker: choose a size and the preview stroke is drawn again at the new width, with a ring for the brush tip tracing along it.

Live preview: https://movin.design/components/radios/brush/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-brush
```

Or copy [`radio-brush.tsx`](./radio-brush.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-brush.html`](./radio-brush.html) where it goes and include [`radio-brush.css`](./radio-brush.css). [`radio-brush.js`](./radio-brush.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
