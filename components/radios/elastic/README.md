# Elastic radio button

A rubber-band selection pill stretches horizontally as it springs between options via Framer Motion layoutId with high-stiffness spring physics. The distortion gives a tactile elastic band feel to the transition.

Live preview: https://movin.design/components/radios/elastic/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-elastic.json
```

Or copy [`radio-elastic.tsx`](./radio-elastic.tsx) into your project. Dependencies: framer-motion.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-elastic.html`](./radio-elastic.html) where it goes and include [`radio-elastic.css`](./radio-elastic.css). [`radio-elastic.js`](./radio-elastic.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
