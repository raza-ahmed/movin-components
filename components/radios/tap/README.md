# Tap radio button

A water flow picker: the handle turns further each step, from a drop that swells, falls and rings the water, to a thin running thread, to a full stream with splashes.

Live preview: https://movin.design/components/radios/tap/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-tap
```

Or copy [`radio-tap.tsx`](./radio-tap.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-tap.html`](./radio-tap.html) where it goes and include [`radio-tap.css`](./radio-tap.css). It is pure CSS, so there is no script.
