# Folders radio button

Three file folders stacked in a drawer, each with its tab at a different place along the top. Choosing a tab brings that folder to the front with a little lift and tips its front flap open in 3D to show the papers inside; the folder it replaces closes and drops back. Nothing rises above the bodies, so every tab stays in view. Pure CSS.

Live preview: https://movin.design/components/radios/folders/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-folders
```

Or copy [`radio-folders.tsx`](./radio-folders.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-folders.html`](./radio-folders.html) where it goes and include [`radio-folders.css`](./radio-folders.css). It is pure CSS, so there is no script.
