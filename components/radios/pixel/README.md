# Pixel radio button

8-bit retro radio: a 4×4 grid of micro-pixels fills in sequentially with staggered CSS animation-delay on selection, like a low-res screen rendering pixel-by-pixel. Each pixel pops in from scale 0 to 1.

Live preview: https://movin.design/components/radios/pixel/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-pixel
```

Or copy [`radio-pixel.tsx`](./radio-pixel.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-pixel.html`](./radio-pixel.html) where it goes and include [`radio-pixel.css`](./radio-pixel.css). It is pure CSS, so there is no script.
