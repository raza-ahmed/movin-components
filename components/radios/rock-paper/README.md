# Rock Paper Scissors radio button

Rock, paper, scissors as a radio group: pick your move and the hand shakes twice, then throws it, fingers unfolding for paper and two of them spreading for scissors.

Live preview: https://movin.design/components/radios/rock-paper/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-rock-paper
```

Or copy [`radio-rock-paper.tsx`](./radio-rock-paper.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-rock-paper.html`](./radio-rock-paper.html) where it goes and include [`radio-rock-paper.css`](./radio-rock-paper.css). [`radio-rock-paper.js`](./radio-rock-paper.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
