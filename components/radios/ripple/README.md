# Ripple radio button

Three concentric ripple rings expand outward from the radio dot center on selection, with staggered 120ms delays. The rings fade as they grow, then collapse, leaving a solid glowing ring. Water-drop tactile feedback.

Live preview: https://movin.design/components/radios/ripple/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-ripple
```

Or copy [`radio-ripple.tsx`](./radio-ripple.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-ripple.html`](./radio-ripple.html) where it goes and include [`radio-ripple.css`](./radio-ripple.css). It is pure CSS, so there is no script.
