# Daylight radio button

A time-of-day picker with a little sky. The sun rides an arc from sunrise to sunset to the option you choose while the sky brightens or dims; at night a shadow slides over it to make a crescent moon and the stars come out. Pure CSS (offset-path for the arc).

Live preview: https://movin.design/components/radios/daylight/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-daylight
```

Or copy [`radio-daylight.tsx`](./radio-daylight.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-daylight.html`](./radio-daylight.html) where it goes and include [`radio-daylight.css`](./radio-daylight.css). It is pure CSS, so there is no script.
