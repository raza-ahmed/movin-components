# Spring radio button

A radio group where selecting an option springs a gray inner dot in with overshoot, adds a soft glow ring on the outer circle, and brightens the label. Mutual exclusivity via native radio semantics.

Live preview: https://movin.design/components/radios/spring/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-spring
```

Or copy [`radio-spring.tsx`](./radio-spring.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-spring.html`](./radio-spring.html) where it goes and include [`radio-spring.css`](./radio-spring.css). It is pure CSS, so there is no script.
