# Chart radio button

A chart type picker: from bar to line, the bars shrink into points at their own tops and a line draws through them; area then fills in under it.

Live preview: https://movin.design/components/radios/chart/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-chart
```

Or copy [`radio-chart.tsx`](./radio-chart.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-chart.html`](./radio-chart.html) where it goes and include [`radio-chart.css`](./radio-chart.css). It is pure CSS, so there is no script.
