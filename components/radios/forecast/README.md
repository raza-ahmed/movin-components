# Forecast radio button

A forecast picker: sunny, cloudy or rain. A cloud rolls in over the turning sun, the sun hides behind it, rain starts to fall, and the temperature rolls to match.

Live preview: https://movin.design/components/radios/forecast/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-forecast
```

Or copy [`radio-forecast.tsx`](./radio-forecast.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-forecast.html`](./radio-forecast.html) where it goes and include [`radio-forecast.css`](./radio-forecast.css). It is pure CSS, so there is no script.
