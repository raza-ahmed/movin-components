# Gear radio button

A gear selector for P, R, N and D: the knob clicks along the gate to the gear you pick with a little overshoot, and the display rolls to the new letter.

Live preview: https://movin.design/components/radios/gear/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-gear
```

Or copy [`radio-gear.tsx`](./radio-gear.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-gear.html`](./radio-gear.html) where it goes and include [`radio-gear.css`](./radio-gear.css). It is pure CSS, so there is no script.
