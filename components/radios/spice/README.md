# Spice radio button

A heat level picker: mild, hot or fire light up one, two or three chillies in turn, heat shimmers rise above them, and at fire the chillies shake.

Live preview: https://movin.design/components/radios/spice/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-spice
```

Or copy [`radio-spice.tsx`](./radio-spice.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-spice.html`](./radio-spice.html) where it goes and include [`radio-spice.css`](./radio-spice.css). It is pure CSS, so there is no script.
