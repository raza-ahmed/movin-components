# Clay radio button

Soft clay morphing: selecting an option triggers a squish animation on the indicator dot (scaleX 1.3, scaleY 0.7 then spring back to 1,1), with a soft tonal fill and layered soft shadow. Feels like pressing a clay button.

Live preview: https://movin.design/components/radios/clay/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-clay.json
```

Or copy [`radio-clay.tsx`](./radio-clay.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-clay.html`](./radio-clay.html) where it goes and include [`radio-clay.css`](./radio-clay.css). It is pure CSS, so there is no script.
