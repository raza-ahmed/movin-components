# Lux radio button

A light level picker drawn as a pendant lamp over a table: its beam and the pool of light on the table widen and brighten with each level.

Live preview: https://movin.design/components/radios/lux/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-lux
```

Or copy [`radio-lux.tsx`](./radio-lux.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-lux.html`](./radio-lux.html) where it goes and include [`radio-lux.css`](./radio-lux.css). It is pure CSS, so there is no script.
