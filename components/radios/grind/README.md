# Grind radio button

A coffee grind picker: choose fine, medium or coarse and the crank turns, grounds pour from the chute, and the pile in the cup settles finer or coarser.

Live preview: https://movin.design/components/radios/grind/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-grind
```

Or copy [`radio-grind.tsx`](./radio-grind.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-grind.html`](./radio-grind.html) where it goes and include [`radio-grind.css`](./radio-grind.css). [`radio-grind.js`](./radio-grind.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
