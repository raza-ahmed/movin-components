# Slices radio button

A pizza slice picker: choose 4, 6 or 8 slices and the cuts swing round to their new angles, a new cut drawing in when one is needed.

Live preview: https://movin.design/components/radios/slices/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-slices
```

Or copy [`radio-slices.tsx`](./radio-slices.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-slices.html`](./radio-slices.html) where it goes and include [`radio-slices.css`](./radio-slices.css). It is pure CSS, so there is no script.
