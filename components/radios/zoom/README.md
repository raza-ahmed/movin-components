# Zoom radio button

Focal lengths through a viewfinder: choose 24, 50 or 85 mm and the scene zooms in or out on the tree with a moment of focus breathing.

Live preview: https://movin.design/components/radios/zoom/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-zoom
```

Or copy [`radio-zoom.tsx`](./radio-zoom.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-zoom.html`](./radio-zoom.html) where it goes and include [`radio-zoom.css`](./radio-zoom.css). [`radio-zoom.js`](./radio-zoom.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
