# Tickets radio button

A ticket quantity picker: choose one to four and the tickets fan out from the stack, one more for each step, or fold back in.

Live preview: https://movin.design/components/radios/tickets/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-tickets
```

Or copy [`radio-tickets.tsx`](./radio-tickets.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-tickets.html`](./radio-tickets.html) where it goes and include [`radio-tickets.css`](./radio-tickets.css). It is pure CSS, so there is no script.
