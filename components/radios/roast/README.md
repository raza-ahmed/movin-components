# Roast radio button

A roast picker: choose light, medium or dark and the beans swell, oil comes up as a sheen and they crack once, twice or three times.

Live preview: https://movin.design/components/radios/roast/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-roast
```

Or copy [`radio-roast.tsx`](./radio-roast.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-roast.html`](./radio-roast.html) where it goes and include [`radio-roast.css`](./radio-roast.css). [`radio-roast.js`](./radio-roast.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
