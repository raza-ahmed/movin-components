# Layers radio button

Map layers in a 3D stack: choose map, satellite or terrain and that layer rises to the top of the stack and lights, while the others settle beneath it.

Live preview: https://movin.design/components/radios/layers/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-layers
```

Or copy [`radio-layers.tsx`](./radio-layers.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-layers.html`](./radio-layers.html) where it goes and include [`radio-layers.css`](./radio-layers.css). It is pure CSS, so there is no script.
