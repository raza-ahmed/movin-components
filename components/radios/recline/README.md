# Recline radio button

Cabin class as a seat: pick economy, premium or business and the seat reclines further for each, its legrest rising to match.

Live preview: https://movin.design/components/radios/recline/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-recline
```

Or copy [`radio-recline.tsx`](./radio-recline.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-recline.html`](./radio-recline.html) where it goes and include [`radio-recline.css`](./radio-recline.css). It is pure CSS, so there is no script.
