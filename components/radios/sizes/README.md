# Sizes radio button

A size picker that shows the size. Above the S, M, L, XL pills, a T-shirt springs bigger or smaller to match the one you choose, and the chest measurement under it updates. Pure CSS with :has().

Live preview: https://movin.design/components/radios/sizes/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-sizes.json
```

Or copy [`radio-sizes.tsx`](./radio-sizes.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-sizes.html`](./radio-sizes.html) where it goes and include [`radio-sizes.css`](./radio-sizes.css). It is pure CSS, so there is no script.
