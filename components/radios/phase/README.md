# Phase radio button

A moon phase picker: choose new, crescent, gibbous or full and the shadow slides across the cratered moon while its glow grows towards full.

Live preview: https://movin.design/components/radios/phase/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-phase
```

Or copy [`radio-phase.tsx`](./radio-phase.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-phase.html`](./radio-phase.html) where it goes and include [`radio-phase.css`](./radio-phase.css). It is pure CSS, so there is no script.
