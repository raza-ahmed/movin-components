# Align radio button

Text alignment buttons above a paragraph of placeholder lines. Choosing left, centre or right slides every line across to its new edge one after another; justify stretches all but the last line to the full width. Pure CSS: each line knows its own width, and one --k (0, 0.5, 1) says how far across it goes.

Live preview: https://movin.design/components/radios/align/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-align
```

Or copy [`radio-align.tsx`](./radio-align.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-align.html`](./radio-align.html) where it goes and include [`radio-align.css`](./radio-align.css). It is pure CSS, so there is no script.
