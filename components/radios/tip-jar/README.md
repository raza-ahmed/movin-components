# Tip Jar radio button

A tip picker with a jar. Choosing 10, 15, 20 or 25% drops that many coins into the jar one after another, each tumbling in and landing on the pile with a little bounce; picking less sends the extras back up out of the top. The amount updates underneath. Pure CSS.

Live preview: https://movin.design/components/radios/tip-jar/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-tip-jar.json
```

Or copy [`radio-tip-jar.tsx`](./radio-tip-jar.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-tip-jar.html`](./radio-tip-jar.html) where it goes and include [`radio-tip-jar.css`](./radio-tip-jar.css). It is pure CSS, so there is no script.
