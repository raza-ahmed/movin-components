# Pillow radio button

Neumorphic soft UI: unselected options have raised outer shadows creating a pillowed surface. Selecting presses it inward with dual inset shadows (dark and light), simulating a physical depression on a soft matte charcoal surface.

Live preview: https://movin.design/components/radios/pillow/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-pillow
```

Or copy [`radio-pillow.tsx`](./radio-pillow.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-pillow.html`](./radio-pillow.html) where it goes and include [`radio-pillow.css`](./radio-pillow.css). It is pure CSS, so there is no script.
