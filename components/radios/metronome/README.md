# Metronome radio button

A tempo picker on a metronome: choose largo, andante or presto and the weight slides along the arm while it swings at the new speed, with a light on every beat.

Live preview: https://movin.design/components/radios/metronome/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-metronome
```

Or copy [`radio-metronome.tsx`](./radio-metronome.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-metronome.html`](./radio-metronome.html) where it goes and include [`radio-metronome.css`](./radio-metronome.css). It is pure CSS, so there is no script.
