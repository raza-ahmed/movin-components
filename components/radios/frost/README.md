# Frost radio button

A frosted glass pill slides between options using Framer Motion layoutId. The translucent backdrop-blur pill springs smoothly from one option to the next, giving a glassmorphism selection indicator.

Live preview: https://movin.design/components/radios/frost/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-frost.json
```

Or copy [`radio-frost.tsx`](./radio-frost.tsx) into your project. Dependencies: framer-motion.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-frost.html`](./radio-frost.html) where it goes and include [`radio-frost.css`](./radio-frost.css). [`radio-frost.js`](./radio-frost.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
