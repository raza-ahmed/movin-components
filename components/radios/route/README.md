# Route radio button

A destination picker on a railway line: choose a station and the train pulls along the track to it, accelerating and braking in; the platform lamp and its name light as it arrives.

Live preview: https://movin.design/components/radios/route/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-route
```

Or copy [`radio-route.tsx`](./radio-route.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-route.html`](./radio-route.html) where it goes and include [`radio-route.css`](./radio-route.css). It is pure CSS, so there is no script.
