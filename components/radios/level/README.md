# Level radio button

Audio balance as a spirit level: choose left, centre or right and the level tilts, while the bubble drifts to the high side, overshoots a little and settles like it is floating in liquid.

Live preview: https://movin.design/components/radios/level/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-level
```

Or copy [`radio-level.tsx`](./radio-level.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-level.html`](./radio-level.html) where it goes and include [`radio-level.css`](./radio-level.css). It is pure CSS, so there is no script.
