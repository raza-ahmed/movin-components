# Scan Line radio button

A white horizontal scan line sweeps left-to-right across the selected option on every selection change, then fades out leaving a glowing underline. Sci-fi terminal aesthetic with monospace labels.

Live preview: https://movin.design/components/radios/scan-line/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-scan-line.json
```

Or copy [`radio-scan-line.tsx`](./radio-scan-line.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-scan-line.html`](./radio-scan-line.html) where it goes and include [`radio-scan-line.css`](./radio-scan-line.css). It is pure CSS, so there is no script.
