# Ink Drop radio button

An ink blot spreads from the center of the selected radio dot — scaling from 0 to 1 with a dramatic ease-out cubic-bezier and slight overshoot. The ink bleeds into a rich dark fill with a subtle paper-like texture vibe.

Live preview: https://movin.design/components/radios/ink-drop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-ink-drop
```

Or copy [`radio-ink-drop.tsx`](./radio-ink-drop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-ink-drop.html`](./radio-ink-drop.html) where it goes and include [`radio-ink-drop.css`](./radio-ink-drop.css). It is pure CSS, so there is no script.
