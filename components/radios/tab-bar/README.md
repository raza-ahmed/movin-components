# Tab Bar radio button

A bottom navigation bar as a radio group. The chosen tab's pill widens to make room for its label, which slides out from behind the icon while the icon fills in with a little bounce; the previous tab folds back to just its outline icon. Pure CSS (the label width animates through grid 0fr to 1fr).

Live preview: https://movin.design/components/radios/tab-bar/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-tab-bar
```

Or copy [`radio-tab-bar.tsx`](./radio-tab-bar.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-tab-bar.html`](./radio-tab-bar.html) where it goes and include [`radio-tab-bar.css`](./radio-tab-bar.css). It is pure CSS, so there is no script.
