# Offset Block radio button

Neo-brutalist hard offset shadow: unselected options sit with a (4px, 4px) black drop-shadow offset; on selection the shadow collapses to (0,0) with a snappy transition, as if the block was pushed flush into the wall.

Live preview: https://movin.design/components/radios/offset-block/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-offset-block
```

Or copy [`radio-offset-block.tsx`](./radio-offset-block.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-offset-block.html`](./radio-offset-block.html) where it goes and include [`radio-offset-block.css`](./radio-offset-block.css). It is pure CSS, so there is no script.
