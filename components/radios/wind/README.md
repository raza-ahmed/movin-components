# Wind radio button

A wind picker on a windsock: calm leaves it hanging limp, a breeze lifts it halfway and a gale flies it straight out, fluttering faster as the wind grows while the grass leans.

Live preview: https://movin.design/components/radios/wind/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-wind
```

Or copy [`radio-wind.tsx`](./radio-wind.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-wind.html`](./radio-wind.html) where it goes and include [`radio-wind.css`](./radio-wind.css). It is pure CSS, so there is no script.
