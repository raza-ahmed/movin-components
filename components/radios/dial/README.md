# Dial radio button

A rotary knob like the one on a fan or an oven. The settings sit round its top arc with a tick each; choosing one (click, or the arrow keys) turns the ridged knob so its pointer swings to it with a mechanical overshoot. Real radios underneath. Pure CSS.

Live preview: https://movin.design/components/radios/dial/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-dial.json
```

Or copy [`radio-dial.tsx`](./radio-dial.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-dial.html`](./radio-dial.html) where it goes and include [`radio-dial.css`](./radio-dial.css). It is pure CSS, so there is no script.
