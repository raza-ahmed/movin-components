# Mood radio button

How was it? Five faces from a deep frown to a big grin. The chosen face springs up larger, fills in light with its features turning dark, and its mouth gives a little bounce while its name rises in underneath; the others stay small and dim. Pure CSS.

Live preview: https://movin.design/components/radios/mood/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-mood.json
```

Or copy [`radio-mood.tsx`](./radio-mood.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-mood.html`](./radio-mood.html) where it goes and include [`radio-mood.css`](./radio-mood.css). It is pure CSS, so there is no script.
