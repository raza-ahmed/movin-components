# Prism radio button

On selection, a metallic gradient sweeps left-to-right across the selected label via CSS background-position animation, then settles into a bright chrome finish. Other options show dim monochrome text.

Live preview: https://movin.design/components/radios/prism/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/radio-prism.json
```

Or copy [`radio-prism.tsx`](./radio-prism.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-prism.html`](./radio-prism.html) where it goes and include [`radio-prism.css`](./radio-prism.css). It is pure CSS, so there is no script.
