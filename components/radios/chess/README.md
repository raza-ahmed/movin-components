# Chess radio button

A pawn promotion picker: choose queen, rook, bishop or knight and the piece drops onto the square with a flash.

Live preview: https://movin.design/components/radios/chess/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-chess
```

Or copy [`radio-chess.tsx`](./radio-chess.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`radio-chess.html`](./radio-chess.html) where it goes and include [`radio-chess.css`](./radio-chess.css). [`radio-chess.js`](./radio-chess.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
