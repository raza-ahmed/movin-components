# Focal radio button

A lens picker drawn from above: as the focal length goes up from 24 to 85 mm the field of view narrows from the camera, leaving fewer of the subjects inside it.

Live preview: https://movin.design/components/radios/focal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-focal
```

Or copy [`radio-focal.tsx`](./radio-focal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-focal.html`](./radio-focal.html) where it goes and include [`radio-focal.css`](./radio-focal.css). It is pure CSS, so there is no script.
