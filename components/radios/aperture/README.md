# Aperture radio button

An aperture picker: choose f/1.8, f/4 or f/11 and six iris blades turn in or out over the light, leaving a wide or a tiny hexagonal opening.

Live preview: https://movin.design/components/radios/aperture/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-aperture
```

Or copy [`radio-aperture.tsx`](./radio-aperture.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-aperture.html`](./radio-aperture.html) where it goes and include [`radio-aperture.css`](./radio-aperture.css). It is pure CSS, so there is no script.
