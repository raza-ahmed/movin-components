# Neon Trace radio button

An SVG rectangle border traces around the selected option using stroke-dashoffset animation, drawing a neon white circuit-board outline from the top-left corner around the full perimeter. The glow persists after tracing.

Live preview: https://movin.design/components/radios/neon-trace/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-neon-trace
```

Or copy [`radio-neon-trace.tsx`](./radio-neon-trace.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-neon-trace.html`](./radio-neon-trace.html) where it goes and include [`radio-neon-trace.css`](./radio-neon-trace.css). It is pure CSS, so there is no script.
