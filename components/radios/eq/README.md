# EQ radio button

A sound picker drawn as an equaliser: choose warm, flat or bright and the curve and its fill bend smoothly into the new shape across the frequencies.

Live preview: https://movin.design/components/radios/eq/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-eq
```

Or copy [`radio-eq.tsx`](./radio-eq.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-eq.html`](./radio-eq.html) where it goes and include [`radio-eq.css`](./radio-eq.css). It is pure CSS, so there is no script.
