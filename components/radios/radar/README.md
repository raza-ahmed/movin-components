# Radar radio button

A sci-fi radio group where selecting an option fires two concentric white rings outward in a looping radar-ping animation. The indicator core glows with a radial gradient and a center dot springs in. Monospace labels shift from dim to bright white.

Live preview: https://movin.design/components/radios/radar/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-radar
```

Or copy [`radio-radar.tsx`](./radio-radar.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-radar.html`](./radio-radar.html) where it goes and include [`radio-radar.css`](./radio-radar.css). It is pure CSS, so there is no script.
