# Elevation radio button

An elevation picker: the card lifts on a spring while its shadow drops further, spreads and softens, from flat on the page to floating.

Live preview: https://movin.design/components/radios/elevation/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-elevation
```

Or copy [`radio-elevation.tsx`](./radio-elevation.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-elevation.html`](./radio-elevation.html) where it goes and include [`radio-elevation.css`](./radio-elevation.css). It is pure CSS, so there is no script.
