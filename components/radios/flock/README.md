# Flock radio button

A formation picker: seven flapping birds fly into a line, a V or a ring, one after another.

Live preview: https://movin.design/components/radios/flock/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-flock
```

Or copy [`radio-flock.tsx`](./radio-flock.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-flock.html`](./radio-flock.html) where it goes and include [`radio-flock.css`](./radio-flock.css). It is pure CSS, so there is no script.
