# XP Bar radio button

Gaming-style XP progress bar fills left-to-right on selection with a gradient bar and particle burst effect. Selecting an option "awards XP" — the bar charges from 0% to 100% and confetti sparks pop at the fill edge.

Live preview: https://movin.design/components/radios/xp-bar/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/radio-xp-bar
```

Or copy [`radio-xp-bar.tsx`](./radio-xp-bar.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`radio-xp-bar.html`](./radio-xp-bar.html) where it goes and include [`radio-xp-bar.css`](./radio-xp-bar.css). It is pure CSS, so there is no script.
