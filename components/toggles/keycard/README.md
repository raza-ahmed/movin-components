# Keycard toggle

A hotel key-slot switch: on, the card slides down into the reader, the signal bars fill one by one and the light turns on. Off, it pops back up at an angle.

Live preview: https://movin.design/components/toggles/keycard/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-keycard
```

Or copy [`toggle-keycard.tsx`](./toggle-keycard.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-keycard.html`](./toggle-keycard.html) where it goes and include [`toggle-keycard.css`](./toggle-keycard.css). It is pure CSS, so there is no script.
