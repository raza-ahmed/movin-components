# Aperture toggle

A camera iris. Six overlapping blades swivel outward together to open a hexagon onto the lens glass, and swivel back to shut it. Pure CSS on a native switch: each blade is one rotated, translated plane.

Live preview: https://movin.design/components/toggles/aperture/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-aperture.json
```

Or copy [`toggle-aperture.tsx`](./toggle-aperture.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-aperture.html`](./toggle-aperture.html) where it goes and include [`toggle-aperture.css`](./toggle-aperture.css). It is pure CSS, so there is no script.
