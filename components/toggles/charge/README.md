# Charge toggle

A fast-charge switch shaped like a battery: the cells fill one by one, a bolt drops in, and the last cell keeps pulsing as if still charging. Off, they drain from the right.

Live preview: https://movin.design/components/toggles/charge/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-charge
```

Or copy [`toggle-charge.tsx`](./toggle-charge.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-charge.html`](./toggle-charge.html) where it goes and include [`toggle-charge.css`](./toggle-charge.css). It is pure CSS, so there is no script.
