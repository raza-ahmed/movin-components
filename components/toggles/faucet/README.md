# Faucet toggle

A tap. Switching on lifts the lever and water pours from the spout, the stream running down into rippling rings on the basin; off drops the lever and the last of the stream falls away from the spout. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/faucet/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-faucet.json
```

Or copy [`toggle-faucet.tsx`](./toggle-faucet.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-faucet.html`](./toggle-faucet.html) where it goes and include [`toggle-faucet.css`](./toggle-faucet.css). It is pure CSS, so there is no script.
