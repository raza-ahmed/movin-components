# Blinds toggle

A window with venetian blinds. Switching on tilts the slats open one after another from the top, letting daylight through in stripes that also fall across the sill below; off tilts them shut again. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/blinds/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-blinds
```

Or copy [`toggle-blinds.tsx`](./toggle-blinds.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-blinds.html`](./toggle-blinds.html) where it goes and include [`toggle-blinds.css`](./toggle-blinds.css). It is pure CSS, so there is no script.
