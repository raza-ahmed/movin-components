# Beam toggle

A metal hilt as a switch. Switching on shoots a blade of white light out of the emitter with a soft halo that hums (a faint flicker) while it is lit, and the button on the hilt glows; switching off draws the blade back in, faster than it came out. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/beam/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-beam
```

Or copy [`toggle-beam.tsx`](./toggle-beam.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-beam.html`](./toggle-beam.html) where it goes and include [`toggle-beam.css`](./toggle-beam.css). It is pure CSS, so there is no script.
