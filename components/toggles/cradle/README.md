# Cradle toggle

A Newton's cradle switch: the raised ball at one end drops and strikes the row, and the impact lifts the ball at the far end, which stays up. Switching back runs it the other way.

Live preview: https://movin.design/components/toggles/cradle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-cradle
```

Or copy [`toggle-cradle.tsx`](./toggle-cradle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-cradle.html`](./toggle-cradle.html) where it goes and include [`toggle-cradle.css`](./toggle-cradle.css). It is pure CSS, so there is no script.
