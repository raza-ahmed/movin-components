# Airplane toggle

Airplane mode where the thumb is the plane. Switching on, it races down the track, noses up to climb and leaves a dashed contrail behind it; switching off, it levels out and taxis back as the contrail fades. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/airplane/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-airplane
```

Or copy [`toggle-airplane.tsx`](./toggle-airplane.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-airplane.html`](./toggle-airplane.html) where it goes and include [`toggle-airplane.css`](./toggle-airplane.css). It is pure CSS, so there is no script.
