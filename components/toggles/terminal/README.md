# Terminal toggle

A Wi-Fi switch as a tiny console: each change types the command in at a terminal pace and then prints the result, with a blinking cursor.

Live preview: https://movin.design/components/toggles/terminal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-terminal
```

Or copy [`toggle-terminal.tsx`](./toggle-terminal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-terminal.html`](./toggle-terminal.html) where it goes and include [`toggle-terminal.css`](./toggle-terminal.css). [`toggle-terminal.js`](./toggle-terminal.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
