# Eye toggle

A visibility switch you can read at a glance. Off, the eye is shut with its lashes down; on, the lids part, the eye glances left and right, then settles and blinks now and then while it stays open. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/eye/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-eye.json
```

Or copy [`toggle-eye.tsx`](./toggle-eye.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-eye.html`](./toggle-eye.html) where it goes and include [`toggle-eye.css`](./toggle-eye.css). It is pure CSS, so there is no script.
