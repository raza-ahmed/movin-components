# Slingshot toggle

A fling switch on an elastic band: pull the thumb back against the band and let go, and it fires across to the other side and wobbles to rest. A plain click flicks it over too.

Live preview: https://movin.design/components/toggles/slingshot/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-slingshot
```

Or copy [`toggle-slingshot.tsx`](./toggle-slingshot.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-slingshot.html`](./toggle-slingshot.html) where it goes and include [`toggle-slingshot.css`](./toggle-slingshot.css). [`toggle-slingshot.js`](./toggle-slingshot.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
