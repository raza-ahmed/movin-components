# Circuit toggle

A circuit switch: a chip slides into place on a small board, current runs along the traces from it, and the LEDs at the end light up.

Live preview: https://movin.design/components/toggles/circuit/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-circuit
```

Or copy [`toggle-circuit.tsx`](./toggle-circuit.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-circuit.html`](./toggle-circuit.html) where it goes and include [`toggle-circuit.css`](./toggle-circuit.css). It is pure CSS, so there is no script.
