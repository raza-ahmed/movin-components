# Ignition toggle

An engine switch: turn the key in the ignition barrel and the dash lights sweep round it in sequence. Off, the key springs back and the lights go dark.

Live preview: https://movin.design/components/toggles/ignition/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-ignition
```

Or copy [`toggle-ignition.tsx`](./toggle-ignition.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-ignition.html`](./toggle-ignition.html) where it goes and include [`toggle-ignition.css`](./toggle-ignition.css). It is pure CSS, so there is no script.
