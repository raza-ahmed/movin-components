# Icon toggle

A dark-mode toggle pill with a sun/moon icon swap. The track shifts from a deep charcoal gradient to a light gray gradient. The knob slides with spring and crossfades between a moon (off) and a sun with rays (on). Each icon counter-rotates 90° as it enters/exits.

Live preview: https://movin.design/components/toggles/icon/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-icon
```

Or copy [`toggle-icon.tsx`](./toggle-icon.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-icon.html`](./toggle-icon.html) where it goes and include [`toggle-icon.css`](./toggle-icon.css). [`toggle-icon.js`](./toggle-icon.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
