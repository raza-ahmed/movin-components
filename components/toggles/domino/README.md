# Domino toggle

A chain-reaction switch: the dominoes topple one after another, faster as the chain goes, and the last one rings the bell. Off, they stand back up in reverse, like a rewind.

Live preview: https://movin.design/components/toggles/domino/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-domino
```

Or copy [`toggle-domino.tsx`](./toggle-domino.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-domino.html`](./toggle-domino.html) where it goes and include [`toggle-domino.css`](./toggle-domino.css). It is pure CSS, so there is no script.
