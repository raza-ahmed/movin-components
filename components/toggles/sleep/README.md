# Sleep toggle

Do not disturb. Off, the thumb holds a bell; switching on slides it across as the bell swings away and a moon turns in to replace it, the track goes night-dark with two stars, and little z's keep drifting up off the moon while it is on. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/sleep/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-sleep.json
```

Or copy [`toggle-sleep.tsx`](./toggle-sleep.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-sleep.html`](./toggle-sleep.html) where it goes and include [`toggle-sleep.css`](./toggle-sleep.css). It is pure CSS, so there is no script.
