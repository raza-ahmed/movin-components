# Pinball toggle

A launch switch like a pinball lane: the plunger compresses and fires, the ball rattles off the end and drops into the hole, which lights up. Off, the ball rolls back.

Live preview: https://movin.design/components/toggles/pinball/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-pinball
```

Or copy [`toggle-pinball.tsx`](./toggle-pinball.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-pinball.html`](./toggle-pinball.html) where it goes and include [`toggle-pinball.css`](./toggle-pinball.css). [`toggle-pinball.js`](./toggle-pinball.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
