# Magnet toggle

A magnetic lock switch: on, field lines flow round the magnet and the steel ball accelerates into it and hums against the poles; off, it is pushed away and coasts back.

Live preview: https://movin.design/components/toggles/magnet/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-magnet
```

Or copy [`toggle-magnet.tsx`](./toggle-magnet.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-magnet.html`](./toggle-magnet.html) where it goes and include [`toggle-magnet.css`](./toggle-magnet.css). It is pure CSS, so there is no script.
