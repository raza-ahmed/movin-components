# Hyperdrive toggle

A warp switch on a starfield track: switching on, the ship jumps across and every star stretches into a hyperspace streak racing past; off, the stars settle back to dots.

Live preview: https://movin.design/components/toggles/hyperdrive/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-hyperdrive
```

Or copy [`toggle-hyperdrive.tsx`](./toggle-hyperdrive.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-hyperdrive.html`](./toggle-hyperdrive.html) where it goes and include [`toggle-hyperdrive.css`](./toggle-hyperdrive.css). It is pure CSS, so there is no script.
