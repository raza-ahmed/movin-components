# Lid toggle

A wake switch drawn as a laptop: the lid swings up from shut on its hinge and the screen glows awake, then a few lines of interface fade in.

Live preview: https://movin.design/components/toggles/lid/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-lid
```

Or copy [`toggle-lid.tsx`](./toggle-lid.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-lid.html`](./toggle-lid.html) where it goes and include [`toggle-lid.css`](./toggle-lid.css). It is pure CSS, so there is no script.
