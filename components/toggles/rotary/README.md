# Rotary toggle

A knurled knob that turns a quarter turn between OFF and ON and snaps into its detent with a little overshoot, while an arc around it fills from one mark to the other. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/rotary/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-rotary.json
```

Or copy [`toggle-rotary.tsx`](./toggle-rotary.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-rotary.html`](./toggle-rotary.html) where it goes and include [`toggle-rotary.css`](./toggle-rotary.css). It is pure CSS, so there is no script.
