# Squish toggle

The thumb stretches horizontally as it slides, peaking at 1.5× width mid-travel before snapping back to a circle at the destination.

Live preview: https://movin.design/components/toggles/squish/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-squish.json
```

Or copy [`toggle-squish.tsx`](./toggle-squish.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-squish.html`](./toggle-squish.html) where it goes and include [`toggle-squish.css`](./toggle-squish.css). [`toggle-squish.js`](./toggle-squish.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
