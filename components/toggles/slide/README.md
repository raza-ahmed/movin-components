# Slide toggle

Classic on/off toggle — the thumb slides with a spring overshoot and the track fades between colors. Pure CSS transitions, no dependencies.

Live preview: https://movin.design/components/toggles/slide/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-slide
```

Or copy [`toggle-slide.tsx`](./toggle-slide.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-slide.html`](./toggle-slide.html) where it goes and include [`toggle-slide.css`](./toggle-slide.css). [`toggle-slide.js`](./toggle-slide.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
