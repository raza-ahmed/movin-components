# Knife Switch toggle

A lab knife switch for main power: the blade drops from upright into the contact clips with a bounce and a spark, and the lamp on the base comes on. Off, it swings back up.

Live preview: https://movin.design/components/toggles/knife/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-knife
```

Or copy [`toggle-knife.tsx`](./toggle-knife.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-knife.html`](./toggle-knife.html) where it goes and include [`toggle-knife.css`](./toggle-knife.css). [`toggle-knife.js`](./toggle-knife.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
