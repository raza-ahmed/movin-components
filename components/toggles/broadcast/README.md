# Broadcast toggle

A go live switch drawn as a broadcast mast: switching on, the tip light blinks, rings of signal pulse out from the top and a live tag pops up.

Live preview: https://movin.design/components/toggles/broadcast/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-broadcast
```

Or copy [`toggle-broadcast.tsx`](./toggle-broadcast.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-broadcast.html`](./toggle-broadcast.html) where it goes and include [`toggle-broadcast.css`](./toggle-broadcast.css). It is pure CSS, so there is no script.
