# Swarm toggle

A night-lights switch: fireflies drift loosely around the track; switching on, they fly over and gather into a glowing ring that becomes the thumb.

Live preview: https://movin.design/components/toggles/swarm/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-swarm
```

Or copy [`toggle-swarm.tsx`](./toggle-swarm.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-swarm.html`](./toggle-swarm.html) where it goes and include [`toggle-swarm.css`](./toggle-swarm.css). It is pure CSS, so there is no script.
