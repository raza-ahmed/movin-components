# Prism toggle

A spectrum switch: a beam of light enters the prism and, when on, fans out the other side into a spread of graded tones.

Live preview: https://movin.design/components/toggles/prism/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-prism
```

Or copy [`toggle-prism.tsx`](./toggle-prism.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-prism.html`](./toggle-prism.html) where it goes and include [`toggle-prism.css`](./toggle-prism.css). It is pure CSS, so there is no script.
