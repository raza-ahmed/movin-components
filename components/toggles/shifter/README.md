# Shifter toggle

A gear stick in a gated plate. Switching on drives the knob out of P along its slot, round the corners and down into D, which lights up; off takes it back the same way. Pure CSS: the knob rides an offset-path drawn to match the groove.

Live preview: https://movin.design/components/toggles/shifter/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-shifter
```

Or copy [`toggle-shifter.tsx`](./toggle-shifter.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-shifter.html`](./toggle-shifter.html) where it goes and include [`toggle-shifter.css`](./toggle-shifter.css). It is pure CSS, so there is no script.
