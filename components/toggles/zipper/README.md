# Zipper toggle

A zip as a switch. The pull slides along the track and the teeth interlock behind it as it goes; switching off runs it back and the two rows part again. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/zipper/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-zipper
```

Or copy [`toggle-zipper.tsx`](./toggle-zipper.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-zipper.html`](./toggle-zipper.html) where it goes and include [`toggle-zipper.css`](./toggle-zipper.css). It is pure CSS, so there is no script.
