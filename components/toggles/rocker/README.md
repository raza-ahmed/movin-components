# Rocker toggle

A wall light switch. The rocker paddle tips in 3D from one end to the other with a firm snap, its shading flipping as it turns toward the light, and a small LED on the plate glows when it is on. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/rocker/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-rocker
```

Or copy [`toggle-rocker.tsx`](./toggle-rocker.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-rocker.html`](./toggle-rocker.html) where it goes and include [`toggle-rocker.css`](./toggle-rocker.css). It is pure CSS, so there is no script.
