# Sprout toggle

An eco-mode switch: the stem grows out of the seed, two leaves unfurl one after the other and a bud pops at the top. Off, it all withdraws into the soil.

Live preview: https://movin.design/components/toggles/sprout/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-sprout
```

Or copy [`toggle-sprout.tsx`](./toggle-sprout.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-sprout.html`](./toggle-sprout.html) where it goes and include [`toggle-sprout.css`](./toggle-sprout.css). It is pure CSS, so there is no script.
