# Gradient Track toggle

When active, the track background runs a drifting dark-to-light gray gradient on a loop, making the track itself feel alive. The thumb glows on active state. No dependencies.

Live preview: https://movin.design/components/toggles/gradient-track/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-gradient-track.json
```

Or copy [`toggle-gradient-track.tsx`](./toggle-gradient-track.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-gradient-track.html`](./toggle-gradient-track.html) where it goes and include [`toggle-gradient-track.css`](./toggle-gradient-track.css). [`toggle-gradient-track.js`](./toggle-gradient-track.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
