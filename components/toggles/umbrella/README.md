# Umbrella toggle

A rain cover switch: the umbrella snaps open with a springy flare, and the falling rain stops on the canopy instead of running through.

Live preview: https://movin.design/components/toggles/umbrella/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-umbrella
```

Or copy [`toggle-umbrella.tsx`](./toggle-umbrella.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-umbrella.html`](./toggle-umbrella.html) where it goes and include [`toggle-umbrella.css`](./toggle-umbrella.css). It is pure CSS, so there is no script.
