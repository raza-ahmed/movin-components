# Flag toggle

A flag for review switch: the flag runs up the pole from half-mast, unfurls and starts to wave; switching off, it slides back down limp.

Live preview: https://movin.design/components/toggles/flag/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-flag
```

Or copy [`toggle-flag.tsx`](./toggle-flag.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-flag.html`](./toggle-flag.html) where it goes and include [`toggle-flag.css`](./toggle-flag.css). It is pure CSS, so there is no script.
