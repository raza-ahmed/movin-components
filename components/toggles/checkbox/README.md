# Checkbox toggle

A square checkbox that fills with mid-gray on check. The SVG checkmark springs in with an overshoot scale: a completely different shape from pill-style toggles. No dependencies.

Live preview: https://movin.design/components/toggles/checkbox/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-checkbox
```

Or copy [`toggle-checkbox.tsx`](./toggle-checkbox.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-checkbox.html`](./toggle-checkbox.html) where it goes and include [`toggle-checkbox.css`](./toggle-checkbox.css). [`toggle-checkbox.js`](./toggle-checkbox.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
