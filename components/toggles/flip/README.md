# Flip toggle

The thumb squishes flat at mid-travel then snaps back — like a coin flipping — as it moves between positions. Bright track on active state. No dependencies.

Live preview: https://movin.design/components/toggles/flip/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-flip.json
```

Or copy [`toggle-flip.tsx`](./toggle-flip.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-flip.html`](./toggle-flip.html) where it goes and include [`toggle-flip.css`](./toggle-flip.css). [`toggle-flip.js`](./toggle-flip.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
