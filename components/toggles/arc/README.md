# Arc toggle

A high-voltage switch: off, two dim electrodes sit apart; on, a crackling arc jumps the gap and never holds still, the electrodes glow and the track lights faintly.

Live preview: https://movin.design/components/toggles/arc/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-arc
```

Or copy [`toggle-arc.tsx`](./toggle-arc.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-arc.html`](./toggle-arc.html) where it goes and include [`toggle-arc.css`](./toggle-arc.css). It is pure CSS, so there is no script.
