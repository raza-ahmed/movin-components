# Rack & Pinion toggle

A rack-and-pinion switch: the thumb is a gear that rolls along a toothed rack, turning exactly as far as it travels, and lights up when it reaches the end stop.

Live preview: https://movin.design/components/toggles/rack/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-rack
```

Or copy [`toggle-rack.tsx`](./toggle-rack.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-rack.html`](./toggle-rack.html) where it goes and include [`toggle-rack.css`](./toggle-rack.css). It is pure CSS, so there is no script.
