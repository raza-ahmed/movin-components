# Spring toggle

Framer Motion spring physics drives both the thumb position and the track color — the thumb overshoots and bounces back with genuine physical weight.

Live preview: https://movin.design/components/toggles/spring/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-spring
```

Or copy [`toggle-spring.tsx`](./toggle-spring.tsx) into your project. Dependencies: framer-motion.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-spring.html`](./toggle-spring.html) where it goes and include [`toggle-spring.css`](./toggle-spring.css). [`toggle-spring.js`](./toggle-spring.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
