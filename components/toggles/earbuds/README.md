# Earbuds toggle

A connect switch drawn as an earbuds case: the lid flips open on its hinge, both buds rise out one after the other and the status light comes on.

Live preview: https://movin.design/components/toggles/earbuds/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-earbuds
```

Or copy [`toggle-earbuds.tsx`](./toggle-earbuds.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-earbuds.html`](./toggle-earbuds.html) where it goes and include [`toggle-earbuds.css`](./toggle-earbuds.css). It is pure CSS, so there is no script.
