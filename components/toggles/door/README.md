# Door toggle

A guest access switch drawn as a door: switching on, it swings open in 3D on its hinge and light spills out from the doorway across the floor.

Live preview: https://movin.design/components/toggles/door/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-door
```

Or copy [`toggle-door.tsx`](./toggle-door.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-door.html`](./toggle-door.html) where it goes and include [`toggle-door.css`](./toggle-door.css). It is pure CSS, so there is no script.
