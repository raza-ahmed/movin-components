# Split Flap toggle

A departures board that reads OFF or ON. Switching clatters each letter through a few flaps on its own beat before it lands, top half falling and bottom half dropping into place; a letter that doesn't change stays put, as on a real board.

Live preview: https://movin.design/components/toggles/flap/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-flap.json
```

Or copy [`toggle-flap.tsx`](./toggle-flap.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-flap.html`](./toggle-flap.html) where it goes and include [`toggle-flap.css`](./toggle-flap.css). [`toggle-flap.js`](./toggle-flap.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
