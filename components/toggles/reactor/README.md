# Reactor toggle

A power switch whose thumb is a reactor core inside two gyro rings. Switching on, the thumb springs across, the rings spin up and brighten, the core glows and energy streams down the track.

Live preview: https://movin.design/components/toggles/reactor/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-reactor
```

Or copy [`toggle-reactor.tsx`](./toggle-reactor.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-reactor.html`](./toggle-reactor.html) where it goes and include [`toggle-reactor.css`](./toggle-reactor.css). It is pure CSS, so there is no script.
