# Segmented toggle

An iOS-style segmented control with two labelled options. A frosted-glass pill slides underneath the active segment — fundamentally different from a circular-thumb toggle. No dependencies.

Live preview: https://movin.design/components/toggles/segmented/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-segmented.json
```

Or copy [`toggle-segmented.tsx`](./toggle-segmented.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-segmented.html`](./toggle-segmented.html) where it goes and include [`toggle-segmented.css`](./toggle-segmented.css). [`toggle-segmented.js`](./toggle-segmented.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
