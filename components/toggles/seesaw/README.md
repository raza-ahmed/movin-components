# Seesaw toggle

The track is a seesaw on a pivot and the thumb is a ball. Switching tips the beam the other way and the ball rolls downhill to the low end, picking up speed and actually rotating as it rolls (the stripe on it turns by the distance over its radius), then settles. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/seesaw/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-seesaw
```

Or copy [`toggle-seesaw.tsx`](./toggle-seesaw.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-seesaw.html`](./toggle-seesaw.html) where it goes and include [`toggle-seesaw.css`](./toggle-seesaw.css). It is pure CSS, so there is no script.
