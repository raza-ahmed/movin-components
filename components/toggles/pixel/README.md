# Pixel toggle

An 8-bit switch. Chunky pixel corners, a square thumb with a highlight pixel, and movement that jumps in five hard steps instead of gliding, with the track filling in a checker pattern a step behind it, like a sprite on an old console. Pure CSS (steps() timing).

Live preview: https://movin.design/components/toggles/pixel/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-pixel.json
```

Or copy [`toggle-pixel.tsx`](./toggle-pixel.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-pixel.html`](./toggle-pixel.html) where it goes and include [`toggle-pixel.css`](./toggle-pixel.css). It is pure CSS, so there is no script.
