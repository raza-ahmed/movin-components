# Neumorphic toggle

A dark neumorphic toggle with a recessed track and physically-raised knob created entirely from layered box-shadows. Off: dark extruded knob on dark track. On: light knob with glow slides right, track gains a soft inner glow.

Live preview: https://movin.design/components/toggles/neumorphic/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-neumorphic.json
```

Or copy [`toggle-neumorphic.tsx`](./toggle-neumorphic.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-neumorphic.html`](./toggle-neumorphic.html) where it goes and include [`toggle-neumorphic.css`](./toggle-neumorphic.css). [`toggle-neumorphic.js`](./toggle-neumorphic.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
