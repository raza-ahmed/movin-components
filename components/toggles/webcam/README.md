# Webcam toggle

A camera switch drawn as a laptop webcam: the ridged privacy shutter slides off the lens and the camera light comes on; slide it back to cover it.

Live preview: https://movin.design/components/toggles/webcam/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-webcam
```

Or copy [`toggle-webcam.tsx`](./toggle-webcam.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-webcam.html`](./toggle-webcam.html) where it goes and include [`toggle-webcam.css`](./toggle-webcam.css). It is pure CSS, so there is no script.
