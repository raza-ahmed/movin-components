# Mute toggle

A sound switch: switching on, the sound waves spread from the speaker one after another and keep a soft pulse, and the mute slash wipes away.

Live preview: https://movin.design/components/toggles/mute/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-mute
```

Or copy [`toggle-mute.tsx`](./toggle-mute.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-mute.html`](./toggle-mute.html) where it goes and include [`toggle-mute.css`](./toggle-mute.css). It is pure CSS, so there is no script.
