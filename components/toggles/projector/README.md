# Projector toggle

A hologram switch: a scanline figure floats on a cone of light above an emitter bar. Switching, it glitches out where it stands and rematerialises at the other end, and it flickers faintly while on.

Live preview: https://movin.design/components/toggles/projector/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-projector
```

Or copy [`toggle-projector.tsx`](./toggle-projector.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-projector.html`](./toggle-projector.html) where it goes and include [`toggle-projector.css`](./toggle-projector.css). [`toggle-projector.js`](./toggle-projector.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
