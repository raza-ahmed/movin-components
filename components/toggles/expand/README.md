# Expand toggle

Instead of sliding, the thumb expands from a small circle in the corner to flood-fill the entire pill track in mid-gray. Toggling back shrinks it. No dependencies.

Live preview: https://movin.design/components/toggles/expand/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-expand
```

Or copy [`toggle-expand.tsx`](./toggle-expand.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-expand.html`](./toggle-expand.html) where it goes and include [`toggle-expand.css`](./toggle-expand.css). [`toggle-expand.js`](./toggle-expand.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
