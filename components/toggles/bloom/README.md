# Bloom toggle

A switch shaped like a flower: on, the bud opens its six petals one after another with a springy pop and the centre lights. Off, they fold back into a bud.

Live preview: https://movin.design/components/toggles/bloom/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-bloom
```

Or copy [`toggle-bloom.tsx`](./toggle-bloom.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-bloom.html`](./toggle-bloom.html) where it goes and include [`toggle-bloom.css`](./toggle-bloom.css). It is pure CSS, so there is no script.
