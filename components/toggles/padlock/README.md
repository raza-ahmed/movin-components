# Padlock toggle

A lock switch: the thumb carries a padlock whose shackle stands open while it is off. Switching on slides it across and drops the shackle shut with a little bounce and a jolt of the body; switching off pops the shackle back up. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/padlock/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-padlock
```

Or copy [`toggle-padlock.tsx`](./toggle-padlock.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-padlock.html`](./toggle-padlock.html) where it goes and include [`toggle-padlock.css`](./toggle-padlock.css). It is pure CSS, so there is no script.
