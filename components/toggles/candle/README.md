# Candle toggle

A candle as a switch. Switching on, the flame swells up off the wick with a warm glow around it and keeps flickering; switching off snuffs it, and a thin wisp of smoke curls up from the wick and fades.

Live preview: https://movin.design/components/toggles/candle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-candle
```

Or copy [`toggle-candle.tsx`](./toggle-candle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-candle.html`](./toggle-candle.html) where it goes and include [`toggle-candle.css`](./toggle-candle.css). [`toggle-candle.js`](./toggle-candle.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
