# Morse toggle

A signal switch that speaks Morse: off, the track spells OFF in dim dots and dashes; on, it keys in ON symbol by symbol and then transmits it on a loop.

Live preview: https://movin.design/components/toggles/morse/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-morse
```

Or copy [`toggle-morse.tsx`](./toggle-morse.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-morse.html`](./toggle-morse.html) where it goes and include [`toggle-morse.css`](./toggle-morse.css). It is pure CSS, so there is no script.
