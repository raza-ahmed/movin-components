# Glow toggle

Toggle that emits a soft halo glow from the track when active. Box-shadow transitions in on activation, fades out on deactivation.

Live preview: https://movin.design/components/toggles/glow/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-glow
```

Or copy [`toggle-glow.tsx`](./toggle-glow.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-glow.html`](./toggle-glow.html) where it goes and include [`toggle-glow.css`](./toggle-glow.css). [`toggle-glow.js`](./toggle-glow.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
