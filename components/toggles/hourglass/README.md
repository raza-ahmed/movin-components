# Hourglass toggle

A focus-timer switch: the hourglass flips over and the sand runs through to the other bulb in a thin stream. Switching back flips it again and the sand runs back.

Live preview: https://movin.design/components/toggles/hourglass/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-hourglass
```

Or copy [`toggle-hourglass.tsx`](./toggle-hourglass.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-hourglass.html`](./toggle-hourglass.html) where it goes and include [`toggle-hourglass.css`](./toggle-hourglass.css). [`toggle-hourglass.js`](./toggle-hourglass.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
