# Mitosis toggle

A merge switch made of goo: a cell stretches, necks and splits, and the drop that breaks away re-forms as a full cell at the other end.

Live preview: https://movin.design/components/toggles/mitosis/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-mitosis
```

Or copy [`toggle-mitosis.tsx`](./toggle-mitosis.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-mitosis.html`](./toggle-mitosis.html) where it goes and include [`toggle-mitosis.css`](./toggle-mitosis.css). It is pure CSS, so there is no script.
