# Solar toggle

A solar-charging switch: a small satellite unfolds its panels one by one on both sides, then light glints across the cells and its status light turns on.

Live preview: https://movin.design/components/toggles/solar/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-solar
```

Or copy [`toggle-solar.tsx`](./toggle-solar.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-solar.html`](./toggle-solar.html) where it goes and include [`toggle-solar.css`](./toggle-solar.css). It is pure CSS, so there is no script.
