# Caps Lock toggle

A latching keycap. Pressing it sinks the key into its well with a little overshoot and it stays half down while on, with the LED in its corner lit; pressing again pops it back up. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/caps/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-caps
```

Or copy [`toggle-caps.tsx`](./toggle-caps.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-caps.html`](./toggle-caps.html) where it goes and include [`toggle-caps.css`](./toggle-caps.css). It is pure CSS, so there is no script.
