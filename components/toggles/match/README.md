# Match toggle

A switch drawn as a match: it strikes along the box, sparks and catches into a flickering flame; switch it off and the flame goes out in a thread of smoke.

Live preview: https://movin.design/components/toggles/match/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-match
```

Or copy [`toggle-match.tsx`](./toggle-match.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-match.html`](./toggle-match.html) where it goes and include [`toggle-match.css`](./toggle-match.css). [`toggle-match.js`](./toggle-match.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
