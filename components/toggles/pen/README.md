# Pen toggle

An edit mode switch drawn as a fountain pen: switching on, the cap slides off the nib and parks behind the barrel, and the nib writes a little line of ink.

Live preview: https://movin.design/components/toggles/pen/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-pen
```

Or copy [`toggle-pen.tsx`](./toggle-pen.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-pen.html`](./toggle-pen.html) where it goes and include [`toggle-pen.css`](./toggle-pen.css). It is pure CSS, so there is no script.
