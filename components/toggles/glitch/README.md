# Glitch toggle

A glitch switch: the thumb teleports across in jerky jumps, trailed by offset ghost copies, while the scanlined track tears into displaced slices.

Live preview: https://movin.design/components/toggles/glitch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-glitch
```

Or copy [`toggle-glitch.tsx`](./toggle-glitch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-glitch.html`](./toggle-glitch.html) where it goes and include [`toggle-glitch.css`](./toggle-glitch.css). [`toggle-glitch.js`](./toggle-glitch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
