# Lighthouse toggle

A beacon switch shaped like a lighthouse: on, the lamp lights and its beam sweeps round over a moving sea.

Live preview: https://movin.design/components/toggles/lighthouse/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-lighthouse
```

Or copy [`toggle-lighthouse.tsx`](./toggle-lighthouse.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-lighthouse.html`](./toggle-lighthouse.html) where it goes and include [`toggle-lighthouse.css`](./toggle-lighthouse.css). It is pure CSS, so there is no script.
