# Eclipse toggle

A dark-mode switch as an eclipse: the moon slides over the sun, the track darkens, and the corona flares out round the covered disc and turns slowly.

Live preview: https://movin.design/components/toggles/eclipse/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-eclipse
```

Or copy [`toggle-eclipse.tsx`](./toggle-eclipse.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-eclipse.html`](./toggle-eclipse.html) where it goes and include [`toggle-eclipse.css`](./toggle-eclipse.css). It is pure CSS, so there is no script.
