# Orbit toggle

An orbit switch: the planet travels half an orbit round the star with every press, always moving forward, and the star lights up when the switch is on.

Live preview: https://movin.design/components/toggles/orbit/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-orbit
```

Or copy [`toggle-orbit.tsx`](./toggle-orbit.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-orbit.html`](./toggle-orbit.html) where it goes and include [`toggle-orbit.css`](./toggle-orbit.css). [`toggle-orbit.js`](./toggle-orbit.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
