# Neon Sign toggle

An OPEN sign as a switch. Off, the tubes are dark glass; on, the word stutters to life with a few flickers before burning steady with a glow that lights the board, and the E keeps catching now and then, like a real sign that needs a new transformer. Pure CSS on a native switch.

Live preview: https://movin.design/components/toggles/neon-sign/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-neon-sign.json
```

Or copy [`toggle-neon-sign.tsx`](./toggle-neon-sign.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-neon-sign.html`](./toggle-neon-sign.html) where it goes and include [`toggle-neon-sign.css`](./toggle-neon-sign.css). It is pure CSS, so there is no script.
