# Cassette toggle

A playback switch shaped like a cassette: on, the reels spin and tape slowly winds from one spool to the other, and the play lamp lights.

Live preview: https://movin.design/components/toggles/cassette/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-cassette
```

Or copy [`toggle-cassette.tsx`](./toggle-cassette.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-cassette.html`](./toggle-cassette.html) where it goes and include [`toggle-cassette.css`](./toggle-cassette.css). It is pure CSS, so there is no script.
