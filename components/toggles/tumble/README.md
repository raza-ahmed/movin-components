# Tumble toggle

A shuffle switch: a die tumbles over its edges to the other end of the track, lifting at each corner, and a light comes on where it lands.

Live preview: https://movin.design/components/toggles/tumble/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-tumble
```

Or copy [`toggle-tumble.tsx`](./toggle-tumble.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-tumble.html`](./toggle-tumble.html) where it goes and include [`toggle-tumble.css`](./toggle-tumble.css). [`toggle-tumble.js`](./toggle-tumble.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
