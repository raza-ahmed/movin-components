# Portal toggle

A teleport switch: the ball dives into a portal at one end of the track, vanishes, and pops out of the portal at the other end; each gate flares as it passes through.

Live preview: https://movin.design/components/toggles/portal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-portal
```

Or copy [`toggle-portal.tsx`](./toggle-portal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-portal.html`](./toggle-portal.html) where it goes and include [`toggle-portal.css`](./toggle-portal.css). [`toggle-portal.js`](./toggle-portal.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
