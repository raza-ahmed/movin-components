# Waveform toggle

A sound switch: the speaker unmutes and a flat line springs up into a running sound wave.

Live preview: https://movin.design/components/toggles/waveform/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-waveform
```

Or copy [`toggle-waveform.tsx`](./toggle-waveform.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-waveform.html`](./toggle-waveform.html) where it goes and include [`toggle-waveform.css`](./toggle-waveform.css). It is pure CSS, so there is no script.
