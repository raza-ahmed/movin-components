# Binary toggle

A debug-flag switch: a byte of zeros flips to ones bit by bit in a wave from the left, and back from the right when switched off.

Live preview: https://movin.design/components/toggles/binary/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-binary
```

Or copy [`toggle-binary.tsx`](./toggle-binary.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-binary.html`](./toggle-binary.html) where it goes and include [`toggle-binary.css`](./toggle-binary.css). It is pure CSS, so there is no script.
