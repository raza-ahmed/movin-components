# Pull Cord toggle

A hanging lamp with a pull chain. Each switch tugs the cord down and lets it spring back with a bounce, and the bulb lights (or goes out) at the bottom of the pull, throwing a soft cone of light.

Live preview: https://movin.design/components/toggles/cord/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/toggle-cord.json
```

Or copy [`toggle-cord.tsx`](./toggle-cord.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`toggle-cord.html`](./toggle-cord.html) where it goes and include [`toggle-cord.css`](./toggle-cord.css). [`toggle-cord.js`](./toggle-cord.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
