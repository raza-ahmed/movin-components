# Fuse toggle

An ignite switch: a spark burns along the fuse leaving ash behind it, and when it reaches the end the bulb pops on.

Live preview: https://movin.design/components/toggles/fuse/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-fuse
```

Or copy [`toggle-fuse.tsx`](./toggle-fuse.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-fuse.html`](./toggle-fuse.html) where it goes and include [`toggle-fuse.css`](./toggle-fuse.css). It is pure CSS, so there is no script.
