# Helix toggle

A sync switch: off, two strands lie flat and parallel; on, they twist into a turning double helix.

Live preview: https://movin.design/components/toggles/helix/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/toggle-helix
```

Or copy [`toggle-helix.tsx`](./toggle-helix.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`toggle-helix.html`](./toggle-helix.html) where it goes and include [`toggle-helix.css`](./toggle-helix.css). It is pure CSS, so there is no script.
