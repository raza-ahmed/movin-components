# Dart checkbox

A dartboard checkbox: ticking throws a dart into the bullseye, the board jolts, a ring flashes and the dart quivers before it settles; unticking pulls it out.

Live preview: https://movin.design/components/checkboxes/dart/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-dart
```

Or copy [`checkbox-dart.tsx`](./checkbox-dart.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-dart.html`](./checkbox-dart.html) where it goes and include [`checkbox-dart.css`](./checkbox-dart.css). [`checkbox-dart.js`](./checkbox-dart.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
