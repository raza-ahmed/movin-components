# Fire Fill checkbox

Animated flame gradient rises from the box bottom with a jagged flickering top edge (clip-path polygon keyframes). Light-to-dark gray fill with continuous flicker — clearly distinct from liquid (smooth, no animation while filled).

Live preview: https://movin.design/components/checkboxes/fire-fill/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-fire-fill
```

Or copy [`checkbox-fire-fill.tsx`](./checkbox-fire-fill.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-fire-fill.html`](./checkbox-fire-fill.html) where it goes and include [`checkbox-fire-fill.css`](./checkbox-fire-fill.css). It is pure CSS, so there is no script.
