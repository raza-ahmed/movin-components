# Catapult checkbox

A catapult checkbox: ticking swings the arm and flings the tick in a spinning arc into the box, which lights as it lands; unticking hops it back into the cup.

Live preview: https://movin.design/components/checkboxes/catapult/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-catapult
```

Or copy [`checkbox-catapult.tsx`](./checkbox-catapult.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-catapult.html`](./checkbox-catapult.html) where it goes and include [`checkbox-catapult.css`](./checkbox-catapult.css). [`checkbox-catapult.js`](./checkbox-catapult.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
