# Mailbox checkbox

A mailbox checkbox: ticking slides a letter in through the door and then swings the flag up with a bounce, lighting it; unticking lowers the flag again.

Live preview: https://movin.design/components/checkboxes/mailbox/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-mailbox
```

Or copy [`checkbox-mailbox.tsx`](./checkbox-mailbox.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-mailbox.html`](./checkbox-mailbox.html) where it goes and include [`checkbox-mailbox.css`](./checkbox-mailbox.css). [`checkbox-mailbox.js`](./checkbox-mailbox.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
