# Spark Trail checkbox

On check, 8 short white spark-streaks shoot outward in all directions and fade quickly, like an electric discharge. More energy-focused and rapid than confetti — pure white, no color variation.

Live preview: https://movin.design/components/checkboxes/spark-trail/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-spark-trail.json
```

Or copy [`checkbox-spark-trail.tsx`](./checkbox-spark-trail.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-spark-trail.html`](./checkbox-spark-trail.html) where it goes and include [`checkbox-spark-trail.css`](./checkbox-spark-trail.css). It is pure CSS, so there is no script.
