# Polaroid checkbox

An instant photo checkbox: ticking gives the print a shake and the picture slowly develops, from dark and blurred to a sharp tick over a little landscape.

Live preview: https://movin.design/components/checkboxes/polaroid/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-polaroid
```

Or copy [`checkbox-polaroid.tsx`](./checkbox-polaroid.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-polaroid.html`](./checkbox-polaroid.html) where it goes and include [`checkbox-polaroid.css`](./checkbox-polaroid.css). [`checkbox-polaroid.js`](./checkbox-polaroid.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
