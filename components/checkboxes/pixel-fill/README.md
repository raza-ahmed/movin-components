# Pixel Fill checkbox

A checkbox whose interior is a 4×4 grid of micro-squares that fill in one by one in a randomised stagger order on check, and clear in reverse on uncheck. Retro pixel game aesthetic.

Live preview: https://movin.design/components/checkboxes/pixel-fill/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-pixel-fill
```

Or copy [`checkbox-pixel-fill.tsx`](./checkbox-pixel-fill.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-pixel-fill.html`](./checkbox-pixel-fill.html) where it goes and include [`checkbox-pixel-fill.css`](./checkbox-pixel-fill.css). It is pure CSS, so there is no script.
