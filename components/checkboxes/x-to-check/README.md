# X to Check checkbox

Both states have visible content: unchecked shows a dim × (reject), checked shows a ✓ on a solid fill (approve). The × rotates away as the ✓ rotates in. The box shifts from faint to solid. A clear reject→approve narrative.

Live preview: https://movin.design/components/checkboxes/x-to-check/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-x-to-check
```

Or copy [`checkbox-x-to-check.tsx`](./checkbox-x-to-check.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-x-to-check.html`](./checkbox-x-to-check.html) where it goes and include [`checkbox-x-to-check.css`](./checkbox-x-to-check.css). It is pure CSS, so there is no script.
