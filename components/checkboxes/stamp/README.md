# Stamp checkbox

The check mark crashes down from above like a rubber stamp, with a blur-to-focus motion and six ink-splatter dots radiating outward on impact. Dramatic and tactile.

Live preview: https://movin.design/components/checkboxes/stamp/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-stamp
```

Or copy [`checkbox-stamp.tsx`](./checkbox-stamp.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-stamp.html`](./checkbox-stamp.html) where it goes and include [`checkbox-stamp.css`](./checkbox-stamp.css). [`checkbox-stamp.js`](./checkbox-stamp.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
