# Marble checkbox

A marble run checkbox: ticking rolls a marble down the ramp, over the edge and into the hole in the box, where it lands with a bounce and the hole glows; unticking pops it back up the ramp.

Live preview: https://movin.design/components/checkboxes/marble/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-marble
```

Or copy [`checkbox-marble.tsx`](./checkbox-marble.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-marble.html`](./checkbox-marble.html) where it goes and include [`checkbox-marble.css`](./checkbox-marble.css). [`checkbox-marble.js`](./checkbox-marble.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
