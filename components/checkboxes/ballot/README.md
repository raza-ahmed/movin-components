# Ballot checkbox

An I voted checkbox: ticking it drops the folded ballot down through the slot into the box with a little thunk; unticking lifts it back out.

Live preview: https://movin.design/components/checkboxes/ballot/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-ballot
```

Or copy [`checkbox-ballot.tsx`](./checkbox-ballot.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-ballot.html`](./checkbox-ballot.html) where it goes and include [`checkbox-ballot.css`](./checkbox-ballot.css). [`checkbox-ballot.js`](./checkbox-ballot.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
