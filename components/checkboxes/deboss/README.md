# Deboss checkbox

A letterpress checkbox: ticking brings a press plate down onto a paper square, it gives under the pressure, and the plate lifts to leave the tick pressed into the paper with a shadow and a highlight.

Live preview: https://movin.design/components/checkboxes/deboss/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-deboss
```

Or copy [`checkbox-deboss.tsx`](./checkbox-deboss.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-deboss.html`](./checkbox-deboss.html) where it goes and include [`checkbox-deboss.css`](./checkbox-deboss.css). [`checkbox-deboss.js`](./checkbox-deboss.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
