# Heartbeat checkbox

On check, a tiny SVG ECG heartbeat line draws across the box using stroke-dashoffset, then fades while the check mark reveals. Dark background with a soft white trace. Medical/vital signs aesthetic.

Live preview: https://movin.design/components/checkboxes/heartbeat/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-heartbeat
```

Or copy [`checkbox-heartbeat.tsx`](./checkbox-heartbeat.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-heartbeat.html`](./checkbox-heartbeat.html) where it goes and include [`checkbox-heartbeat.css`](./checkbox-heartbeat.css). It is pure CSS, so there is no script.
