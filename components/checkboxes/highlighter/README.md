# Highlighter checkbox

A checkbox that highlights its own label: ticking, a marker nib swipes across the text leaving a skewed band of ink, and the box fills with the same ink; unticking, the band retracts from the right.

Live preview: https://movin.design/components/checkboxes/highlighter/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-highlighter
```

Or copy [`checkbox-highlighter.tsx`](./checkbox-highlighter.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-highlighter.html`](./checkbox-highlighter.html) where it goes and include [`checkbox-highlighter.css`](./checkbox-highlighter.css). [`checkbox-highlighter.js`](./checkbox-highlighter.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
