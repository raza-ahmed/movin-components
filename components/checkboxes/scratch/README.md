# Scratch checkbox

A diagonal clip-path wipe reveals the filled checked state from the bottom-right corner, like scratching a lottery card. Unchecking collapses the fill back.

Live preview: https://movin.design/components/checkboxes/scratch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-scratch
```

Or copy [`checkbox-scratch.tsx`](./checkbox-scratch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-scratch.html`](./checkbox-scratch.html) where it goes and include [`checkbox-scratch.css`](./checkbox-scratch.css). It is pure CSS, so there is no script.
