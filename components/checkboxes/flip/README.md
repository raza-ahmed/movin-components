# Flip checkbox

A checkbox that performs a full 360° Y-axis coin flip via CSS keyframes when toggled. The fill color and stroke-dashoffset check mark transition during the rotation.

Live preview: https://movin.design/components/checkboxes/flip/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-flip
```

Or copy [`checkbox-flip.tsx`](./checkbox-flip.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-flip.html`](./checkbox-flip.html) where it goes and include [`checkbox-flip.css`](./checkbox-flip.css). It is pure CSS, so there is no script.
