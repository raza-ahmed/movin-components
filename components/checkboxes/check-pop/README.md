# Check Pop checkbox

A checkbox where the SVG checkmark springs into view with a scale overshoot (cubic-bezier spring) on check and collapses instantly on uncheck. No keyframes needed — pure CSS transition on the SVG transform.

Live preview: https://movin.design/components/checkboxes/check-pop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-check-pop.json
```

Or copy [`checkbox-check-pop.tsx`](./checkbox-check-pop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-check-pop.html`](./checkbox-check-pop.html) where it goes and include [`checkbox-check-pop.css`](./checkbox-check-pop.css). It is pure CSS, so there is no script.
