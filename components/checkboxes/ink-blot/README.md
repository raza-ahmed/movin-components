# Ink Blot checkbox

The box fill spreads via border-radius morphing through organic amoeba/blob shapes — animating through asymmetric four-corner border-radius values before settling square again. Feels like ink spreading.

Live preview: https://movin.design/components/checkboxes/ink-blot/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-ink-blot.json
```

Or copy [`checkbox-ink-blot.tsx`](./checkbox-ink-blot.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-ink-blot.html`](./checkbox-ink-blot.html) where it goes and include [`checkbox-ink-blot.css`](./checkbox-ink-blot.css). [`checkbox-ink-blot.js`](./checkbox-ink-blot.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
