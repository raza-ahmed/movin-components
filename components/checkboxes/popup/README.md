# Pop-up checkbox

A pop-up book checkbox: the tick lies folded flat on an open book in perspective, and ticking makes it spring up and stand out of the page, casting a soft shadow.

Live preview: https://movin.design/components/checkboxes/popup/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-popup
```

Or copy [`checkbox-popup.tsx`](./checkbox-popup.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-popup.html`](./checkbox-popup.html) where it goes and include [`checkbox-popup.css`](./checkbox-popup.css). It is pure CSS, so there is no script.
