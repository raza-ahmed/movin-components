# Shake Lock checkbox

The box rattles in a rapid X-axis jitter sequence as if locking in, then snaps to the checked silver fill. Unchecking plays a shorter reverse shake. Kinetic, mechanical feel.

Live preview: https://movin.design/components/checkboxes/shake-lock/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-shake-lock.json
```

Or copy [`checkbox-shake-lock.tsx`](./checkbox-shake-lock.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-shake-lock.html`](./checkbox-shake-lock.html) where it goes and include [`checkbox-shake-lock.css`](./checkbox-shake-lock.css). [`checkbox-shake-lock.js`](./checkbox-shake-lock.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
