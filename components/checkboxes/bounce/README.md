# Bounce checkbox

A checkbox that plays a spring-bounce keyframe animation on the box itself when toggled — compresses then overshoots on check, lightly expands then settles on uncheck. Fill and border color transition simultaneously.

Live preview: https://movin.design/components/checkboxes/bounce/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-bounce.json
```

Or copy [`checkbox-bounce.tsx`](./checkbox-bounce.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-bounce.html`](./checkbox-bounce.html) where it goes and include [`checkbox-bounce.css`](./checkbox-bounce.css). It is pure CSS, so there is no script.
