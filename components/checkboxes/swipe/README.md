# Swipe checkbox

A swipe-to-complete checkbox: ticking slides the task card aside to show a tick beneath, springs it back, fills its circle and strikes the text through; unticking nudges it the other way.

Live preview: https://movin.design/components/checkboxes/swipe/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-swipe
```

Or copy [`checkbox-swipe.tsx`](./checkbox-swipe.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-swipe.html`](./checkbox-swipe.html) where it goes and include [`checkbox-swipe.css`](./checkbox-swipe.css). [`checkbox-swipe.js`](./checkbox-swipe.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
