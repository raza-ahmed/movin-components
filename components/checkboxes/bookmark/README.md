# Bookmark checkbox

A bookmark icon as the checkbox. Checking pours a ribbon of fill down from its top and the whole ribbon swings on its pin a few times before it hangs still; unchecking drains it back up. Pure CSS.

Live preview: https://movin.design/components/checkboxes/bookmark/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-bookmark
```

Or copy [`checkbox-bookmark.tsx`](./checkbox-bookmark.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-bookmark.html`](./checkbox-bookmark.html) where it goes and include [`checkbox-bookmark.css`](./checkbox-bookmark.css). It is pure CSS, so there is no script.
