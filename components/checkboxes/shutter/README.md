# Shutter checkbox

The checked fill opens like a camera iris/shutter using clip-path polygon animation — panels spread outward from a collapsed line to full coverage. Sharp, mechanical feel.

Live preview: https://movin.design/components/checkboxes/shutter/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-shutter.json
```

Or copy [`checkbox-shutter.tsx`](./checkbox-shutter.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-shutter.html`](./checkbox-shutter.html) where it goes and include [`checkbox-shutter.css`](./checkbox-shutter.css). [`checkbox-shutter.js`](./checkbox-shutter.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
