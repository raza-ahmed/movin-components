# Glitch checkbox

On toggle, light and dark ghost overlays jitter in opposite X directions and a horizontal scan line sweeps through, creating a digital corruption/glitch effect before resolving to the new state.

Live preview: https://movin.design/components/checkboxes/glitch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-glitch
```

Or copy [`checkbox-glitch.tsx`](./checkbox-glitch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-glitch.html`](./checkbox-glitch.html) where it goes and include [`checkbox-glitch.css`](./checkbox-glitch.css). [`checkbox-glitch.js`](./checkbox-glitch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
