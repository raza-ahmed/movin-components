# Gravity Drop checkbox

The check mark falls from above the box with realistic gravity physics — accelerates in, overshoots slightly, bounces twice, then settles. Unchecking tosses it back upward and fades it out.

Live preview: https://movin.design/components/checkboxes/gravity-drop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-gravity-drop
```

Or copy [`checkbox-gravity-drop.tsx`](./checkbox-gravity-drop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-gravity-drop.html`](./checkbox-gravity-drop.html) where it goes and include [`checkbox-gravity-drop.css`](./checkbox-gravity-drop.css). [`checkbox-gravity-drop.js`](./checkbox-gravity-drop.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
