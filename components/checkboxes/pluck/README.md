# Pluck checkbox

A string checkbox: the tick is a string between two pins. Ticking pulls its middle down taut into a tick; unticking lets go and it twangs back and forth across the line before it settles.

Live preview: https://movin.design/components/checkboxes/pluck/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-pluck
```

Or copy [`checkbox-pluck.tsx`](./checkbox-pluck.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-pluck.html`](./checkbox-pluck.html) where it goes and include [`checkbox-pluck.css`](./checkbox-pluck.css). [`checkbox-pluck.js`](./checkbox-pluck.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
