# Raised checkbox

The checked state looks physically raised off the surface. A sphere-like radial gradient (silver → dark gray) combined with six layered box-shadows (rim highlight, outer glow, ground lift shadow, inner top shine, inner bottom depth) creates a convincing 3D embossed button. The box also lifts 1px on the Y axis. Flat and recessed when unchecked.

Live preview: https://movin.design/components/checkboxes/raised/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-raised
```

Or copy [`checkbox-raised.tsx`](./checkbox-raised.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-raised.html`](./checkbox-raised.html) where it goes and include [`checkbox-raised.css`](./checkbox-raised.css). It is pure CSS, so there is no script.
