# Stencil checkbox

A stencil checkbox: ticking, a metal plate with a tick cut out of it drops over the box, a burst of spray mist puffs, and the plate lifts away to leave a crisp painted tick with overspray round it.

Live preview: https://movin.design/components/checkboxes/stencil/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-stencil
```

Or copy [`checkbox-stencil.tsx`](./checkbox-stencil.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-stencil.html`](./checkbox-stencil.html) where it goes and include [`checkbox-stencil.css`](./checkbox-stencil.css). [`checkbox-stencil.js`](./checkbox-stencil.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
