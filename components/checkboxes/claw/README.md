# Claw checkbox

A claw machine checkbox: ticking lowers the claw into the bin, opens it and lets the tick drop; unticking sends it back down to grab the tick and lift it out again.

Live preview: https://movin.design/components/checkboxes/claw/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-claw
```

Or copy [`checkbox-claw.tsx`](./checkbox-claw.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-claw.html`](./checkbox-claw.html) where it goes and include [`checkbox-claw.css`](./checkbox-claw.css). [`checkbox-claw.js`](./checkbox-claw.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
