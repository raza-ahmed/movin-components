# Dovetail checkbox

A woodwork checkbox: the second half of a dovetail joint slides down into the first, completing the tick that runs across both, and the joint thuds as it seats.

Live preview: https://movin.design/components/checkboxes/dovetail/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-dovetail
```

Or copy [`checkbox-dovetail.tsx`](./checkbox-dovetail.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-dovetail.html`](./checkbox-dovetail.html) where it goes and include [`checkbox-dovetail.css`](./checkbox-dovetail.css). [`checkbox-dovetail.js`](./checkbox-dovetail.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
