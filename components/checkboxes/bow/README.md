# Bow checkbox

A gift wrap checkbox: ticking it, a ribbon crosses the box in two bands, the knot cinches, the loops spring out and the tails fall last.

Live preview: https://movin.design/components/checkboxes/bow/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-bow
```

Or copy [`checkbox-bow.tsx`](./checkbox-bow.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-bow.html`](./checkbox-bow.html) where it goes and include [`checkbox-bow.css`](./checkbox-bow.css). It is pure CSS, so there is no script.
