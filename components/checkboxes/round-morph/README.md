# Round Morph checkbox

The checkbox shape morphs from a rounded square (7px radius) to a perfect circle on check via animated border-radius with a spring overshoot. Clean and satisfying shape transformation.

Live preview: https://movin.design/components/checkboxes/round-morph/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-round-morph.json
```

Or copy [`checkbox-round-morph.tsx`](./checkbox-round-morph.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-round-morph.html`](./checkbox-round-morph.html) where it goes and include [`checkbox-round-morph.css`](./checkbox-round-morph.css). It is pure CSS, so there is no script.
