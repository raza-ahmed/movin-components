# Laser Draw checkbox

The check mark draws itself with a glowing white laser effect using stroke-dashoffset animation and a pulsing drop-shadow filter. Visually distinct from draw-check: hot, fiery, continuous glow.

Live preview: https://movin.design/components/checkboxes/laser-draw/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-laser-draw
```

Or copy [`checkbox-laser-draw.tsx`](./checkbox-laser-draw.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-laser-draw.html`](./checkbox-laser-draw.html) where it goes and include [`checkbox-laser-draw.css`](./checkbox-laser-draw.css). It is pure CSS, so there is no script.
