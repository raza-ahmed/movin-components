# Sticker checkbox

A favourite checkbox: ticking it slaps a star sticker down at an angle, it flattens out and settles, and a sheen sweeps across it.

Live preview: https://movin.design/components/checkboxes/sticker/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-sticker
```

Or copy [`checkbox-sticker.tsx`](./checkbox-sticker.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-sticker.html`](./checkbox-sticker.html) where it goes and include [`checkbox-sticker.css`](./checkbox-sticker.css). [`checkbox-sticker.js`](./checkbox-sticker.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
