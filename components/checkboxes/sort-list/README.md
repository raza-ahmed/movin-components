# Sorting List checkbox

A short to-do list that tidies itself. Checking a task slides it down below the open ones while the others glide up into its place, and a progress bar over the list fills and counts; unchecking floats it back up.

Live preview: https://movin.design/components/checkboxes/sort-list/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-sort-list
```

Or copy [`checkbox-sort-list.tsx`](./checkbox-sort-list.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-sort-list.html`](./checkbox-sort-list.html) where it goes and include [`checkbox-sort-list.css`](./checkbox-sort-list.css). [`checkbox-sort-list.js`](./checkbox-sort-list.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
