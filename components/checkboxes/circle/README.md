# Circle checkbox

No box: a circular ring indicator. On check, an SVG circle stroke draws around the full circumference via strokeDashoffset, then the check mark springs into the center. Completely different shape from square checkboxes.

Live preview: https://movin.design/components/checkboxes/circle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-circle
```

Or copy [`checkbox-circle.tsx`](./checkbox-circle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-circle.html`](./checkbox-circle.html) where it goes and include [`checkbox-circle.css`](./checkbox-circle.css). It is pure CSS, so there is no script.
