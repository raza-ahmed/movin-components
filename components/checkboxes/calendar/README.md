# Calendar checkbox

A tear-off calendar checkbox: ticking flips today's page up over the binding to show the day ticked off underneath; unticking flips it back down.

Live preview: https://movin.design/components/checkboxes/calendar/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-calendar
```

Or copy [`checkbox-calendar.tsx`](./checkbox-calendar.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-calendar.html`](./checkbox-calendar.html) where it goes and include [`checkbox-calendar.css`](./checkbox-calendar.css). It is pure CSS, so there is no script.
