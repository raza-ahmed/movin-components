# Smile checkbox

A little face as the checkbox. Unchecked it is a dark, straight-faced circle; checked it lights up with a bounce, the flat mouth swaps for a drawn smile and the dot eyes curve into happy arcs.

Live preview: https://movin.design/components/checkboxes/smile/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-smile.json
```

Or copy [`checkbox-smile.tsx`](./checkbox-smile.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-smile.html`](./checkbox-smile.html) where it goes and include [`checkbox-smile.css`](./checkbox-smile.css). It is pure CSS, so there is no script.
