# Gears checkbox

A gears checkbox: two meshed gears turn together, the small one the other way and faster, until the tick on the big gear stands upright and lights.

Live preview: https://movin.design/components/checkboxes/gears/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-gears
```

Or copy [`checkbox-gears.tsx`](./checkbox-gears.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-gears.html`](./checkbox-gears.html) where it goes and include [`checkbox-gears.css`](./checkbox-gears.css). It is pure CSS, so there is no script.
