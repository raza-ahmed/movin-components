# Keycap checkbox

A mechanical keyboard key. Pressing it travels down as its side wall shrinks; checked, it latches half-way down like Caps Lock and the LED on the cap glows. Pure CSS.

Live preview: https://movin.design/components/checkboxes/keycap/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-keycap
```

Or copy [`checkbox-keycap.tsx`](./checkbox-keycap.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-keycap.html`](./checkbox-keycap.html) where it goes and include [`checkbox-keycap.css`](./checkbox-keycap.css). It is pure CSS, so there is no script.
