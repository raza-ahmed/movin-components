# Dog-ear checkbox

Checking turns the box into a sheet of paper and folds its top corner down in 3D, the way you dog-ear a page you have read, showing the paper's darker underside. Pure CSS.

Live preview: https://movin.design/components/checkboxes/dog-ear/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-dog-ear
```

Or copy [`checkbox-dog-ear.tsx`](./checkbox-dog-ear.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-dog-ear.html`](./checkbox-dog-ear.html) where it goes and include [`checkbox-dog-ear.css`](./checkbox-dog-ear.css). It is pure CSS, so there is no script.
