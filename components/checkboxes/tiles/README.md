# Tiles checkbox

A puzzle checkbox: four scrambled tiles each turned a different way rotate back into place one after another, and the tick they make lights up.

Live preview: https://movin.design/components/checkboxes/tiles/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-tiles
```

Or copy [`checkbox-tiles.tsx`](./checkbox-tiles.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-tiles.html`](./checkbox-tiles.html) where it goes and include [`checkbox-tiles.css`](./checkbox-tiles.css). It is pure CSS, so there is no script.
