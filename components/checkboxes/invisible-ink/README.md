# Invisible Ink checkbox

An invisible ink checkbox: ticking sweeps a UV light across the box, showing the hidden tick only where the light shines, then the whole tick lights up and glows.

Live preview: https://movin.design/components/checkboxes/invisible-ink/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-invisible-ink
```

Or copy [`checkbox-invisible-ink.tsx`](./checkbox-invisible-ink.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-invisible-ink.html`](./checkbox-invisible-ink.html) where it goes and include [`checkbox-invisible-ink.css`](./checkbox-invisible-ink.css). [`checkbox-invisible-ink.js`](./checkbox-invisible-ink.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
