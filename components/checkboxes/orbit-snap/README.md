# Orbit Snap checkbox

A glowing white dot orbits the checkbox perimeter for ~700ms on check, then vanishes and the check mark snaps in. Unchecking instantly removes the check. Gives a satisfying "loading then locking" sequence.

Live preview: https://movin.design/components/checkboxes/orbit-snap/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-orbit-snap.json
```

Or copy [`checkbox-orbit-snap.tsx`](./checkbox-orbit-snap.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-orbit-snap.html`](./checkbox-orbit-snap.html) where it goes and include [`checkbox-orbit-snap.css`](./checkbox-orbit-snap.css). It is pure CSS, so there is no script.
