# Receipt checkbox

A receipt checkbox: ticking prints a receipt out of the slot line by line, ending in a tick, and the printer light comes on; unticking pulls it back in.

Live preview: https://movin.design/components/checkboxes/receipt/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-receipt
```

Or copy [`checkbox-receipt.tsx`](./checkbox-receipt.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-receipt.html`](./checkbox-receipt.html) where it goes and include [`checkbox-receipt.css`](./checkbox-receipt.css). It is pure CSS, so there is no script.
