# Sync checkbox

A sync checkbox: ticking spins the two sync arrows round and fades them into a ring that draws closed with a tick inside; unticking brings the arrows back.

Live preview: https://movin.design/components/checkboxes/sync/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-sync
```

Or copy [`checkbox-sync.tsx`](./checkbox-sync.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-sync.html`](./checkbox-sync.html) where it goes and include [`checkbox-sync.css`](./checkbox-sync.css). [`checkbox-sync.js`](./checkbox-sync.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
