# Select All checkbox

A parent checkbox over a branch of children. Checking the parent cascades down the branch one child after another; checking only some children turns the parent into an animated half-state dash that becomes a tick when the last one is done.

Live preview: https://movin.design/components/checkboxes/select-all/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-select-all.json
```

Or copy [`checkbox-select-all.tsx`](./checkbox-select-all.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-select-all.html`](./checkbox-select-all.html) where it goes and include [`checkbox-select-all.css`](./checkbox-select-all.css). [`checkbox-select-all.js`](./checkbox-select-all.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
