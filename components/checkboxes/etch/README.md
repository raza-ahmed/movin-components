# Etch checkbox

A sketch toy checkbox: ticking turns the two knobs and a line draws the tick on the screen; unticking shakes the toy and the drawing fades away.

Live preview: https://movin.design/components/checkboxes/etch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-etch
```

Or copy [`checkbox-etch.tsx`](./checkbox-etch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-etch.html`](./checkbox-etch.html) where it goes and include [`checkbox-etch.css`](./checkbox-etch.css). [`checkbox-etch.js`](./checkbox-etch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
