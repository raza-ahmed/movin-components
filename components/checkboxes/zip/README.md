# Zip checkbox

A zip checkbox: ticking runs the slider along the zip, the teeth lock together one after another behind it, and the pull tab swings and shows a tick; unticking unzips from the far end.

Live preview: https://movin.design/components/checkboxes/zip/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-zip
```

Or copy [`checkbox-zip.tsx`](./checkbox-zip.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-zip.html`](./checkbox-zip.html) where it goes and include [`checkbox-zip.css`](./checkbox-zip.css). It is pure CSS, so there is no script.
