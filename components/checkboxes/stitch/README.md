# Stitch checkbox

The box is a patch of fabric and the tick is sewn in: a needle runs along the tick leaving dashed stitches behind it one by one, then slips away. Unchecking pulls the thread out. Pure CSS.

Live preview: https://movin.design/components/checkboxes/stitch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-stitch.json
```

Or copy [`checkbox-stitch.tsx`](./checkbox-stitch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-stitch.html`](./checkbox-stitch.html) where it goes and include [`checkbox-stitch.css`](./checkbox-stitch.css). It is pure CSS, so there is no script.
