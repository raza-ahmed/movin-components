# Filament checkbox

A light bulb checkbox whose filament is the tick: ticking flickers it on until it glows with a halo; unticking lets it cool slowly, the way a real filament does.

Live preview: https://movin.design/components/checkboxes/filament/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-filament
```

Or copy [`checkbox-filament.tsx`](./checkbox-filament.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-filament.html`](./checkbox-filament.html) where it goes and include [`checkbox-filament.css`](./checkbox-filament.css). [`checkbox-filament.js`](./checkbox-filament.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
