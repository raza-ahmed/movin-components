# Ghost Through checkbox

The box fades to near-translucency while the check mark materializes through it, then the box fades back to solid — creating a "materializing through" ghost effect. Eerie and subtle.

Live preview: https://movin.design/components/checkboxes/ghost-through/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-ghost-through
```

Or copy [`checkbox-ghost-through.tsx`](./checkbox-ghost-through.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-ghost-through.html`](./checkbox-ghost-through.html) where it goes and include [`checkbox-ghost-through.css`](./checkbox-ghost-through.css). [`checkbox-ghost-through.js`](./checkbox-ghost-through.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
