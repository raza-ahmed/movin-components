# Pencil checkbox

A checkbox with a pencil in it: ticking, the pencil sweeps in and sketches a hand-drawn tick; unticking, it flips round and the eraser scrubs the mark out, shedding crumbs.

Live preview: https://movin.design/components/checkboxes/pencil/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-pencil
```

Or copy [`checkbox-pencil.tsx`](./checkbox-pencil.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-pencil.html`](./checkbox-pencil.html) where it goes and include [`checkbox-pencil.css`](./checkbox-pencil.css). [`checkbox-pencil.js`](./checkbox-pencil.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
