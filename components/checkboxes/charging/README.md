# Charging checkbox

A light gray progress bar fills left-to-right inside the box over 600ms like a battery charging. When full, the bar fades and a check mark springs in. Unchecking drains the bar.

Live preview: https://movin.design/components/checkboxes/charging/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-charging
```

Or copy [`checkbox-charging.tsx`](./checkbox-charging.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-charging.html`](./checkbox-charging.html) where it goes and include [`checkbox-charging.css`](./checkbox-charging.css). It is pure CSS, so there is no script.
