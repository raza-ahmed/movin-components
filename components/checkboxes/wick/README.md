# Wick checkbox

A candlelight checkbox: ticking it, the wick catches and a flame flickers up with a soft glow; unticking, it gutters out in a thread of smoke.

Live preview: https://movin.design/components/checkboxes/wick/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-wick
```

Or copy [`checkbox-wick.tsx`](./checkbox-wick.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-wick.html`](./checkbox-wick.html) where it goes and include [`checkbox-wick.css`](./checkbox-wick.css). [`checkbox-wick.js`](./checkbox-wick.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
