# Coin checkbox

A tip jar checkbox: ticking drops the coin into the slot, the machine clunks and its little display lights with a tick; unticking pops the coin back out.

Live preview: https://movin.design/components/checkboxes/coin/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-coin
```

Or copy [`checkbox-coin.tsx`](./checkbox-coin.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-coin.html`](./checkbox-coin.html) where it goes and include [`checkbox-coin.css`](./checkbox-coin.css). [`checkbox-coin.js`](./checkbox-coin.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
