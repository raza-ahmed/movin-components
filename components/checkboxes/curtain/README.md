# Curtain checkbox

Two gray half-panels slide apart like theater curtains on check, revealing the check mark behind them. Unchecking slides the panels back in to conceal it.

Live preview: https://movin.design/components/checkboxes/curtain/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-curtain
```

Or copy [`checkbox-curtain.tsx`](./checkbox-curtain.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-curtain.html`](./checkbox-curtain.html) where it goes and include [`checkbox-curtain.css`](./checkbox-curtain.css). It is pure CSS, so there is no script.
