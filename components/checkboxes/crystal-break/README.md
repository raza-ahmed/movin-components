# Crystal Break checkbox

On toggle, the box visually shatters into three angled polygonal shards that briefly separate outward, then collapse back revealing the new state. A satisfying destructive-reassembly metaphor.

Live preview: https://movin.design/components/checkboxes/crystal-break/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-crystal-break.json
```

Or copy [`checkbox-crystal-break.tsx`](./checkbox-crystal-break.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-crystal-break.html`](./checkbox-crystal-break.html) where it goes and include [`checkbox-crystal-break.css`](./checkbox-crystal-break.css). [`checkbox-crystal-break.js`](./checkbox-crystal-break.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
