# Retro LED checkbox

The box interior is a 5×5 dot matrix. On check, white LEDs light up in a staggered sequence that traces a check-mark pattern through the grid. Off state: all dots dim. Retro display aesthetic.

Live preview: https://movin.design/components/checkboxes/retro-led/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-retro-led
```

Or copy [`checkbox-retro-led.tsx`](./checkbox-retro-led.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-retro-led.html`](./checkbox-retro-led.html) where it goes and include [`checkbox-retro-led.css`](./checkbox-retro-led.css). It is pure CSS, so there is no script.
