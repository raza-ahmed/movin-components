# Strike Task checkbox

A to-do row. Checking ticks the box with a pen stroke, then a hand-drawn scribble runs through the task text, out and back, as the text greys out; unchecking rubs it out.

Live preview: https://movin.design/components/checkboxes/strike-task/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-strike-task
```

Or copy [`checkbox-strike-task.tsx`](./checkbox-strike-task.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-strike-task.html`](./checkbox-strike-task.html) where it goes and include [`checkbox-strike-task.css`](./checkbox-strike-task.css). It is pure CSS, so there is no script.
