# CRT checkbox

A tiny CRT screen checkbox: ticking powers the tube on from a line to a glowing tick behind scanlines; unticking collapses the picture to a line, then a dot that fades.

Live preview: https://movin.design/components/checkboxes/crt/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-crt
```

Or copy [`checkbox-crt.tsx`](./checkbox-crt.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-crt.html`](./checkbox-crt.html) where it goes and include [`checkbox-crt.css`](./checkbox-crt.css). [`checkbox-crt.js`](./checkbox-crt.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
