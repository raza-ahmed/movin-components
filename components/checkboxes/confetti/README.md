# Confetti checkbox

On check, 8 grayscale confetti pieces (alternating rectangles and circles) burst radially outward from the center in all directions, rotating and fading as they travel. Playful and celebratory.

Live preview: https://movin.design/components/checkboxes/confetti/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-confetti
```

Or copy [`checkbox-confetti.tsx`](./checkbox-confetti.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-confetti.html`](./checkbox-confetti.html) where it goes and include [`checkbox-confetti.css`](./checkbox-confetti.css). It is pure CSS, so there is no script.
