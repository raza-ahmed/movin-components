# Punch checkbox

A boarding-pass checkbox: ticking brings a ticket punch down on the stub, it bites a tick-shaped hole, the chad tumbles out and the ticket jolts.

Live preview: https://movin.design/components/checkboxes/punch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-punch
```

Or copy [`checkbox-punch.tsx`](./checkbox-punch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-punch.html`](./checkbox-punch.html) where it goes and include [`checkbox-punch.css`](./checkbox-punch.css). [`checkbox-punch.js`](./checkbox-punch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
