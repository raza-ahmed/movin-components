# Neon checkbox

A dark box with a near-invisible border that transforms into a white neon sign on check. A brief 400ms flicker keyframe (simulating a neon tube buzzing to life) plays on activation. The check stroke has a drop-shadow glow matching the neon color.

Live preview: https://movin.design/components/checkboxes/neon/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-neon.json
```

Or copy [`checkbox-neon.tsx`](./checkbox-neon.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-neon.html`](./checkbox-neon.html) where it goes and include [`checkbox-neon.css`](./checkbox-neon.css). It is pure CSS, so there is no script.
