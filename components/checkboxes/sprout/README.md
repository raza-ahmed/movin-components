# Sprout checkbox

Checking plants a seed: the box fills and ticks, then a stem grows up out of its top edge and two leaves unfurl one after the other before the little plant starts to sway. Unchecking pulls the sprout back into the soil.

Live preview: https://movin.design/components/checkboxes/sprout/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-sprout.json
```

Or copy [`checkbox-sprout.tsx`](./checkbox-sprout.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-sprout.html`](./checkbox-sprout.html) where it goes and include [`checkbox-sprout.css`](./checkbox-sprout.css). It is pure CSS, so there is no script.
