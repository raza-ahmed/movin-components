# Wax checkbox

A seal and send checkbox: ticking it, the envelope flap folds shut in 3D and a wax seal drops onto it with a soft press.

Live preview: https://movin.design/components/checkboxes/wax/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-wax
```

Or copy [`checkbox-wax.tsx`](./checkbox-wax.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-wax.html`](./checkbox-wax.html) where it goes and include [`checkbox-wax.css`](./checkbox-wax.css). [`checkbox-wax.js`](./checkbox-wax.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
