# Radar Sweep checkbox

A conic gradient sweeps clockwise from the top, filling the box like a radar scan over ~700ms. The check mark appears once the sweep completes. Driven by a requestAnimationFrame loop.

Live preview: https://movin.design/components/checkboxes/radar-sweep/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-radar-sweep
```

Or copy [`checkbox-radar-sweep.tsx`](./checkbox-radar-sweep.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-radar-sweep.html`](./checkbox-radar-sweep.html) where it goes and include [`checkbox-radar-sweep.css`](./checkbox-radar-sweep.css). It is pure CSS, so there is no script.
