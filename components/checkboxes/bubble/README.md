# Bubble checkbox

A bubble wrap checkbox: ticking pops the bubble with a squash and a burst of lines; unticking puffs it back up.

Live preview: https://movin.design/components/checkboxes/bubble/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-bubble
```

Or copy [`checkbox-bubble.tsx`](./checkbox-bubble.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-bubble.html`](./checkbox-bubble.html) where it goes and include [`checkbox-bubble.css`](./checkbox-bubble.css). [`checkbox-bubble.js`](./checkbox-bubble.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
