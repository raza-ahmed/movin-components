# Paperclip checkbox

An attach receipt checkbox: ticking it, a paperclip slides down onto the crooked receipt and grips it, and the paper springs level under it.

Live preview: https://movin.design/components/checkboxes/paperclip/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-paperclip
```

Or copy [`checkbox-paperclip.tsx`](./checkbox-paperclip.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-paperclip.html`](./checkbox-paperclip.html) where it goes and include [`checkbox-paperclip.css`](./checkbox-paperclip.css). It is pure CSS, so there is no script.
