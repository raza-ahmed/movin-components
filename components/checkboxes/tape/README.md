# Tape checkbox

A packing checkbox: ticking slaps a strip of masking tape with a marker tick across the box, landing at a slight angle; unticking peels it away and off.

Live preview: https://movin.design/components/checkboxes/tape/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-tape
```

Or copy [`checkbox-tape.tsx`](./checkbox-tape.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-tape.html`](./checkbox-tape.html) where it goes and include [`checkbox-tape.css`](./checkbox-tape.css). [`checkbox-tape.js`](./checkbox-tape.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
