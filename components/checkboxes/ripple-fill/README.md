# Ripple Fill checkbox

A circular gray fill expands from the center outward via clip-path circle animation, like a water-drop ripple filling the box. The check mark fades in after the fill completes.

Live preview: https://movin.design/components/checkboxes/ripple-fill/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-ripple-fill
```

Or copy [`checkbox-ripple-fill.tsx`](./checkbox-ripple-fill.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-ripple-fill.html`](./checkbox-ripple-fill.html) where it goes and include [`checkbox-ripple-fill.css`](./checkbox-ripple-fill.css). It is pure CSS, so there is no script.
