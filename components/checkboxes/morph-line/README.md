# Morph Line checkbox

A short horizontal line morphs into a check mark using SVG path d attribute animation — extending first, then bending into the check V-shape. Unchecking reverses the morph back to a line.

Live preview: https://movin.design/components/checkboxes/morph-line/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-morph-line.json
```

Or copy [`checkbox-morph-line.tsx`](./checkbox-morph-line.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-morph-line.html`](./checkbox-morph-line.html) where it goes and include [`checkbox-morph-line.css`](./checkbox-morph-line.css). [`checkbox-morph-line.js`](./checkbox-morph-line.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
