# Fingerprint checkbox

Press and hold to confirm. While held, the fingerprint's ridges light up one by one from the centre outwards; let go early and they drain away. Held to the end, it checks and a badge pops in. Space still toggles it from the keyboard.

Live preview: https://movin.design/components/checkboxes/fingerprint/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-fingerprint.json
```

Or copy [`checkbox-fingerprint.tsx`](./checkbox-fingerprint.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-fingerprint.html`](./checkbox-fingerprint.html) where it goes and include [`checkbox-fingerprint.css`](./checkbox-fingerprint.css). [`checkbox-fingerprint.js`](./checkbox-fingerprint.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
