# Draw Check checkbox

A checkbox where the SVG checkmark stroke draws itself on via stroke-dashoffset when checked, combined with a brief scale pop on the box. The path writes itself left-to-right rather than snapping in.

Live preview: https://movin.design/components/checkboxes/draw-check/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-draw-check
```

Or copy [`checkbox-draw-check.tsx`](./checkbox-draw-check.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-draw-check.html`](./checkbox-draw-check.html) where it goes and include [`checkbox-draw-check.css`](./checkbox-draw-check.css). It is pure CSS, so there is no script.
