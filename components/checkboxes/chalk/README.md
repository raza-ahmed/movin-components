# Chalk checkbox

A lesson done checkbox drawn in chalk: ticking it scrawls a grainy tick inside a hand-drawn box and a little dust falls from it.

Live preview: https://movin.design/components/checkboxes/chalk/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-chalk
```

Or copy [`checkbox-chalk.tsx`](./checkbox-chalk.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-chalk.html`](./checkbox-chalk.html) where it goes and include [`checkbox-chalk.css`](./checkbox-chalk.css). [`checkbox-chalk.js`](./checkbox-chalk.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
