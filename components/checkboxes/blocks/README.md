# Blocks checkbox

A falling blocks checkbox: ticking drops pixel blocks into the box row by row until they stack into a tick, each squashing as it lands; unticking clears the line with a flash.

Live preview: https://movin.design/components/checkboxes/blocks/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-blocks
```

Or copy [`checkbox-blocks.tsx`](./checkbox-blocks.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-blocks.html`](./checkbox-blocks.html) where it goes and include [`checkbox-blocks.css`](./checkbox-blocks.css). [`checkbox-blocks.js`](./checkbox-blocks.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
