# Pulse Ring checkbox

A checkbox that emits a gray ring radiating outward (scale 1→2.4, opacity 0.65→0) when checked. The ring only fires on check, not uncheck. The check mark draws in via stroke-dashoffset.

Live preview: https://movin.design/components/checkboxes/pulse-ring/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add https://movin.design/r/checkbox-pulse-ring.json
```

Or copy [`checkbox-pulse-ring.tsx`](./checkbox-pulse-ring.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-pulse-ring.html`](./checkbox-pulse-ring.html) where it goes and include [`checkbox-pulse-ring.css`](./checkbox-pulse-ring.css). It is pure CSS, so there is no script.
