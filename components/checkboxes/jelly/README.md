# Jelly checkbox

A jelly cube checkbox: ticking squashes it and it wobbles, stretching tall and wide in turn, while the tick drops in and sets; unticking gives a smaller wobble.

Live preview: https://movin.design/components/checkboxes/jelly/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-jelly
```

Or copy [`checkbox-jelly.tsx`](./checkbox-jelly.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-jelly.html`](./checkbox-jelly.html) where it goes and include [`checkbox-jelly.css`](./checkbox-jelly.css). [`checkbox-jelly.js`](./checkbox-jelly.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
