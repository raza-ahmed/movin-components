# Spotlight checkbox

A spotlight checkbox: ticking swings a spotlight round onto the box, its beam lights the floor, and the tick appears in the light; unticking turns it away and dark.

Live preview: https://movin.design/components/checkboxes/spotlight/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-spotlight
```

Or copy [`checkbox-spotlight.tsx`](./checkbox-spotlight.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-spotlight.html`](./checkbox-spotlight.html) where it goes and include [`checkbox-spotlight.css`](./checkbox-spotlight.css). It is pure CSS, so there is no script.
