# Pushpin checkbox

A pin to board checkbox: ticking it drops a pin into the crooked note card and the card swings level on the board.

Live preview: https://movin.design/components/checkboxes/pushpin/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-pushpin
```

Or copy [`checkbox-pushpin.tsx`](./checkbox-pushpin.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-pushpin.html`](./checkbox-pushpin.html) where it goes and include [`checkbox-pushpin.css`](./checkbox-pushpin.css). [`checkbox-pushpin.js`](./checkbox-pushpin.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
