# Merge checkbox

A git branch checkbox: ticking draws the branch curving back into main, the merge commit fills with a tick and pulses; unticking leaves the branch open again.

Live preview: https://movin.design/components/checkboxes/merge/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-merge
```

Or copy [`checkbox-merge.tsx`](./checkbox-merge.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-merge.html`](./checkbox-merge.html) where it goes and include [`checkbox-merge.css`](./checkbox-merge.css). It is pure CSS, so there is no script.
