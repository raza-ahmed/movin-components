# Tilt Hover checkbox

On hover, the box tilts in 3D perspective (rotateX + rotateY) giving depth and a subtle lift shadow. Clicking snaps it flat and fills with mid-gray. The tilt resets once checked.

Live preview: https://movin.design/components/checkboxes/tilt-hover/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-tilt-hover
```

Or copy [`checkbox-tilt-hover.tsx`](./checkbox-tilt-hover.tsx) into your project. Dependencies: none.

## Plain HTML + CSS

No framework and no dependencies. Paste [`checkbox-tilt-hover.html`](./checkbox-tilt-hover.html) where it goes and include [`checkbox-tilt-hover.css`](./checkbox-tilt-hover.css). It is pure CSS, so there is no script.
