# Hoop checkbox

A basketball checkbox: ticking shoots the ball in an arc through the hoop, the net swishes and the backboard lights with a tick; unticking rolls the ball back.

Live preview: https://movin.design/components/checkboxes/hoop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-hoop
```

Or copy [`checkbox-hoop.tsx`](./checkbox-hoop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-hoop.html`](./checkbox-hoop.html) where it goes and include [`checkbox-hoop.css`](./checkbox-hoop.css). [`checkbox-hoop.js`](./checkbox-hoop.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
