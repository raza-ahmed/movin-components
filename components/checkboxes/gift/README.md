# Gift checkbox

A present checkbox: ticking pops the lid off the box, it flies up and lands askew, and a tick springs out of the box; unticking sinks the tick and closes the lid.

Live preview: https://movin.design/components/checkboxes/gift/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-gift
```

Or copy [`checkbox-gift.tsx`](./checkbox-gift.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-gift.html`](./checkbox-gift.html) where it goes and include [`checkbox-gift.css`](./checkbox-gift.css). [`checkbox-gift.js`](./checkbox-gift.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
