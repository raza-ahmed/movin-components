# Scan checkbox

A ticket scanner checkbox: ticking sweeps a laser line down and back over a code, it flashes, and the code dissolves into a tick; unticking rebuilds the code.

Live preview: https://movin.design/components/checkboxes/scan/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-scan
```

Or copy [`checkbox-scan.tsx`](./checkbox-scan.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-scan.html`](./checkbox-scan.html) where it goes and include [`checkbox-scan.css`](./checkbox-scan.css). [`checkbox-scan.js`](./checkbox-scan.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
