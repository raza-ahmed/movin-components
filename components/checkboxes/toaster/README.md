# Toaster checkbox

A breakfast included checkbox: ticking it pops the toast up out of the toaster with a bounce, browned and ready, as the lever goes up.

Live preview: https://movin.design/components/checkboxes/toaster/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/checkbox-toaster
```

Or copy [`checkbox-toaster.tsx`](./checkbox-toaster.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`checkbox-toaster.html`](./checkbox-toaster.html) where it goes and include [`checkbox-toaster.css`](./checkbox-toaster.css). [`checkbox-toaster.js`](./checkbox-toaster.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
