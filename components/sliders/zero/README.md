# Zero slider

A bipolar exposure slider: the fill grows from the centre in either direction, the thumb sticks at zero for a moment as a drag crosses it, and the sign flips over.

Live preview: https://movin.design/components/sliders/zero/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-zero
```

Or copy [`slider-zero.tsx`](./slider-zero.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-zero.html`](./slider-zero.html) where it goes and include [`slider-zero.css`](./slider-zero.css). [`slider-zero.js`](./slider-zero.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
