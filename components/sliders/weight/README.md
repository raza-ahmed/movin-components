# Weight slider

A font-weight slider: the sample letters thicken from Thin to Black as you drag, and the weight name and number change below.

Live preview: https://movin.design/components/sliders/weight/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-weight
```

Or copy [`slider-weight.tsx`](./slider-weight.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-weight.html`](./slider-weight.html) where it goes and include [`slider-weight.css`](./slider-weight.css). [`slider-weight.js`](./slider-weight.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
