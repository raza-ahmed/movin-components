# Windsock slider

A wind speed slider drawn as a windsock: in calm air it hangs limp from the pole, and as the wind picks up it lifts level and fills, flapping faster, with the Beaufort name in the reading.

Live preview: https://movin.design/components/sliders/windsock/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-windsock
```

Or copy [`slider-windsock.tsx`](./slider-windsock.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-windsock.html`](./slider-windsock.html) where it goes and include [`slider-windsock.css`](./slider-windsock.css). [`slider-windsock.js`](./slider-windsock.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
