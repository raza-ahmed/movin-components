# Pinion slider

A rack and pinion: the track is a toothed rack and the thumb a gear that turns as it rolls along, its teeth meshing with the rack, the travelled length inked.

Live preview: https://movin.design/components/sliders/pinion/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-pinion
```

Or copy [`slider-pinion.tsx`](./slider-pinion.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-pinion.html`](./slider-pinion.html) where it goes and include [`slider-pinion.css`](./slider-pinion.css). [`slider-pinion.js`](./slider-pinion.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
