# Bubble slider

An opacity slider whose value bubble leans against the drag like it has weight, harder the faster you move, then swings upright once the thumb rests.

Live preview: https://movin.design/components/sliders/bubble/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-bubble
```

Or copy [`slider-bubble.tsx`](./slider-bubble.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-bubble.html`](./slider-bubble.html) where it goes and include [`slider-bubble.css`](./slider-bubble.css). [`slider-bubble.js`](./slider-bubble.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
