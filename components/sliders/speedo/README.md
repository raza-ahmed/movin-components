# Speedo slider

A speed-limit slider as a car gauge: the needle sweeps the dial with a little overshoot, the lit arc follows it and the digital reading changes in km/h.

Live preview: https://movin.design/components/sliders/speedo/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-speedo
```

Or copy [`slider-speedo.tsx`](./slider-speedo.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-speedo.html`](./slider-speedo.html) where it goes and include [`slider-speedo.css`](./slider-speedo.css). [`slider-speedo.js`](./slider-speedo.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
