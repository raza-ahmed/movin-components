# Rings slider

A tree age slider drawn as a cut stump: the trunk widens with the years and growth rings appear from the pith outwards, a little uneven like real wood.

Live preview: https://movin.design/components/sliders/rings/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-rings
```

Or copy [`slider-rings.tsx`](./slider-rings.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-rings.html`](./slider-rings.html) where it goes and include [`slider-rings.css`](./slider-rings.css). [`slider-rings.js`](./slider-rings.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
