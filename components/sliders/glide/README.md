# Glide slider

A slider with momentum: flick the thumb and it keeps gliding, slowing with friction, and bounces off the ends with a squash.

Live preview: https://movin.design/components/sliders/glide/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-glide
```

Or copy [`slider-glide.tsx`](./slider-glide.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-glide.html`](./slider-glide.html) where it goes and include [`slider-glide.css`](./slider-glide.css). [`slider-glide.js`](./slider-glide.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
