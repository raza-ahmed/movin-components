# Vial slider

A stereo balance control shaped like a spirit level: the thumb is the air bubble, which stretches as it moves, wobbles as it stops and settles between the two centre marks.

Live preview: https://movin.design/components/sliders/vial/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-vial
```

Or copy [`slider-vial.tsx`](./slider-vial.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-vial.html`](./slider-vial.html) where it goes and include [`slider-vial.css`](./slider-vial.css). [`slider-vial.js`](./slider-vial.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
