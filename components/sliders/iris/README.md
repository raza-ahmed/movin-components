# Iris slider

An aperture slider drawn as a lens iris: the blades close in and turn as you stop down from f/1.4 to f/16, and the soft lights behind sharpen into focus.

Live preview: https://movin.design/components/sliders/iris/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-iris
```

Or copy [`slider-iris.tsx`](./slider-iris.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-iris.html`](./slider-iris.html) where it goes and include [`slider-iris.css`](./slider-iris.css). [`slider-iris.js`](./slider-iris.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
