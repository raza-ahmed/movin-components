# Telescope slider

A zoom slider as a telescope: the tubes slide out of each other and the moon in the eyepiece grows until its craters fill the view, with the magnification beside it.

Live preview: https://movin.design/components/sliders/telescope/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-telescope
```

Or copy [`slider-telescope.tsx`](./slider-telescope.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-telescope.html`](./slider-telescope.html) where it goes and include [`slider-telescope.css`](./slider-telescope.css). [`slider-telescope.js`](./slider-telescope.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
