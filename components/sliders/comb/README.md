# Comb slider

A slider made of fine ticks that rise around the thumb like a magnified dock, lean the way you drag, harder the faster you go, and stand back up when you stop.

Live preview: https://movin.design/components/sliders/comb/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-comb
```

Or copy [`slider-comb.tsx`](./slider-comb.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-comb.html`](./slider-comb.html) where it goes and include [`slider-comb.css`](./slider-comb.css). [`slider-comb.js`](./slider-comb.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
