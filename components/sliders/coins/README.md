# Coins slider

A tip slider as a stack of coins: every dollar drops another coin onto the stack with a bounce, and taking one off lifts it back into the air.

Live preview: https://movin.design/components/sliders/coins/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-coins
```

Or copy [`slider-coins.tsx`](./slider-coins.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-coins.html`](./slider-coins.html) where it goes and include [`slider-coins.css`](./slider-coins.css). [`slider-coins.js`](./slider-coins.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
