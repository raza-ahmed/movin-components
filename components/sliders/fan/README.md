# Fan slider

A fan-speed slider with five settings: the blades spool up and wind down smoothly rather than jumping, and air lines stream off faster at each step.

Live preview: https://movin.design/components/sliders/fan/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-fan
```

Or copy [`slider-fan.tsx`](./slider-fan.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-fan.html`](./slider-fan.html) where it goes and include [`slider-fan.css`](./slider-fan.css). [`slider-fan.js`](./slider-fan.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
