# Strata slider

A slider whose fill is three layers of paper: the top one follows the thumb and the ones underneath trail on softer springs, so a drag fans their edges out and they settle back into a stack.

Live preview: https://movin.design/components/sliders/strata/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-strata
```

Or copy [`slider-strata.tsx`](./slider-strata.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-strata.html`](./slider-strata.html) where it goes and include [`slider-strata.css`](./slider-strata.css). [`slider-strata.js`](./slider-strata.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
