# Radius slider

A corner-radius slider: the square softens into a circle as you drag, a guide shows the radius at its corner and the thumb itself rounds with it.

Live preview: https://movin.design/components/sliders/radius/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-radius
```

Or copy [`slider-radius.tsx`](./slider-radius.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-radius.html`](./slider-radius.html) where it goes and include [`slider-radius.css`](./slider-radius.css). [`slider-radius.js`](./slider-radius.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
