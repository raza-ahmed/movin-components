# Trail slider

A trail-distance slider over an elevation profile: drag and the hiker walks the line, the walked part fills in and the distance and height above update.

Live preview: https://movin.design/components/sliders/trail/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-trail
```

Or copy [`slider-trail.tsx`](./slider-trail.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-trail.html`](./slider-trail.html) where it goes and include [`slider-trail.css`](./slider-trail.css). [`slider-trail.js`](./slider-trail.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
