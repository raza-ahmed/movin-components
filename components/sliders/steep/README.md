# Steep slider

A tea-strength slider: the bag bobs in the cup, colour curls out of it into the water, steam rises and the strength word and steeping time change below.

Live preview: https://movin.design/components/sliders/steep/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-steep
```

Or copy [`slider-steep.tsx`](./slider-steep.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-steep.html`](./slider-steep.html) where it goes and include [`slider-steep.css`](./slider-steep.css). [`slider-steep.js`](./slider-steep.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
