# Rain slider

A rainfall slider: more and more drops fall as the rate rises, the puddle spreads and ripples ring out on it, from a drizzle to a downpour.

Live preview: https://movin.design/components/sliders/rain/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-rain
```

Or copy [`slider-rain.tsx`](./slider-rain.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-rain.html`](./slider-rain.html) where it goes and include [`slider-rain.css`](./slider-rain.css). [`slider-rain.js`](./slider-rain.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
