# Gap slider

A thick-track slider split by a slim handle with a gap either side of it: the handle thins as you press, the value rises above it in a pill, and a stop dot marks the end.

Live preview: https://movin.design/components/sliders/gap/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-gap
```

Or copy [`slider-gap.tsx`](./slider-gap.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-gap.html`](./slider-gap.html) where it goes and include [`slider-gap.css`](./slider-gap.css). [`slider-gap.js`](./slider-gap.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
