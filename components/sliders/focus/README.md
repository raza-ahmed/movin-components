# Focus slider

A camera focus slider: the scene sharpens from a blur as you drag, the focus box closes in on the subject, and at sharp focus it locks with a flash and the AF light comes on.

Live preview: https://movin.design/components/sliders/focus/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-focus
```

Or copy [`slider-focus.tsx`](./slider-focus.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-focus.html`](./slider-focus.html) where it goes and include [`slider-focus.css`](./slider-focus.css). [`slider-focus.js`](./slider-focus.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
