# Ratchet slider

The thumb carries a pawl that rides over teeth cut in the track: it lifts up each ramp, drops off the edge into the next tooth and lands with a small click.

Live preview: https://movin.design/components/sliders/ratchet/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-ratchet
```

Or copy [`slider-ratchet.tsx`](./slider-ratchet.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-ratchet.html`](./slider-ratchet.html) where it goes and include [`slider-ratchet.css`](./slider-ratchet.css). [`slider-ratchet.js`](./slider-ratchet.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
