# Shuttle slider

A spring-loaded shuttle from an edit suite: push the handle either way and the time runs faster the further you push it, with chevrons lighting up; let go and it springs back to centre.

Live preview: https://movin.design/components/sliders/shuttle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-shuttle
```

Or copy [`slider-shuttle.tsx`](./slider-shuttle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-shuttle.html`](./slider-shuttle.html) where it goes and include [`slider-shuttle.css`](./slider-shuttle.css). [`slider-shuttle.js`](./slider-shuttle.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
