# Extrude slider

A storage bar seen from a little above: the filled part rises out of the track as a solid block with shaded faces, and grows taller while you hold it.

Live preview: https://movin.design/components/sliders/extrude/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-extrude
```

Or copy [`slider-extrude.tsx`](./slider-extrude.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-extrude.html`](./slider-extrude.html) where it goes and include [`slider-extrude.css`](./slider-extrude.css). [`slider-extrude.js`](./slider-extrude.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
