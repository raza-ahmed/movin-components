# Pour slider

A fill-level slider as a glass of water: drag up and the glass fills, the surface rolling and bubbles rising through it, with the level marked on a scale beside the glass.

Live preview: https://movin.design/components/sliders/pour/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-pour
```

Or copy [`slider-pour.tsx`](./slider-pour.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-pour.html`](./slider-pour.html) where it goes and include [`slider-pour.css`](./slider-pour.css). [`slider-pour.js`](./slider-pour.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
