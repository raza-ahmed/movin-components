# Fuse slider

A delay slider drawn as a burning fuse: the cord still to burn is the fill, ash lies ahead of the thumb, and the spark at the thumb fizzes and spits more embers the faster you drag.

Live preview: https://movin.design/components/sliders/fuse/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-fuse
```

Or copy [`slider-fuse.tsx`](./slider-fuse.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-fuse.html`](./slider-fuse.html) where it goes and include [`slider-fuse.css`](./slider-fuse.css). [`slider-fuse.js`](./slider-fuse.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
