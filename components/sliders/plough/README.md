# Plough slider

The thumb is a blade pushing sand: behind it the floor is scraped clean as the fill, and pushing forward builds a heap against the blade, bigger the faster you push, that slumps flat when you stop.

Live preview: https://movin.design/components/sliders/plough/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-plough
```

Or copy [`slider-plough.tsx`](./slider-plough.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-plough.html`](./slider-plough.html) where it goes and include [`slider-plough.css`](./slider-plough.css). [`slider-plough.js`](./slider-plough.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
