# Foil slider

A brightness slider in brushed metal with a polished bead for a thumb: the sheen slides back across the metal as you drag, like foil tilting under a light, and the bead's highlight shifts with it.

Live preview: https://movin.design/components/sliders/foil/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-foil
```

Or copy [`slider-foil.tsx`](./slider-foil.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-foil.html`](./slider-foil.html) where it goes and include [`slider-foil.css`](./slider-foil.css). [`slider-foil.js`](./slider-foil.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
