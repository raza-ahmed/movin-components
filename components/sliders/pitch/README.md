# Pitch slider

An oscilloscope frequency slider: the wave on the screen tightens and runs faster as the pitch climbs, with the reading in hertz across three octaves.

Live preview: https://movin.design/components/sliders/pitch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-pitch
```

Or copy [`slider-pitch.tsx`](./slider-pitch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-pitch.html`](./slider-pitch.html) where it goes and include [`slider-pitch.css`](./slider-pitch.css). [`slider-pitch.js`](./slider-pitch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
