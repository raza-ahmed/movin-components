# Band slider

A time range whose fill is a rubber band looped round two pegs: it thins as you pull the pegs apart and thickens as they close, buzzes as you drag and twangs when you let go.

Live preview: https://movin.design/components/sliders/band/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-band
```

Or copy [`slider-band.tsx`](./slider-band.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-band.html`](./slider-band.html) where it goes and include [`slider-band.css`](./slider-band.css). [`slider-band.js`](./slider-band.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
