# Ruler slider

A weight picker as a tape measure: the ruler slides under a fixed marker as you drag and the big reading above changes kilogram by kilogram.

Live preview: https://movin.design/components/sliders/ruler/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-ruler
```

Or copy [`slider-ruler.tsx`](./slider-ruler.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-ruler.html`](./slider-ruler.html) where it goes and include [`slider-ruler.css`](./slider-ruler.css). [`slider-ruler.js`](./slider-ruler.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
