# Balance slider

A save and spend split drawn as a balance scale: the heavier pan tips down, overshooting a little before it settles, and the reading shows both shares.

Live preview: https://movin.design/components/sliders/balance/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-balance
```

Or copy [`slider-balance.tsx`](./slider-balance.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-balance.html`](./slider-balance.html) where it goes and include [`slider-balance.css`](./slider-balance.css). [`slider-balance.js`](./slider-balance.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
