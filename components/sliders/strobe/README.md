# Strobe slider

A slider whose thumb leaves fading afterimages as it moves, like a strobe photograph: spread far apart on a fast drag and bunched up on a slow one.

Live preview: https://movin.design/components/sliders/strobe/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-strobe
```

Or copy [`slider-strobe.tsx`](./slider-strobe.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-strobe.html`](./slider-strobe.html) where it goes and include [`slider-strobe.css`](./slider-strobe.css). [`slider-strobe.js`](./slider-strobe.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
