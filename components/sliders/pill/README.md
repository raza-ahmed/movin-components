# Pill slider

At rest it is a small chip with a speaker icon and the value; hover, focus or tap it and it unfolds into a full volume slider, then folds back once you are done.

Live preview: https://movin.design/components/sliders/pill/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-pill
```

Or copy [`slider-pill.tsx`](./slider-pill.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-pill.html`](./slider-pill.html) where it goes and include [`slider-pill.css`](./slider-pill.css). [`slider-pill.js`](./slider-pill.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
