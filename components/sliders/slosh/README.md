# Slosh slider

The fill is liquid in a sealed glass tube: drag and its face leans back against the motion, then sloshes forward past upright when you stop and settles level.

Live preview: https://movin.design/components/sliders/slosh/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-slosh
```

Or copy [`slider-slosh.tsx`](./slider-slosh.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-slosh.html`](./slider-slosh.html) where it goes and include [`slider-slosh.css`](./slider-slosh.css). [`slider-slosh.js`](./slider-slosh.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
