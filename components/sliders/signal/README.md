# Signal slider

A signal-strength slider: five bars rise and light one by one as you drag, and a word for the strength changes from No signal to Excellent.

Live preview: https://movin.design/components/sliders/signal/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-signal
```

Or copy [`slider-signal.tsx`](./slider-signal.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-signal.html`](./slider-signal.html) where it goes and include [`slider-signal.css`](./slider-signal.css). [`slider-signal.js`](./slider-signal.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
