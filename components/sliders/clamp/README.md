# Clamp slider

An inset slider drawn as a vice: drag either jaw and both close in from the ends together, and once they reach the word between them they squeeze it narrower.

Live preview: https://movin.design/components/sliders/clamp/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-clamp
```

Or copy [`slider-clamp.tsx`](./slider-clamp.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-clamp.html`](./slider-clamp.html) where it goes and include [`slider-clamp.css`](./slider-clamp.css). [`slider-clamp.js`](./slider-clamp.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
