# Tally slider

A streak counter drawn as tally marks: each mark draws itself in with a pen stroke, every fifth strikes through the four before it, and going back rubs them out from the end.

Live preview: https://movin.design/components/sliders/tally/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-tally
```

Or copy [`slider-tally.tsx`](./slider-tally.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-tally.html`](./slider-tally.html) where it goes and include [`slider-tally.css`](./slider-tally.css). [`slider-tally.js`](./slider-tally.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
