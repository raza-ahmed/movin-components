# Compare slider

A before-and-after comparison: drag the divider across two versions of a page and each side reveals more of its version, with the label on each.

Live preview: https://movin.design/components/sliders/compare/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-compare
```

Or copy [`slider-compare.tsx`](./slider-compare.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-compare.html`](./slider-compare.html) where it goes and include [`slider-compare.css`](./slider-compare.css). [`slider-compare.js`](./slider-compare.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
