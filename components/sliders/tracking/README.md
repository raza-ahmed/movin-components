# Tracking slider

A letter-spacing slider: the letters of the word spread apart and draw together as you drag, each a beat after the one before, with the value in em below.

Live preview: https://movin.design/components/sliders/tracking/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-tracking
```

Or copy [`slider-tracking.tsx`](./slider-tracking.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-tracking.html`](./slider-tracking.html) where it goes and include [`slider-tracking.css`](./slider-tracking.css). [`slider-tracking.js`](./slider-tracking.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
