# Thumbwheel slider

An exposure control set as a knurled roller in a slot: drag across it and the ridges roll past with real curvature, clicking into each third of a stop, with a fine line below showing where you are in the range.

Live preview: https://movin.design/components/sliders/thumbwheel/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-thumbwheel
```

Or copy [`slider-thumbwheel.tsx`](./slider-thumbwheel.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-thumbwheel.html`](./slider-thumbwheel.html) where it goes and include [`slider-thumbwheel.css`](./slider-thumbwheel.css). [`slider-thumbwheel.js`](./slider-thumbwheel.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
