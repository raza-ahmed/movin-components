# Glass slider

A volume slider whose solid thumb turns into a glass lens while you hold it, magnifying the track underneath, then turns solid again when you let go.

Live preview: https://movin.design/components/sliders/glass/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-glass
```

Or copy [`slider-glass.tsx`](./slider-glass.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-glass.html`](./slider-glass.html) where it goes and include [`slider-glass.css`](./slider-glass.css). [`slider-glass.js`](./slider-glass.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
