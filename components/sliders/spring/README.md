# Spring slider

A tension slider as a coil spring: drag and the spring stretches between the wall and the weight, its coils flattening out as it lengthens, with the force in newtons below.

Live preview: https://movin.design/components/sliders/spring/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-spring
```

Or copy [`slider-spring.tsx`](./slider-spring.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-spring.html`](./slider-spring.html) where it goes and include [`slider-spring.css`](./slider-spring.css). [`slider-spring.js`](./slider-spring.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
