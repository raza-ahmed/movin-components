# Nib slider

The thumb is a pen nib and the fill is the line it draws: drag slowly for a heavy stroke and quickly for a hairline, so the fill keeps a record of how you moved.

Live preview: https://movin.design/components/sliders/nib/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-nib
```

Or copy [`slider-nib.tsx`](./slider-nib.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-nib.html`](./slider-nib.html) where it goes and include [`slider-nib.css`](./slider-nib.css). [`slider-nib.js`](./slider-nib.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
