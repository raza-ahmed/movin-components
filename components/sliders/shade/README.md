# Shade slider

An ink-strength picker: the track is the ramp from paper to full ink, the thumb carries the shade you pick, and the swatch beside the name fills with it.

Live preview: https://movin.design/components/sliders/shade/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-shade
```

Or copy [`slider-shade.tsx`](./slider-shade.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-shade.html`](./slider-shade.html) where it goes and include [`slider-shade.css`](./slider-shade.css). [`slider-shade.js`](./slider-shade.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
