# Curl slider

A page turn slider: the corner of the page curls back as you drag, showing the next chapter underneath, until the page has turned.

Live preview: https://movin.design/components/sliders/curl/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-curl
```

Or copy [`slider-curl.tsx`](./slider-curl.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-curl.html`](./slider-curl.html) where it goes and include [`slider-curl.css`](./slider-curl.css). [`slider-curl.js`](./slider-curl.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
