# Overcast slider

A cloud cover slider: clouds drift in from either side one after another as the cover rises, the sky greys over and the sun dims behind them.

Live preview: https://movin.design/components/sliders/overcast/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-overcast
```

Or copy [`slider-overcast.tsx`](./slider-overcast.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-overcast.html`](./slider-overcast.html) where it goes and include [`slider-overcast.css`](./slider-overcast.css). [`slider-overcast.js`](./slider-overcast.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
