# Hourglass slider

A timer slider as an hourglass: drag up to add minutes and the sand flows back into the top bulb, while the stream keeps trickling into the pile below.

Live preview: https://movin.design/components/sliders/hourglass/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-hourglass
```

Or copy [`slider-hourglass.tsx`](./slider-hourglass.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-hourglass.html`](./slider-hourglass.html) where it goes and include [`slider-hourglass.css`](./slider-hourglass.css). [`slider-hourglass.js`](./slider-hourglass.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
