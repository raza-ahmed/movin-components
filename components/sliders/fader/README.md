# Fader slider

A mixing-desk channel fader: push the cap up its groove past the dB scale and the stereo meter beside it bounces up to the level you set, with the reading in decibels below.

Live preview: https://movin.design/components/sliders/fader/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-fader
```

Or copy [`slider-fader.tsx`](./slider-fader.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-fader.html`](./slider-fader.html) where it goes and include [`slider-fader.css`](./slider-fader.css). [`slider-fader.js`](./slider-fader.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
