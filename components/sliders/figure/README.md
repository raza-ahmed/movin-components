# Figure slider

A slider whose number is the thumb: the figure rides a hairline that parts around it and leans into the drag like italic type, then rights itself with a small swing when you let go.

Live preview: https://movin.design/components/sliders/figure/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-figure
```

Or copy [`slider-figure.tsx`](./slider-figure.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-figure.html`](./slider-figure.html) where it goes and include [`slider-figure.css`](./slider-figure.css). [`slider-figure.js`](./slider-figure.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
