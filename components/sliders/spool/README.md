# Spool slider

A length slider whose thumb is a spool of thread: it rolls along the track laying its thread down as the fill, shrinking as it runs out and filling out again as it winds back.

Live preview: https://movin.design/components/sliders/spool/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-spool
```

Or copy [`slider-spool.tsx`](./slider-spool.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-spool.html`](./slider-spool.html) where it goes and include [`slider-spool.css`](./slider-spool.css). [`slider-spool.js`](./slider-spool.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
