# Zipper slider

An unzip slider: drag the pull along and the zip opens behind it, the teeth parting along both edges in a widening V.

Live preview: https://movin.design/components/sliders/zipper/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-zipper
```

Or copy [`slider-zipper.tsx`](./slider-zipper.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-zipper.html`](./slider-zipper.html) where it goes and include [`slider-zipper.css`](./slider-zipper.css). [`slider-zipper.js`](./slider-zipper.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
