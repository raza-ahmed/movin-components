# Wedge slider

A volume slider shaped as a ramp: the track widens from a hairline to a full wedge, the fill brightens towards the thumb, and the whole ramp swells while you hold it.

Live preview: https://movin.design/components/sliders/wedge/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-wedge
```

Or copy [`slider-wedge.tsx`](./slider-wedge.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-wedge.html`](./slider-wedge.html) where it goes and include [`slider-wedge.css`](./slider-wedge.css). [`slider-wedge.js`](./slider-wedge.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
