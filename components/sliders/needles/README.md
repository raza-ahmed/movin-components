# Needles slider

A row of compass needles above the track all swing to point at the thumb; the ones it has passed are inked, the ones ahead stay faint, and they wobble a little as they settle.

Live preview: https://movin.design/components/sliders/needles/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-needles
```

Or copy [`slider-needles.tsx`](./slider-needles.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-needles.html`](./slider-needles.html) where it goes and include [`slider-needles.css`](./slider-needles.css). [`slider-needles.js`](./slider-needles.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
