# Lift slider

An opacity slider whose thumb you pick up: it lifts off the track over a softening shadow and swings as you drag, then drops back with a squash and a ripple.

Live preview: https://movin.design/components/sliders/lift/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-lift
```

Or copy [`slider-lift.tsx`](./slider-lift.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-lift.html`](./slider-lift.html) where it goes and include [`slider-lift.css`](./slider-lift.css). [`slider-lift.js`](./slider-lift.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
