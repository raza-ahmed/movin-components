# Goo slider

A liquid volume slider: the fill and the thumb are one blob, and a drop pulls off the thumb and melts back into it as you drag.

Live preview: https://movin.design/components/sliders/goo/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-goo
```

Or copy [`slider-goo.tsx`](./slider-goo.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-goo.html`](./slider-goo.html) where it goes and include [`slider-goo.css`](./slider-goo.css). [`slider-goo.js`](./slider-goo.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
