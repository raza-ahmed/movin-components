# Foam slider

The track is a slab of memory foam: the thumb presses a dent into it, deeper while you hold it, and where the thumb has just been the dent fills back in slowly.

Live preview: https://movin.design/components/sliders/foam/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-foam
```

Or copy [`slider-foam.tsx`](./slider-foam.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-foam.html`](./slider-foam.html) where it goes and include [`slider-foam.css`](./slider-foam.css). [`slider-foam.js`](./slider-foam.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
