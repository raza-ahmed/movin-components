# Merge slider

A price range with two thumbs, each with its value above it; bring them close and the two labels slide together and merge into one range label.

Live preview: https://movin.design/components/sliders/merge/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-merge
```

Or copy [`slider-merge.tsx`](./slider-merge.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-merge.html`](./slider-merge.html) where it goes and include [`slider-merge.css`](./slider-merge.css). [`slider-merge.js`](./slider-merge.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
