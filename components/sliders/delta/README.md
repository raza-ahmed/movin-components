# Delta slider

Grab the thumb and a ghost stays at the value you started from, with a bracket and a signed change between them; let go and the ghost slides over and joins the thumb.

Live preview: https://movin.design/components/sliders/delta/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-delta
```

Or copy [`slider-delta.tsx`](./slider-delta.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-delta.html`](./slider-delta.html) where it goes and include [`slider-delta.css`](./slider-delta.css). [`slider-delta.js`](./slider-delta.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
