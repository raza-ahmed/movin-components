# Bass slider

A bass slider as a speaker: the woofer cone pumps harder and throws a wider shock ring around the cabinet the more bass you add.

Live preview: https://movin.design/components/sliders/bass/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-bass
```

Or copy [`slider-bass.tsx`](./slider-bass.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-bass.html`](./slider-bass.html) where it goes and include [`slider-bass.css`](./slider-bass.css). [`slider-bass.js`](./slider-bass.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
