# Cast slider

A light slider whose thumb is a small lamp: the scale ticks stand up from the track and each throws a shadow away from it, long far off and short close by, swinging round as the lamp passes.

Live preview: https://movin.design/components/sliders/cast/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-cast
```

Or copy [`slider-cast.tsx`](./slider-cast.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-cast.html`](./slider-cast.html) where it goes and include [`slider-cast.css`](./slider-cast.css). [`slider-cast.js`](./slider-cast.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
