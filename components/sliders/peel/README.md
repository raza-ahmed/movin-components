# Peel slider

A coverage slider whose fill is a strip of masking tape with its end folded back: drag back to peel it up, with the flap lifting higher the faster you pull, and forward to press it down.

Live preview: https://movin.design/components/sliders/peel/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-peel
```

Or copy [`slider-peel.tsx`](./slider-peel.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-peel.html`](./slider-peel.html) where it goes and include [`slider-peel.css`](./slider-peel.css). [`slider-peel.js`](./slider-peel.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
