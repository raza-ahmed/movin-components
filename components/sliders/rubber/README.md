# Rubber slider

A tall brightness capsule: drag past either end and it stretches after your finger, then springs back into shape when you let go, while the sun inside grows its rays.

Live preview: https://movin.design/components/sliders/rubber/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-rubber
```

Or copy [`slider-rubber.tsx`](./slider-rubber.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-rubber.html`](./slider-rubber.html) where it goes and include [`slider-rubber.css`](./slider-rubber.css). [`slider-rubber.js`](./slider-rubber.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
