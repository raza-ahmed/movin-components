# Tempo slider

A tempo slider whose thumb keeps time at the tempo you set: every beat it kicks and sends a ring and a pulse running both ways down the track, with every fourth beat accented.

Live preview: https://movin.design/components/sliders/tempo/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-tempo
```

Or copy [`slider-tempo.tsx`](./slider-tempo.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-tempo.html`](./slider-tempo.html) where it goes and include [`slider-tempo.css`](./slider-tempo.css). [`slider-tempo.js`](./slider-tempo.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
