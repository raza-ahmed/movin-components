# Tide slider

A tide height slider drawn as a harbour: the water rises up the wall against its marks, the moored boat bobs up with it and the mooring line goes from slack to nearly straight.

Live preview: https://movin.design/components/sliders/tide/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-tide
```

Or copy [`slider-tide.tsx`](./slider-tide.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-tide.html`](./slider-tide.html) where it goes and include [`slider-tide.css`](./slider-tide.css). [`slider-tide.js`](./slider-tide.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
