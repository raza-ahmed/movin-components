# Halftone slider

An ink coverage slider printed in halftone: dots far behind the thumb swell and fuse into solid ink, thinning to fine points at its edge, with faint dots ahead.

Live preview: https://movin.design/components/sliders/halftone/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-halftone
```

Or copy [`slider-halftone.tsx`](./slider-halftone.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-halftone.html`](./slider-halftone.html) where it goes and include [`slider-halftone.css`](./slider-halftone.css). [`slider-halftone.js`](./slider-halftone.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
