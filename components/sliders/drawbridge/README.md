# Drawbridge slider

A drawbridge slider: the two leaves lift apart as you drag; while it is down a car drives across, and once it is well open a boat sails through underneath.

Live preview: https://movin.design/components/sliders/drawbridge/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-drawbridge
```

Or copy [`slider-drawbridge.tsx`](./slider-drawbridge.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-drawbridge.html`](./slider-drawbridge.html) where it goes and include [`slider-drawbridge.css`](./slider-drawbridge.css). [`slider-drawbridge.js`](./slider-drawbridge.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
