# Pleat slider

A slider whose ribbon folds like an accordion: the part ahead of the thumb is pleated and packs tighter as you push, then pulls flat again as you drag back.

Live preview: https://movin.design/components/sliders/pleat/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-pleat
```

Or copy [`slider-pleat.tsx`](./slider-pleat.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-pleat.html`](./slider-pleat.html) where it goes and include [`slider-pleat.css`](./slider-pleat.css). [`slider-pleat.js`](./slider-pleat.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
