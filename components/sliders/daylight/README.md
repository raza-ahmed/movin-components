# Daylight slider

A time-of-day slider: the sun arcs across the sky from sunrise to sunset, the sky brightens towards noon, the stars fade out and the clock reads the time.

Live preview: https://movin.design/components/sliders/daylight/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-daylight
```

Or copy [`slider-daylight.tsx`](./slider-daylight.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-daylight.html`](./slider-daylight.html) where it goes and include [`slider-daylight.css`](./slider-daylight.css). [`slider-daylight.js`](./slider-daylight.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
