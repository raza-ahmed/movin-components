# Depth slider

The numbers along the scale are sharp near the thumb and fall out of focus further away, and the plane of focus trails the thumb and hunts past it a little, like a lens racking focus.

Live preview: https://movin.design/components/sliders/depth/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-depth
```

Or copy [`slider-depth.tsx`](./slider-depth.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-depth.html`](./slider-depth.html) where it goes and include [`slider-depth.css`](./slider-depth.css). [`slider-depth.js`](./slider-depth.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
