# Vernier slider

A scrubber with fine control: drag down away from the track and the thumb slows to half, quarter, then fine speed, while the scale above zooms in around it and names the speed.

Live preview: https://movin.design/components/sliders/vernier/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-vernier
```

Or copy [`slider-vernier.tsx`](./slider-vernier.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-vernier.html`](./slider-vernier.html) where it goes and include [`slider-vernier.css`](./slider-vernier.css). [`slider-vernier.js`](./slider-vernier.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
