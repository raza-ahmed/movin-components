# Grow slider

A watering slider for a potted plant: the stem rises, leaves pop out along it in turn and the flower opens at the top once it is fully watered.

Live preview: https://movin.design/components/sliders/grow/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-grow
```

Or copy [`slider-grow.tsx`](./slider-grow.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-grow.html`](./slider-grow.html) where it goes and include [`slider-grow.css`](./slider-grow.css). [`slider-grow.js`](./slider-grow.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
