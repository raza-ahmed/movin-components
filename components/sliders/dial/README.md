# Dial slider

A gain knob: drag sideways or use the arrow keys and the knob turns through its sweep while a ring of lights fills in around it.

Live preview: https://movin.design/components/sliders/dial/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-dial
```

Or copy [`slider-dial.tsx`](./slider-dial.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-dial.html`](./slider-dial.html) where it goes and include [`slider-dial.css`](./slider-dial.css). [`slider-dial.js`](./slider-dial.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
