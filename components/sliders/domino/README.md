# Domino slider

A count slider whose track is a row of dominoes: drag forward and they topple one into the next to make the fill, drag back and they stand up again.

Live preview: https://movin.design/components/sliders/domino/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-domino
```

Or copy [`slider-domino.tsx`](./slider-domino.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-domino.html`](./slider-domino.html) where it goes and include [`slider-domino.css`](./slider-domino.css). [`slider-domino.js`](./slider-domino.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
