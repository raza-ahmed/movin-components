# Bow slider

A draw-weight slider as a bow: drag and the string pulls back with the arrow while the limbs bend further, with the weight in pounds below.

Live preview: https://movin.design/components/sliders/bow/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-bow
```

Or copy [`slider-bow.tsx`](./slider-bow.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-bow.html`](./slider-bow.html) where it goes and include [`slider-bow.css`](./slider-bow.css). [`slider-bow.js`](./slider-bow.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
