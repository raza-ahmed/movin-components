# Magnet slider

A recommended value marked on the track pulls the thumb in when you drag close, with the pin leaning towards it and a pulse when it catches; drag on past to break free.

Live preview: https://movin.design/components/sliders/magnet/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-magnet
```

Or copy [`slider-magnet.tsx`](./slider-magnet.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-magnet.html`](./slider-magnet.html) where it goes and include [`slider-magnet.css`](./slider-magnet.css). [`slider-magnet.js`](./slider-magnet.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
