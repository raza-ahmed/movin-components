# Thermometer slider

A temperature slider as a glass thermometer: the column climbs the scale and the reading changes in degrees; near the top, the bulb starts to bubble.

Live preview: https://movin.design/components/sliders/thermometer/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-thermometer
```

Or copy [`slider-thermometer.tsx`](./slider-thermometer.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-thermometer.html`](./slider-thermometer.html) where it goes and include [`slider-thermometer.css`](./slider-thermometer.css). [`slider-thermometer.js`](./slider-thermometer.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
