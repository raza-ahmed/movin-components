# Throttle slider

A thrust slider for a rocket: the flame lengthens and flickers, the rocket lifts off its pad and shakes harder as it climbs, and at high thrust the stars start to streak past.

Live preview: https://movin.design/components/sliders/throttle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-throttle
```

Or copy [`slider-throttle.tsx`](./slider-throttle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-throttle.html`](./slider-throttle.html) where it goes and include [`slider-throttle.css`](./slider-throttle.css). [`slider-throttle.js`](./slider-throttle.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
