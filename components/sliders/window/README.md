# Window slider

A car window slider: the glass rolls down, a dog pokes its head out past a third of the way, wind starts to stream by halfway and near the bottom its ears flap.

Live preview: https://movin.design/components/sliders/window/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-window
```

Or copy [`slider-window.tsx`](./slider-window.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-window.html`](./slider-window.html) where it goes and include [`slider-window.css`](./slider-window.css). [`slider-window.js`](./slider-window.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
