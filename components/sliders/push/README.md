# Push slider

Three dividers on one track that cannot pass each other: drag one into the next and it shoves it along, so the four segments always add up to the whole.

Live preview: https://movin.design/components/sliders/push/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-push
```

Or copy [`slider-push.tsx`](./slider-push.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-push.html`](./slider-push.html) where it goes and include [`slider-push.css`](./slider-push.css). [`slider-push.js`](./slider-push.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
