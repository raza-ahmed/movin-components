# Squiggle slider

A playback scrubber whose played part is a travelling wave. Hold it and the wave settles flat so you can aim; let go and it ripples back, with the elapsed and total time below.

Live preview: https://movin.design/components/sliders/squiggle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-squiggle
```

Or copy [`slider-squiggle.tsx`](./slider-squiggle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-squiggle.html`](./slider-squiggle.html) where it goes and include [`slider-squiggle.css`](./slider-squiggle.css). [`slider-squiggle.js`](./slider-squiggle.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
