# Notch slider

A size picker with five detents: the thumb clicks into each notch with a little overshoot, the notch pulses and the chosen size label lifts.

Live preview: https://movin.design/components/sliders/notch/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-notch
```

Or copy [`slider-notch.tsx`](./slider-notch.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-notch.html`](./slider-notch.html) where it goes and include [`slider-notch.css`](./slider-notch.css). [`slider-notch.js`](./slider-notch.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
