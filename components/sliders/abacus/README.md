# Abacus slider

A counter of ten beads on a rod: drag the gap and the beads slide across one after another, knocking to a stop against the row with a small rebound.

Live preview: https://movin.design/components/sliders/abacus/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-abacus
```

Or copy [`slider-abacus.tsx`](./slider-abacus.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-abacus.html`](./slider-abacus.html) where it goes and include [`slider-abacus.css`](./slider-abacus.css). [`slider-abacus.js`](./slider-abacus.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
