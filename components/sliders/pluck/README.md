# Pluck slider

A tension slider drawn as a taut string with a bead for a thumb: press and the string bends under the bead, pull up or down to bend it further, and let go to make it twang.

Live preview: https://movin.design/components/sliders/pluck/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-pluck
```

Or copy [`slider-pluck.tsx`](./slider-pluck.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-pluck.html`](./slider-pluck.html) where it goes and include [`slider-pluck.css`](./slider-pluck.css). [`slider-pluck.js`](./slider-pluck.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
