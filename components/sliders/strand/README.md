# Strand slider

A slider made of five strands drawn through a ring: behind the ring they lie bound together as the fill, and ahead they fan out loose, rippling away from the ring as you drag.

Live preview: https://movin.design/components/sliders/strand/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-strand
```

Or copy [`slider-strand.tsx`](./slider-strand.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-strand.html`](./slider-strand.html) where it goes and include [`slider-strand.css`](./slider-strand.css). [`slider-strand.js`](./slider-strand.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
