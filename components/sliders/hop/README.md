# Hop slider

A ten-step slider whose thumb hops from step to step in little arcs, squashing as it lands, with a dotted trace of each jump fading behind it.

Live preview: https://movin.design/components/sliders/hop/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-hop
```

Or copy [`slider-hop.tsx`](./slider-hop.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-hop.html`](./slider-hop.html) where it goes and include [`slider-hop.css`](./slider-hop.css). [`slider-hop.js`](./slider-hop.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
