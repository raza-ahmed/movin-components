# Mood slider

A rating slider with a face: drag and the mouth bends from a frown to a grin, the brows go from worried to raised, the eyes widen and a word names the mood.

Live preview: https://movin.design/components/sliders/mood/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-mood
```

Or copy [`slider-mood.tsx`](./slider-mood.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-mood.html`](./slider-mood.html) where it goes and include [`slider-mood.css`](./slider-mood.css). [`slider-mood.js`](./slider-mood.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
