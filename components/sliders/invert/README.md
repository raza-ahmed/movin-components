# Invert slider

A wide volume bar with its label inside: the fill sweeps under the words and inverts them where it covers them, and the speaker icon gains and loses waves as you go.

Live preview: https://movin.design/components/sliders/invert/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-invert
```

Or copy [`slider-invert.tsx`](./slider-invert.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-invert.html`](./slider-invert.html) where it goes and include [`slider-invert.css`](./slider-invert.css). [`slider-invert.js`](./slider-invert.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
