# Nudge slider

The value label rides above the thumb and shoves the Off and Max labels out of the way as it comes near: they get knocked down, out and tipped over, so the three never overlap.

Live preview: https://movin.design/components/sliders/nudge/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-nudge
```

Or copy [`slider-nudge.tsx`](./slider-nudge.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-nudge.html`](./slider-nudge.html) where it goes and include [`slider-nudge.css`](./slider-nudge.css). [`slider-nudge.js`](./slider-nudge.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
