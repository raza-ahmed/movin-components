# Twist slider

A slider whose track is a ribbon with a half twist at the thumb: ink on one face, paper on the other. Drag fast and the twist stretches out behind you, then tightens as you stop.

Live preview: https://movin.design/components/sliders/twist/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-twist
```

Or copy [`slider-twist.tsx`](./slider-twist.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-twist.html`](./slider-twist.html) where it goes and include [`slider-twist.css`](./slider-twist.css). [`slider-twist.js`](./slider-twist.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
