# Keys slider

A note picker drawn as a two-octave keyboard: the key under the thumb goes down and darkens, its neighbours dip a little, and the note name rides above.

Live preview: https://movin.design/components/sliders/keys/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-keys
```

Or copy [`slider-keys.tsx`](./slider-keys.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-keys.html`](./slider-keys.html) where it goes and include [`slider-keys.css`](./slider-keys.css). [`slider-keys.js`](./slider-keys.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
