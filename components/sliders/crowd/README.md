# Crowd slider

An expected guests slider drawn as a room of seats: people pop into their seats in a scattered order as the number grows, the way a room fills up.

Live preview: https://movin.design/components/sliders/crowd/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-crowd
```

Or copy [`slider-crowd.tsx`](./slider-crowd.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-crowd.html`](./slider-crowd.html) where it goes and include [`slider-crowd.css`](./slider-crowd.css). [`slider-crowd.js`](./slider-crowd.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
