# Louvre slider

A light slider made of slats that turn face-on as the thumb passes over them and edge-on as it leaves, so every drag sends a wave along the row.

Live preview: https://movin.design/components/sliders/louvre/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-louvre
```

Or copy [`slider-louvre.tsx`](./slider-louvre.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-louvre.html`](./slider-louvre.html) where it goes and include [`slider-louvre.css`](./slider-louvre.css). [`slider-louvre.js`](./slider-louvre.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
