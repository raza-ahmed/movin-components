# Candle slider

A burn time slider drawn as a candle: it melts down to a stub as the hours pass, drips lengthen down its side and the flame and glow follow it down.

Live preview: https://movin.design/components/sliders/candle/

## React + Tailwind

Install with the shadcn CLI:

```sh
npx shadcn@latest add @movin/slider-candle
```

Or copy [`slider-candle.tsx`](./slider-candle.tsx) into your project. Dependencies: none.

## Plain HTML + CSS + JS

No framework and no dependencies. Paste [`slider-candle.html`](./slider-candle.html) where it goes and include [`slider-candle.css`](./slider-candle.css). [`slider-candle.js`](./slider-candle.js) sets up every copy on the page; in a framework, call its init function on your element once it is mounted.
